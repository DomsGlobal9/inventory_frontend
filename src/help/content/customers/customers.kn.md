ಗ್ರಾಹಕರನ್ನು ಅವರ **ಫೋನ್ ನಂಬರ್** ನಿಂದ ಹುಡುಕಲಾಗುತ್ತದೆ. ಒಂದು ನಂಬರ್ ಒಬ್ಬ ಗ್ರಾಹಕರಿಗೆ ಮಾತ್ರ.

ಗ್ರಾಹಕರನ್ನು ಮೊದಲು ಇಲ್ಲಿ ಸೇರಿಸಬೇಕಾಗಿಲ್ಲ. [New sale](/help/orders/new-sale) ನಲ್ಲಿ ಹೊಸ ನಂಬರ್ ಟೈಪ್ ಮಾಡಿದಾಗ, ಗ್ರಾಹಕರು ಸೇಲ್ ಜೊತೆಗೆ ಸೇವ್ ಆಗುತ್ತಾರೆ.

## 1. Customers ತೆರೆಯಿರಿ

1. ಎಡಗಡೆಯ ಮೆನುವಿನಲ್ಲಿ [[1]] **Customers** ಒತ್ತಿರಿ.
2. [[2]] ಫೋನ್, ಹೆಸರು, ಗ್ರಾಹಕರ ಕೋಡ್ ಅಥವಾ ಇಮೇಲ್‌ನಿಂದ ಹುಡುಕಿ.
3. ಯಾರನ್ನಾದರೂ ಸೇರಿಸಲು, [[3]] **Add customer** ಒತ್ತಿರಿ.

![Customers ಪಟ್ಟಿ. ಎಡ ಮೆನುವಿನಲ್ಲಿ Customers 1, ಹುಡುಕುವ ಬಾಕ್ಸ್ 2 ಮತ್ತು Add customer ಬಟನ್ 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-open.webp "ಆ ಗ್ರಾಹಕರನ್ನು ತೆರೆಯಲು ಸಾಲಿನಲ್ಲಿ View ಒತ್ತಿರಿ.")

## 2. ಗ್ರಾಹಕರನ್ನು ಸೇರಿಸಿ

1. [[1]] **Phone** ನಂಬರ್ ಟೈಪ್ ಮಾಡಿ. ಅದು ಹೇಗೆ ಸೇವ್ ಆಗುತ್ತದೆ ಎಂದು ಹಸಿರು ಸಾಲು ತೋರಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ *Saved as +91 99123 45678*.
2. [[2]] **Name** ಟೈಪ್ ಮಾಡಿ.
3. Email, Company ಮತ್ತು GSTIN ಕಡ್ಡಾಯ ಅಲ್ಲ. ಇವು ನಿಮ್ಮ ಸ್ವಂತ ದಾಖಲೆಗಾಗಿ ಗ್ರಾಹಕರ ಜೊತೆ ಸೇವ್ ಆಗುತ್ತವೆ. ರಸೀದಿಯಲ್ಲಿ ಗ್ರಾಹಕರ ಕಂಪನಿ ಅಥವಾ GSTIN ಪ್ರಿಂಟ್ ಆಗುವುದಿಲ್ಲ, ನಿಮ್ಮ ಅಂಗಡಿಯ GSTIN ಮಾತ್ರ ಪ್ರಿಂಟ್ ಆಗುತ್ತದೆ.
4. [[3]] **Add customer** ಒತ್ತಿರಿ.

![Add customer ಫಾರ್ಮ್. 99123 45678 ಇರುವ Phone 1, Kavya Menon ಇರುವ Name 2 ಮತ್ತು Add customer ಬಟನ್ 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-add-customer.webp "ಸೇವ್ ಆದ ತಕ್ಷಣ ಗ್ರಾಹಕರ ಪೇಜ್ ತೆರೆಯುತ್ತದೆ.")

ಆ ನಂಬರ್ ಈಗಾಗಲೇ ಯಾರಿಗಾದರೂ ಸೇವ್ ಆಗಿದ್ದರೆ, ಅದು ಯಾರದು ಎಂದು ಮತ್ತು ಅವರನ್ನು ತೆರೆಯುವ ಬಟನ್ ಕಾಣುತ್ತದೆ:

![ಕೆಂಪು ಮೆಸೇಜ್: Lakshmi Narayanan is already saved with that number, Open Lakshmi Narayanan ಬಟನ್‌ನೊಂದಿಗೆ.](2-number-taken.webp "ಬಹುಶಃ ನೀವು ಈಗಾಗಲೇ ಇದೇ ಗ್ರಾಹಕರನ್ನು ಹುಡುಕುತ್ತಿದ್ದಿರಿ.")

## 3. ಗ್ರಾಹಕರ ಪೇಜ್

1. [[1]] **New sale** ಈ ಗ್ರಾಹಕರಿಗೆ ಕೌಂಟರ್ ಸೇಲ್ ಶುರು ಮಾಡುತ್ತದೆ (ಕಂಪ್ಯೂಟರ್ ಅಥವಾ ಟ್ಯಾಬ್ಲೆಟ್‌ನಲ್ಲಿ).
2. [[2]] **Edit** ಅವರ ಫೋನ್, ಹೆಸರು, ಇಮೇಲ್, ಕಂಪನಿ ಅಥವಾ GSTIN ಬದಲಿಸುತ್ತದೆ.
3. [[3]] **Groups** ಅವರು ಇರುವ ಗುಂಪುಗಳನ್ನು ತೋರಿಸುತ್ತದೆ.
4. [[4]] **Sales Orders** ಅವರು ಖರೀದಿಸಿದ ಎಲ್ಲವನ್ನೂ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. ಆರ್ಡರ್ ತೆರೆಯಲು **View** ಒತ್ತಿರಿ.
5. [[5]] **Dispatches** ಅವರಿಗೆ ಕಳುಹಿಸಿದ ಅಥವಾ ಕೈಗೆ ಕೊಟ್ಟದ್ದನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. ರಿಟರ್ನ್ ಬುಕ್ ಮಾಡುವುದು ಇಲ್ಲಿಂದಲೇ.

![Lakshmi Narayanan ಅವರ ಪೇಜ್. New sale 1, Edit 2, Groups ಬಾಕ್ಸ್ 3, Sales Orders ಟ್ಯಾಬ್ 4 ಮತ್ತು Dispatches ಟ್ಯಾಬ್ 5 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-customer-page.webp "Contact Info, Company Details ಮತ್ತು Address ಎಡಗಡೆ ಇವೆ.")

## 4. ಗ್ರಾಹಕರನ್ನು ಗುಂಪಿಗೆ ಸೇರಿಸಿ

ಆಫರ್‌ಗಳನ್ನು ಒಂದು ಗುಂಪಿಗೆ ಮಾತ್ರ ಮಾಡಬಹುದು, ಉದಾಹರಣೆಗೆ *VIP*. ಗುಂಪಿನಲ್ಲಿರುವ ಎಲ್ಲರಿಗೂ ಆ ಆಫರ್ ಸಿಗುತ್ತದೆ.

1. [[1]] ಗುಂಪಿನ ಹೆಸರು ಟೈಪ್ ಮಾಡಿ, ಉದಾಹರಣೆಗೆ **VIP**, ಮತ್ತು **Enter** ಅಥವಾ **+** ಒತ್ತಿರಿ.
2. [[2]] ಅಥವಾ ಬೇರೆ ಗ್ರಾಹಕರು ಈಗಾಗಲೇ ಇರುವ ಗುಂಪು ಒತ್ತಿರಿ. ಅದರಲ್ಲಿ ಎಷ್ಟು ಗ್ರಾಹಕರು ಇದ್ದಾರೆ ಎಂದು ಚಿಕ್ಕ ಸಂಖ್ಯೆ ತೋರಿಸುತ್ತದೆ.

![ಹೊಸ ಗ್ರಾಹಕರ Groups ಬಾಕ್ಸ್. Add to a group ಬಾಕ್ಸ್ 1 ಎಂದು, ಸೂಚಿಸಿದ ಗುಂಪು VIP 1 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-add-to-group.webp "ಗ್ರಾಹಕರನ್ನು ಗುಂಪಿನಿಂದ ತೆಗೆಯಲು ಆ ಗುಂಪಿನ ಮೇಲಿನ x ಒತ್ತಿರಿ.")

ಅದು ತಕ್ಷಣ ಸೇವ್ ಆಗುತ್ತದೆ. [ಆಫರ್‌ಗಳು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತವೆ](/help/offers/how-offers-work) ನಲ್ಲಿ ಇನ್ನಷ್ಟು ಓದಿ.

## ಉದಾಹರಣೆ: VIP ಗ್ರಾಹಕರಿಗೆ ಮಾತ್ರ ಆಫರ್

1. ಪ್ರತಿ VIP ಗ್ರಾಹಕರ ಪೇಜ್ ತೆರೆಯಿರಿ ಮತ್ತು ಹಂತ 4 ರಲ್ಲಿ ಇರುವಂತೆ ಅವರನ್ನು **VIP** ಗುಂಪಿಗೆ ಸೇರಿಸಿ.
2. **Offers** ಗೆ ಹೋಗಿ ಆಫರ್ ಮಾಡಿ. [ಹೊಸ ಆಫರ್ ಮಾಡಿ](/help/offers/create-an-offer) ನೋಡಿ.
3. **Customers** ಕೆಳಗೆ **Some groups** ಆರಿಸಿ, ನಂತರ **VIP** ಗುಂಪು ಒತ್ತಿರಿ. ಅದರಲ್ಲಿ ಎಷ್ಟು ಗ್ರಾಹಕರು ಇದ್ದಾರೆ ಎಂದು ಚಿಕ್ಕ ಸಂಖ್ಯೆ ತೋರಿಸುತ್ತದೆ.
4. ಆಫರ್ ಸೇವ್ ಮಾಡಿ.

ಕೌಂಟರ್‌ನಲ್ಲಿ, ಸೇಲ್‌ನಲ್ಲಿ VIP ಗುಂಪಿನ ಗ್ರಾಹಕರು ಇದ್ದಾಗ ಮಾತ್ರ ಆಫರ್ ಸಿಗುತ್ತದೆ. ಮೊದಲು **New sale** ನಲ್ಲಿ ಗ್ರಾಹಕರ ಫೋನ್ ನಂಬರ್ ಟೈಪ್ ಮಾಡಿ. ಗ್ರಾಹಕರು ಇಲ್ಲದ ಸೇಲ್‌ಗೆ, ಅಥವಾ ಗುಂಪಿನಲ್ಲಿ ಇಲ್ಲದ ಗ್ರಾಹಕರಿಗೆ ಆಫರ್ ಸಿಗುವುದಿಲ್ಲ.

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq "... is already saved with that number." ಎಂದು ಬರುತ್ತಿದೆ
ಬೇರೆ ಗ್ರಾಹಕರಿಗೆ ಈ ಫೋನ್ ನಂಬರ್ ಇದೆ. ಅವರ ಬಳಿ ಹೋಗಲು **Open** ಒತ್ತಿರಿ. ನಿಜವಾಗಿಯೂ ಬೇರೆ ವ್ಯಕ್ತಿಯಾಗಿದ್ದರೆ, ಗ್ರಾಹಕರ ಬಳಿ ನಂಬರ್ ಸರಿಯಾಗಿದೆಯೇ ಎಂದು ಕೇಳಿ.
:::

:::faq ಗ್ರಾಹಕರು ಸಿಗುತ್ತಿಲ್ಲ
ಫೋನ್ ನಂಬರ್‌ನ ಕೊನೆಯ ಕೆಲವು ಅಂಕಿಗಳಿಂದ ಅಥವಾ ಮೊದಲ ಹೆಸರಿನಿಂದ ಮಾತ್ರ ಹುಡುಕಿ. ಸ್ಟೇಟಸ್ ಪಟ್ಟಿಯನ್ನೂ ಮತ್ತೆ **All Statuses** ಗೆ ಇಡಿ.
:::

:::faq ಮೆನುವಿನಲ್ಲಿ Customers ಕಾಣುತ್ತಿಲ್ಲ
ನಿಮ್ಮ ರೋಲ್‌ಗೆ ಗ್ರಾಹಕರನ್ನು ನೋಡುವ ಅನುಮತಿ ಇಲ್ಲ. ಸ್ಟಾಕ್ ರೂಮ್ ಸ್ಟಾಫ್ ಮತ್ತು ಇನ್ವೆಂಟರಿ ಮ್ಯಾನೇಜರ್‌ಗಳಿಗೆ Customers ಇಲ್ಲ. ಅಂಗಡಿಯ ಮಾಲೀಕರನ್ನು ಕೇಳಿ.
:::
