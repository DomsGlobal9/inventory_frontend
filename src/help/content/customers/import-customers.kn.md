ನಿಮ್ಮ ಬಳಿ Excel‌ನಲ್ಲಿ ಗ್ರಾಹಕರ ಪಟ್ಟಿ ಇದ್ದಾಗ, ಉದಾಹರಣೆಗೆ ಹಳೆಯ ರಿಜಿಸ್ಟರ್ ಅಥವಾ ಬಿಲ್ಲಿಂಗ್ ಸಾಫ್ಟ್‌ವೇರ್‌ನಿಂದ, ಇದನ್ನು ಬಳಸಿ. ಶೀಟ್‌ನ ಪ್ರತಿ ಸಾಲು ಒಬ್ಬ ಗ್ರಾಹಕ.

ಗ್ರಾಹಕರನ್ನು ಸೇರಿಸಬಲ್ಲವರಿಗೆ ಮಾತ್ರ **Import customers** ಕಾಣುತ್ತದೆ.

## 1. Import customers ತೆರೆಯಿರಿ

1. ಎಡಬದಿಯ ಮೆನುವಿನಲ್ಲಿ [[1]] **Customers** ಒತ್ತಿ.
2. ಮೇಲೆ [[2]] **Import customers** ಒತ್ತಿ.

![Customers ಸ್ಕ್ರೀನ್. ಮೆನುವಿನಲ್ಲಿ Customers ಮೇಲೆ 1, Import customers ಬಟನ್ ಮೇಲೆ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-open.webp "Import customers, Add customer ಪಕ್ಕದಲ್ಲಿದೆ.")

## 2. ಮಾದರಿ ಫೈಲ್ ತುಂಬಿ, ಆಯ್ಕೆ ಮಾಡಿ

1. [[1]] **Download the example file (Excel)** ಒತ್ತಿ. *customers-import-example.xlsx* ಎಂಬ ಫೈಲ್ ಸಿಗುತ್ತದೆ. ಅದನ್ನು Excel‌ನಲ್ಲಿ ತೆರೆಯಿರಿ.
2. **Customers** ಶೀಟ್‌ನಲ್ಲಿ ನಿಮ್ಮ ಗ್ರಾಹಕರನ್ನು ಟೈಪ್ ಮಾಡಿ, ಪ್ರತಿ ಸಾಲಿಗೆ ಒಬ್ಬ ಗ್ರಾಹಕ. ಮೊದಲ ಸಾಲನ್ನು (ಕಾಲಮ್ ಹೆಸರುಗಳು) ಹಾಗೆಯೇ ಇಡಿ. ಎರಡನೇ ಶೀಟ್ **How to fill**‌ನಲ್ಲಿ ಉದಾಹರಣೆಗಳಿವೆ.
3. ಫೈಲ್ ಸೇವ್ ಮಾಡಿ.
4. ScaleEzy‌ಗೆ ಹಿಂತಿರುಗಿ [[2]] **Choose a file** ಒತ್ತಿ ನಿಮ್ಮ ಫೈಲ್ ಆಯ್ಕೆ ಮಾಡಿ. ಫೈಲ್ ಅನ್ನು ಎಳೆದು ಬಾಕ್ಸ್ ಮೇಲೆ ಬಿಡಬಹುದು ಕೂಡ.

![Import customers ವಿಂಡೋ. Download the example file ಮೇಲೆ 1, Choose a file ಬಾಕ್ಸ್ ಮೇಲೆ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-choose.webp "ಒಂದು ಫೈಲ್‌ನಲ್ಲಿ 5,000 ಗ್ರಾಹಕರವರೆಗೆ ಇರಬಹುದು.")

### ಪ್ರತಿ ಕಾಲಮ್‌ನಲ್ಲಿ ಏನು ಬರೆಯಬೇಕು

| ಕಾಲಮ್ | ಏನು ಬರೆಯಬೇಕು |
|---|---|
| **Name** | ಗ್ರಾಹಕರ ಹೆಸರು. ಕಡ್ಡಾಯ. |
| **Phone** | 10 ಅಂಕಿಯ ಮೊಬೈಲ್ ನಂಬರ್. ಕಡ್ಡಾಯ. ನಡುವೆ ಸ್ಪೇಸ್, ಮುಂದೆ *+91* ಅಥವಾ *0* ಇದ್ದರೂ ಪರವಾಗಿಲ್ಲ. |
| **Email** | ಕಡ್ಡಾಯವಲ್ಲ. |
| **Birthday**, **Anniversary** | ಕಡ್ಡಾಯವಲ್ಲ. ಮೊದಲು ದಿನ ಬರೆಯಿರಿ, ಉದಾಹರಣೆಗೆ *14-08* ಅಥವಾ *14-08-1990*. ವರ್ಷವನ್ನು ಇಡುವುದಿಲ್ಲ. |
| **Address** | ಕಡ್ಡಾಯವಲ್ಲ. |
| **GST number**, **Company** | ಕಡ್ಡಾಯವಲ್ಲ, ವ್ಯಾಪಾರಿ ಗ್ರಾಹಕರಿಗೆ. |
| **Notes** | ಕಡ್ಡಾಯವಲ್ಲ. ಗ್ರಾಹಕರ ಬಗ್ಗೆ ನೆನಪಿಡಬೇಕಾದ ಯಾವುದೇ ವಿಷಯ. |

:::tip ನಿಮ್ಮ ಸ್ವಂತ ಶೀಟ್ ಕೂಡ ನಡೆಯುತ್ತದೆ
ಕಾಲಮ್ ಹೆಸರುಗಳು ಅಕ್ಷರಶಃ ಹೊಂದಬೇಕಿಲ್ಲ. *Mobile No.*, *Customer Name*, *DOB*, *City* ಇಂತಹ ಹೆಸರುಗಳು ಅರ್ಥವಾಗುತ್ತವೆ. ScaleEzy ಬಳಸದ ಕಾಲಮ್‌ಗಳ ಹೆಸರುಗಳು ಮುಂದಿನ ಹಂತದಲ್ಲಿ ಕಾಣುತ್ತವೆ, ಹಾಗಾಗಿ ನಿಮಗೆ ತಿಳಿಯದೆ ಏನೂ ಬಿಟ್ಟುಹೋಗುವುದಿಲ್ಲ.
:::

:::warning Excel‌ನಲ್ಲಿ ನಂಬರ್ 9.84802E+09 ರೀತಿ ಕಂಡರೆ
Excel ನಂಬರ್ ಅನ್ನು ಚಿಕ್ಕದು ಮಾಡಿದೆ, ಅದರ ಕೊನೆಯ ಅಂಕಿಗಳು ಹೋಗಿವೆ. Excel‌ನಲ್ಲಿ Phone ಕಾಲಮ್ ಅನ್ನು **Text** ಮಾಡಿ, ನಂಬರ್‌ಗಳನ್ನು ಮತ್ತೆ ಟೈಪ್ ಮಾಡಿ ಸೇವ್ ಮಾಡಿ. ಮಾದರಿ ಫೈಲ್‌ನಲ್ಲಿ Phone ಕಾಲಮ್ ಈಗಾಗಲೇ Text ಆಗಿದೆ.
:::

## 3. ಏನಾಗುತ್ತದೆ ಎಂದು ನೋಡಿ

ScaleEzy ಫೈಲ್ ಓದಿ ಏನು ಮಾಡುತ್ತದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ. ಇನ್ನೂ ಯಾರನ್ನೂ ಸೇರಿಸಿಲ್ಲ.

1. [[1]] ಮೂರು ಸಂಖ್ಯೆಗಳು. **New customers** ಸೇರುತ್ತಾರೆ. **Already in your list** ಎಂದರೆ ಆ ಫೋನ್ ನಂಬರ್ ನಿಮ್ಮಲ್ಲಿ ಈಗಾಗಲೇ ಇರುವ ಗ್ರಾಹಕರದು. **Cannot be added** ಎಂದರೆ ತಪ್ಪಿರುವ ಸಾಲುಗಳು.
2. [[2]] ಸೇರದ ಪ್ರತಿ ಸಾಲು, ನಿಮ್ಮ ಶೀಟ್‌ನಲ್ಲಿನ ಸಾಲಿನ ನಂಬರ್ ಮತ್ತು ಕಾರಣದೊಂದಿಗೆ, ಉದಾಹರಣೆಗೆ *Phone 98480 2233 has 9 digits* (ನಂಬರ್‌ನಲ್ಲಿ 9 ಅಂಕಿಗಳು ಮಾತ್ರ ಇವೆ).
3. ಹೊಸ ಗ್ರಾಹಕರನ್ನು ಸೇರಿಸಲು [[3]] ಬಾಕ್ಸ್ ಟಿಕ್ ಮಾಡಿ, ನಂತರ [[4]] ಎಷ್ಟು ಜನ ಸೇರುತ್ತಾರೆ ಎಂದು ಹೇಳುವ ಬಟನ್ ಒತ್ತಿ, ಉದಾಹರಣೆಗೆ **Add 3 customers**.

![ಪರಿಶೀಲನೆ. ಮೂರು ಸಂಖ್ಯೆಗಳ ಮೇಲೆ 1, ಸೇರದ ಸಾಲುಗಳ ಮೇಲೆ 2, ಟಿಕ್ ಬಾಕ್ಸ್ ಮೇಲೆ 3, Add 3 customers ಬಟನ್ ಮೇಲೆ 4 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-check.webp "ಮೊದಲು ತಪ್ಪುಗಳನ್ನು ಸರಿಪಡಿಸಲು Choose another file ಒತ್ತಿ, ಶೀಟ್ ಸರಿಪಡಿಸಿ ಮತ್ತೆ ಆಯ್ಕೆ ಮಾಡಿ.")

:::note ಈಗಾಗಲೇ ಇರುವ ಗ್ರಾಹಕರು ಎಂದಿಗೂ ಬದಲಾಗುವುದಿಲ್ಲ
ನಿಮ್ಮ ಶೀಟ್‌ನಲ್ಲಿನ ಫೋನ್ ನಂಬರ್ ನಿಮ್ಮ ಪಟ್ಟಿಯಲ್ಲಿ ಈಗಾಗಲೇ ಇರುವ ಗ್ರಾಹಕರದಾಗಿದ್ದರೆ, ಆ ಗ್ರಾಹಕರು ಇದ್ದ ಹಾಗೆಯೇ ಇರುತ್ತಾರೆ. ಹಳೆಯ ಶೀಟ್ ಹೊಸ ವಿವರಗಳ ಮೇಲೆ ಬರೆಯಲು ಸಾಧ್ಯವಿಲ್ಲ.
:::

:::note ಇಂಪೋರ್ಟ್‌ನಿಂದ ಯಾರಿಗೂ WhatsApp ಆಫರ್‌ಗಳು ಹೋಗುವುದಿಲ್ಲ
ಪಟ್ಟಿ ಎಂದರೆ ಗ್ರಾಹಕರ ಒಪ್ಪಿಗೆ ಅಲ್ಲ. ಪ್ರತಿ ಗ್ರಾಹಕರು ಮೊದಲಿನಂತೆ ಟಿಲ್‌ನಲ್ಲಿ ಅಥವಾ ಅಂಗಡಿಯಲ್ಲಿ ಆಫರ್‌ಗಳಿಗೆ ಒಪ್ಪುತ್ತಾರೆ.
:::

## 4. ಮುಗಿಯಿತು

1. [[1]] ಎಷ್ಟು ಗ್ರಾಹಕರು ಸೇರಿದರು ಎಂದು ScaleEzy ಹೇಳುತ್ತದೆ. ಅವರು ತಕ್ಷಣ ನಿಮ್ಮ ಪಟ್ಟಿಯಲ್ಲಿರುತ್ತಾರೆ, ಟಿಲ್ ಅವರನ್ನು ಫೋನ್ ನಂಬರ್‌ನಿಂದ ಹುಡುಕುತ್ತದೆ. ನಿಮ್ಮ ಅಂಗಡಿ ScaleEzy CRM ಬಳಸಿದರೆ, ಅವರು ಕೆಲವು ನಿಮಿಷಗಳಲ್ಲಿ CRM‌ಗೆ ತಲುಪುತ್ತಾರೆ.
2. [[2]] ನಿಮ್ಮ ಇಂಪೋರ್ಟ್‌ಗಳು ದಿನಾಂಕ, ಎಷ್ಟು ಜನ ಸೇರಿದರು ಮತ್ತು ಯಾರು ಮಾಡಿದರು ಎಂಬ ವಿವರಗಳೊಂದಿಗೆ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣುತ್ತವೆ.

![ಇಂಪೋರ್ಟ್ ನಂತರದ ವಿಂಡೋ: 3 customers added ಮೇಲೆ 1, ಫೈಲ್ ಪಕ್ಕದ Take back out ಬಟನ್ ಮೇಲೆ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-done.webp "ವಿಂಡೋ ಮುಚ್ಚಲು Done ಒತ್ತಿ.")

## ಇಂಪೋರ್ಟ್ ಅನ್ನು ಹಿಂದಕ್ಕೆ ತೆಗೆಯಿರಿ

ತಪ್ಪು ಫೈಲ್ ಇಂಪೋರ್ಟ್ ಮಾಡಿದ್ದರೆ, ಮಾಲೀಕರು ಅದನ್ನು ಹಿಂದಕ್ಕೆ ತೆಗೆಯಬಹುದು.

1. **Import customers** ಮತ್ತೆ ಒತ್ತಿ. **Your imports** ಕೆಳಗೆ, ಫೈಲ್ ಪಕ್ಕದಲ್ಲಿ **Take back out** ಒತ್ತಿ.
2. ಎಷ್ಟು ಗ್ರಾಹಕರು ಹೋಗುತ್ತಾರೆ ಎಂದು ScaleEzy ಹೇಳುತ್ತದೆ. ಒಪ್ಪಲು **Take back out** ಒತ್ತಿ.

ಆ ನಂತರ ಬಳಕೆಯಾಗದ ಗ್ರಾಹಕರು ಮಾತ್ರ ತೆಗೆಯಲ್ಪಡುತ್ತಾರೆ. ಆ ನಂತರ ಬಿಲ್, ಪಾಯಿಂಟ್‌ಗಳು, ವಿಳಾಸ ಅಥವಾ ಯಾವುದೇ ಬದಲಾವಣೆ ಪಡೆದ ಗ್ರಾಹಕರು ಸಾಮಾನ್ಯ ಗ್ರಾಹಕರಾಗಿ ನಿಮ್ಮ ಪಟ್ಟಿಯಲ್ಲಿ ಉಳಿಯುತ್ತಾರೆ.

:::note Take back out ಮಾಲೀಕರಿಗೆ ಮಾತ್ರ ಕಾಣುತ್ತದೆ
ಇಂಪೋರ್ಟ್ ಹಿಂದಕ್ಕೆ ತೆಗೆದರೆ ಗ್ರಾಹಕರು ಡಿಲೀಟ್ ಆಗುತ್ತಾರೆ, ಹಾಗಾಗಿ ಇದನ್ನು ಮಾಲೀಕರು ಮಾತ್ರ ಮಾಡಬಹುದು.
:::

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq "The file needs a Name and a Phone column"

:::

:::faq ಒಂದು ಸಾಲು ಆ ನಂಬರ್ "already" ಬೇರೆ ಗ್ರಾಹಕರದು ಎನ್ನುತ್ತದೆ
ಆ ಫೋನ್ ನಂಬರ್ ನಿಮ್ಮ ಪಟ್ಟಿಯಲ್ಲಿ ಈಗಾಗಲೇ ಇರುವ ಗ್ರಾಹಕರದು, ಹಾಗಾಗಿ ಆ ಸಾಲನ್ನು ಬಿಡಲಾಗಿದೆ. ಆ ಗ್ರಾಹಕರ ವಿವರಗಳನ್ನು ಬದಲಿಸಲು, Customers ಪಟ್ಟಿಯಿಂದ ಅವರನ್ನು ತೆರೆದು **Edit** ಒತ್ತಿ.
:::

:::faq ನನ್ನ ಶೀಟ್‌ನಲ್ಲಿ ಒಂದೇ ನಂಬರ್ ಎರಡು ಬಾರಿ ಇದೆ
ಆ ನಂಬರ್ ಇರುವ ಮೊದಲ ಸಾಲು ಮಾತ್ರ ಸೇರುತ್ತದೆ. ಇನ್ನೊಂದು ಸಾಲನ್ನು, ಅದು ಯಾವ ಸಾಲನ್ನು ಪುನರಾವರ್ತಿಸುತ್ತದೆಯೋ ಅದರೊಂದಿಗೆ ತೋರಿಸಲಾಗುತ್ತದೆ.
:::

:::faq ನನ್ನ ಬಳಿ 5,000 ಕ್ಕಿಂತ ಹೆಚ್ಚು ಗ್ರಾಹಕರಿದ್ದಾರೆ
ಶೀಟ್ ಅನ್ನು 5,000 ಸಾಲುಗಳವರೆಗಿನ ಫೈಲ್‌ಗಳಾಗಿ ವಿಭಜಿಸಿ, ಒಂದರ ನಂತರ ಒಂದನ್ನು ಇಂಪೋರ್ಟ್ ಮಾಡಿ.
:::
