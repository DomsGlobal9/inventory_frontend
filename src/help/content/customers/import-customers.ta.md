உங்களிடம் Excel-இல் வாடிக்கையாளர் பட்டியல் இருக்கும்போது, உதாரணமாக பழைய பதிவேடு அல்லது பில்லிங் சாஃப்ட்வேரிலிருந்து, இதைப் பயன்படுத்துங்கள். ஷீட்டின் ஒவ்வொரு வரிசையும் ஒரு வாடிக்கையாளர்.

வாடிக்கையாளர்களைச் சேர்க்கக்கூடியவர்களுக்கு மட்டுமே **Import customers** தெரியும்.

## 1. Import customers-ஐத் திறக்கவும்

1. இடது பக்க மெனுவில் [[1]] **Customers** என்பதை அழுத்தவும்.
2. மேலே [[2]] **Import customers** என்பதை அழுத்தவும்.

![Customers திரை. மெனுவில் Customers மீது 1, Import customers பட்டன் மீது 2 எனக் குறிக்கப்பட்டுள்ளது.](1-open.webp "Import customers, Add customer-க்கு அருகில் உள்ளது.")

## 2. மாதிரி ஃபைலை நிரப்பி, தேர்ந்தெடுக்கவும்

1. [[1]] **Download the example file (Excel)** என்பதை அழுத்தவும். *customers-import-example.xlsx* என்ற ஃபைல் கிடைக்கும். அதை Excel-இல் திறக்கவும்.
2. **Customers** ஷீட்டில் உங்கள் வாடிக்கையாளர்களை டைப் செய்யுங்கள், ஒரு வரிசைக்கு ஒரு வாடிக்கையாளர். முதல் வரிசையை (காலம் பெயர்கள்) அப்படியே வைத்திருங்கள். இரண்டாவது ஷீட் **How to fill**-இல் உதாரணங்கள் உள்ளன.
3. ஃபைலை சேவ் செய்யுங்கள்.
4. ScaleEzy-க்குத் திரும்பி [[2]] **Choose a file** என்பதை அழுத்தி உங்கள் ஃபைலைத் தேர்ந்தெடுக்கவும். ஃபைலை இழுத்து பாக்ஸின் மீது விடவும் செய்யலாம்.

![Import customers விண்டோ. Download the example file மீது 1, Choose a file பாக்ஸ் மீது 2 எனக் குறிக்கப்பட்டுள்ளது.](2-choose.webp "ஒரு ஃபைலில் 5,000 வாடிக்கையாளர்கள் வரை இருக்கலாம்.")

### ஒவ்வொரு காலத்திலும் என்ன எழுத வேண்டும்

| காலம் | என்ன எழுத வேண்டும் |
|---|---|
| **Name** | வாடிக்கையாளரின் பெயர். கட்டாயம். |
| **Phone** | 10 இலக்க மொபைல் எண். கட்டாயம். இடைவெளிகள், முன்னால் *+91* அல்லது *0* இருந்தாலும் பரவாயில்லை. |
| **Email** | கட்டாயமில்லை. |
| **Birthday**, **Anniversary** | கட்டாயமில்லை. முதலில் தேதி, உதாரணமாக *14-08* அல்லது *14-08-1990*. வருடம் வைக்கப்படாது. |
| **Address** | கட்டாயமில்லை. |
| **GST number**, **Company** | கட்டாயமில்லை, வியாபார வாடிக்கையாளர்களுக்கு. |
| **Notes** | கட்டாயமில்லை. வாடிக்கையாளரைப் பற்றி நினைவில் வைக்க விரும்புவது எதுவும். |

:::tip உங்கள் சொந்த ஷீட்டும் வேலை செய்யும்
காலம் பெயர்கள் அச்சு அசலாக இருக்க வேண்டியதில்லை. *Mobile No.*, *Customer Name*, *DOB*, *City* போன்ற பெயர்கள் புரிந்துகொள்ளப்படும். ScaleEzy பயன்படுத்தாத காலங்களின் பெயர்கள் அடுத்த ஸ்டெப்பில் காட்டப்படும்; எனவே உங்களுக்குத் தெரியாமல் எதுவும் விடுபடாது.
:::

:::warning Excel-இல் எண் 9.84802E+09 போலத் தெரிந்தால்
Excel எண்ணைச் சுருக்கிவிட்டது; அதன் கடைசி இலக்கங்கள் போய்விட்டன. Excel-இல் Phone காலத்தை **Text** ஆக மாற்றி, எண்களை மறுபடி டைப் செய்து சேவ் செய்யுங்கள். மாதிரி ஃபைலில் Phone காலம் ஏற்கனவே Text ஆக உள்ளது.
:::

## 3. என்ன நடக்கும் என்று பாருங்கள்

ScaleEzy ஃபைலைப் படித்து என்ன செய்யும் என்று காட்டும். இன்னும் யாரும் சேர்க்கப்படவில்லை.

1. [[1]] மூன்று எண்ணிக்கைகள். **New customers** சேர்க்கப்படுவார்கள். **Already in your list** என்றால் அந்த ஃபோன் எண் உங்களிடம் ஏற்கனவே உள்ள வாடிக்கையாளருடையது. **Cannot be added** என்பவை தவறு உள்ள வரிசைகள்.
2. [[2]] சேர்க்கப்படாத ஒவ்வொரு வரிசையும், உங்கள் ஷீட்டில் அதன் வரிசை எண் மற்றும் காரணத்துடன், உதாரணமாக *Phone 98480 2233 has 9 digits* (எண்ணில் 9 இலக்கங்கள் மட்டுமே).
3. புதிய வாடிக்கையாளர்களைச் சேர்க்க [[3]] பாக்ஸை டிக் செய்து, பிறகு [[4]] எத்தனை பேர் சேர்க்கப்படுவார்கள் என்று சொல்லும் பட்டனை அழுத்தவும், உதாரணமாக **Add 3 customers**.

![சரிபார்ப்பு. மூன்று எண்ணிக்கைகள் மீது 1, சேர்க்கப்படாத வரிசைகள் மீது 2, டிக் பாக்ஸ் மீது 3, Add 3 customers பட்டன் மீது 4 எனக் குறிக்கப்பட்டுள்ளது.](3-check.webp "முதலில் தவறுகளைத் திருத்த, Choose another file-ஐ அழுத்தி, ஷீட்டைத் திருத்தி மறுபடி தேர்ந்தெடுக்கவும்.")

:::note ஏற்கனவே உள்ள வாடிக்கையாளர் ஒருபோதும் மாறமாட்டார்
உங்கள் ஷீட்டில் உள்ள ஃபோன் எண் உங்கள் பட்டியலில் ஏற்கனவே உள்ள வாடிக்கையாளருடையது என்றால், அந்த வாடிக்கையாளர் இருந்தபடியே இருப்பார். பழைய ஷீட் புதிய விவரங்களின் மேல் எழுத முடியாது.
:::

:::note இம்போர்ட்டால் யாருக்கும் WhatsApp ஆஃபர்கள் போகாது
பட்டியல் என்பது வாடிக்கையாளரின் சம்மதம் அல்ல. ஒவ்வொரு வாடிக்கையாளரும் முன்பு போலவே டில்லில் அல்லது கடையில் ஆஃபர்களுக்குச் சம்மதிப்பார்.
:::

## 4. முடிந்தது

1. [[1]] எத்தனை வாடிக்கையாளர்கள் சேர்க்கப்பட்டனர் என்று ScaleEzy சொல்லும். அவர்கள் உடனே உங்கள் பட்டியலில் இருப்பார்கள்; டில் அவர்களை ஃபோன் எண்ணால் கண்டுபிடிக்கும். உங்கள் கடை ScaleEzy CRM பயன்படுத்தினால், அவர்கள் சில நிமிடங்களில் CRM-க்கு வந்துவிடுவார்கள்.
2. [[2]] உங்கள் இம்போர்ட்கள் தேதி, எத்தனை பேர் சேர்க்கப்பட்டனர், யார் செய்தார் என்ற விவரங்களுடன் பட்டியலிடப்படும்.

![இம்போர்ட்டுக்குப் பிறகான விண்டோ: 3 customers added மீது 1, ஃபைலுக்கு அருகில் உள்ள Take back out பட்டன் மீது 2 எனக் குறிக்கப்பட்டுள்ளது.](4-done.webp "விண்டோவை மூட Done-ஐ அழுத்தவும்.")

## இம்போர்ட்டைத் திரும்ப எடுக்கவும்

தவறான ஃபைலை இம்போர்ட் செய்திருந்தால், உரிமையாளர் அதைத் திரும்ப எடுக்கலாம்.

1. **Import customers** என்பதை மறுபடி அழுத்தவும். **Your imports** என்பதன் கீழ், ஃபைலுக்கு அருகில் **Take back out** என்பதை அழுத்தவும்.
2. எத்தனை வாடிக்கையாளர்கள் நீக்கப்படுவார்கள் என்று ScaleEzy சொல்லும். ஒப்புக்கொள்ள **Take back out** என்பதை அழுத்தவும்.

அதன் பிறகு பயன்படுத்தப்படாத வாடிக்கையாளர்கள் மட்டுமே நீக்கப்படுவார்கள். அதன் பிறகு பில், பாயிண்ட்கள், முகவரி அல்லது ஏதேனும் மாற்றம் பெற்ற வாடிக்கையாளர் சாதாரண வாடிக்கையாளராக உங்கள் பட்டியலில் இருப்பார்.

:::note Take back out உரிமையாளருக்கு மட்டுமே தெரியும்
இம்போர்ட்டைத் திரும்ப எடுத்தால் வாடிக்கையாளர்கள் டெலீட் ஆவார்கள்; எனவே இதை உரிமையாளர் மட்டுமே செய்ய முடியும்.
:::

## பொதுவான சிக்கல்கள்
