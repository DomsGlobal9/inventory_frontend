## ಪ್ರಾಡಕ್ಟ್‌ಗಳು

| ಪದ | ಅರ್ಥ |
|---|---|
| **Product** | ನೀವು ಮಾರುವ ಒಂದು ವಸ್ತು (ಪ್ರಾಡಕ್ಟ್), ಉದಾಹರಣೆಗೆ *Cotton Kurti*. |
| **Variant** | ಒಂದು ಪ್ರಾಡಕ್ಟ್‌ನ ಒಂದು ಸೈಜ್ ಮತ್ತು ಬಣ್ಣ (ವೇರಿಯಂಟ್), ಉದಾಹರಣೆಗೆ *Cotton Kurti, Blue, M*. ಸ್ಟಾಕ್ ಅನ್ನು ಪ್ರತಿ ವೇರಿಯಂಟ್‌ಗೆ ಎಣಿಸಲಾಗುತ್ತದೆ. |
| **SKU** | ವೇರಿಯಂಟ್‌ನ ಚಿಕ್ಕ ಕೋಡ್, ಉದಾಹರಣೆಗೆ *KUR-COT-BLU-M*. ನಿಮ್ಮ ಅಂಗಡಿಯಲ್ಲಿ ಇದು ಒಂದೇ ಒಂದು ಇರುತ್ತದೆ, ಪುನರಾವರ್ತನೆ ಆಗುವುದಿಲ್ಲ. |
| **Barcode** | ಬೆಲೆ ಚೀಟಿಯ ಮೇಲೆ ಗೆರೆಗಳಾಗಿ ಪ್ರಿಂಟ್ ಆದ ಸಂಖ್ಯೆ (ಬಾರ್‌ಕೋಡ್). ಅದನ್ನು ಸ್ಕ್ಯಾನ್ ಮಾಡಿದರೆ ವೇರಿಯಂಟ್ ಸಿಗುತ್ತದೆ. |
| **Department** | ಪ್ರಾಡಕ್ಟ್ ಯಾರಿಗಾಗಿ: *Women*, *Men*, *Kids* ಅಥವಾ *Unisex* (ಡಿಪಾರ್ಟ್‌ಮೆಂಟ್). ಪ್ರಾಡಕ್ಟ್ ಸೇರಿಸುವಾಗ ನೀವು ಆರಿಸುವ **Product Category** ಇದೇ. ಒಂದು ಆಫರ್ ಇಡೀ ಡಿಪಾರ್ಟ್‌ಮೆಂಟ್‌ಗಳನ್ನು ಸೇರಿಸಿಕೊಳ್ಳಬಹುದು ಅಥವಾ ಬಿಟ್ಟುಬಿಡಬಹುದು. |
| **Barcode scanner** | ಬಾರ್‌ಕೋಡ್ ಅಥವಾ ಕ್ಯೂಆರ್ ಕೋಡ್ ಓದಿ, ನೀವು ಕ್ಲಿಕ್ ಮಾಡಿದ ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಟೈಪ್ ಮಾಡಿ, ನಂತರ Enter ಒತ್ತುವ USB ಅಥವಾ Bluetooth ಗನ್ (ಸ್ಕ್ಯಾನರ್). [ಬಾರ್‌ಕೋಡ್ ಸ್ಕ್ಯಾನರ್ ಬಳಸಿ](/help/start/barcode-scanner) ನೋಡಿ. |
| **Draft** | ಸೇವ್ ಆಗಿರುವ, ಆದರೆ ಇನ್ನೂ ಮಾರಾಟಕ್ಕೆ ಇಲ್ಲದ ಪ್ರಾಡಕ್ಟ್ (ಡ್ರಾಫ್ಟ್). |
| **Published** | ಸಿದ್ಧವಾಗಿರುವ ಮತ್ತು ಮಾರಾಟಕ್ಕೆ ಇರುವ ಪ್ರಾಡಕ್ಟ್ (ಪಬ್ಲಿಷ್ ಆಗಿದೆ). |
| **Archived** | ನೀವು ಈಗ ಮಾರದ ಪ್ರಾಡಕ್ಟ್, ಅದರ ಇತಿಹಾಸಕ್ಕಾಗಿ ಇಟ್ಟುಕೊಂಡಿದ್ದು (ಆರ್ಕೈವ್). |
| **You pay / Cost** | ಒಂದು ಪೀಸ್‌ಗೆ ನಿಮಗೆ ಆದ ಖರ್ಚು. ಖರ್ಚು ನೋಡಲು ಅನುಮತಿ ಇರುವವರಿಗೆ ಮಾತ್ರ ಇದು ಕಾಣುತ್ತದೆ. |
| **You sell at** | ಮಾರಾಟದ ಬೆಲೆ. |

## ಸ್ಟಾಕ್

| ಪದ | ಅರ್ಥ |
|---|---|
| **Store / Location** | ಸ್ಟಾಕ್ ಇರುವ ಜಾಗ: ಅಂಗಡಿ, ಗೋಡೌನ್, ವೇರ್‌ಹೌಸ್. ನೀವು ಕೆಲಸ ಮಾಡುವ ಜಾಗವನ್ನು ಸ್ಕ್ರೀನ್‌ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ ಆರಿಸಿ. |
| **Stock** | ಒಂದು ಸ್ಟೋರ್‌ನಲ್ಲಿ ಈಗ ಎಷ್ಟು ಪೀಸ್‌ಗಳಿವೆ. |
| **Godown** | ScaleEzy ಯಲ್ಲಿ ತನ್ನದೇ ಸ್ಟೋರ್ ಆಗಿ ಇಟ್ಟಿರುವ ಸ್ಟೋರ್ ರೂಮ್ ಅಥವಾ ವೇರ್‌ಹೌಸ್ (ಗೋಡೌನ್). ಅದಕ್ಕೆ ತನ್ನದೇ ಸ್ಟಾಕ್, ಶೆಲ್ಫ್‌ಗಳು ಮತ್ತು ಅಲರ್ಟ್‌ಗಳು ಇರುತ್ತವೆ. [ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ಸ್ಟೋರ್‌ಗಳೊಂದಿಗೆ ಕೆಲಸ ಮಾಡುವುದು](/help/start/more-than-one-store) ನೋಡಿ. |
| **Reorder level** | ಸ್ಟಾಕ್ ಈ ಸಂಖ್ಯೆಗೆ ಇಳಿದಾಗ, ನಿಮಗೆ ಕಡಿಮೆ ಸ್ಟಾಕ್ ಅಲರ್ಟ್ ಬರುತ್ತದೆ (ರೀಆರ್ಡರ್ ಲೆವೆಲ್). |
| **Low stock / Out of stock** | ರೀಆರ್ಡರ್ ಲೆವೆಲ್‌ಗೆ ಸಮ ಅಥವಾ ಅದಕ್ಕಿಂತ ಕಡಿಮೆ / ಒಂದೂ ಉಳಿದಿಲ್ಲ. |
| **Receive / Stock in** | ಒಳಗೆ ಬರುವ ಸ್ಟಾಕ್. ನಿಮ್ಮ ಸ್ಟಾಕ್ ಹೆಚ್ಚುತ್ತದೆ. |
| **Issue / Stock out** | ಮಾರಾಟವಲ್ಲದೆ ಹೊರಗೆ ಹೋಗುವ ಸ್ಟಾಕ್: ಹಾಳಾದದ್ದು, ಸ್ಯಾಂಪಲ್, ಸಪ್ಲೈಯರ್‌ಗೆ ವಾಪಸ್ ಕಳುಹಿಸಿದ್ದು. |
| **Adjust** | ನಿಜವಾಗಿ ಎಷ್ಟಿದೆ ಎಂದು ಎಣಿಸಿದ ನಂತರ ಸಂಖ್ಯೆಯನ್ನು ಸರಿಪಡಿಸುವುದು. |
| **Ledger** | ಪ್ರತಿ ಸ್ಟಾಕ್ ಬದಲಾವಣೆಯ ಪೂರ್ತಿ ಇತಿಹಾಸ, ಯಾರು ಮಾಡಿದರು ಮತ್ತು ಯಾವಾಗ (ಲೆಡ್ಜರ್). ಇದರಲ್ಲಿ ಯಾವುದೂ ಎಂದಿಗೂ ಅಳಿಸಿ ಹೋಗುವುದಿಲ್ಲ. |
| **Stock count (audit)** | ಒಂದು ಸ್ಟೋರ್‌ನಲ್ಲಿರುವ ಎಲ್ಲವನ್ನೂ ಎಣಿಸಿ, ವ್ಯತ್ಯಾಸಗಳನ್ನು ಒಂದೇ ಬಾರಿಗೆ ಸರಿಪಡಿಸುವುದು (ಸ್ಟಾಕ್ ಎಣಿಕೆ). |
| **Transfer** | ನಿಮ್ಮ ಒಂದು ಸ್ಟೋರ್‌ನಿಂದ ಇನ್ನೊಂದಕ್ಕೆ ಸ್ಟಾಕ್ ಸಾಗಿಸುವುದು (ಟ್ರಾನ್ಸ್‌ಫರ್). |
| **Dead stock** | ತುಂಬಾ ಸಮಯದಿಂದ ಮಾರಾಟವಾಗದ ಸ್ಟಾಕ್. |

## ರ್ಯಾಕ್ ಮತ್ತು ಶೆಲ್ಫ್‌ಗಳು

| ಪದ | ಅರ್ಥ |
|---|---|
| **Shelf address** | ಶೆಲ್ಫ್ ಮೇಲಿನ ಹೆಸರು, ಉದಾಹರಣೆಗೆ *FLOOR-C1-1*: ಜಾಗ FLOOR, ಕಪಾಟು C1, ಶೆಲ್ಫ್ 1. |
| **Label** | ಶೆಲ್ಫ್ ಮೇಲಿನ ಸ್ಟಿಕ್ಕರ್, ಅದರ ಅಡ್ರೆಸ್ ಮತ್ತು ಸ್ಕ್ಯಾನ್ ಮಾಡಲು ಕ್ಯೂಆರ್ ಕೋಡ್ ಜೊತೆಗೆ (ಲೇಬಲ್). |
| **Shop floor** | ಗ್ರಾಹಕರು ಸಾಮಾನು ನೋಡಿ ಆರಿಸುವ ಶೆಲ್ಫ್‌ಗಳು. ಕೌಂಟರ್ ಮಾರಾಟ ಮೊದಲು ಇವುಗಳಿಂದಲೇ ತೆಗೆಯುತ್ತದೆ. |
| **Back room** | ಸ್ಟೋರ್ ರೂಮ್ ಅಥವಾ ಗೋಡೌನ್ ಶೆಲ್ಫ್‌ಗಳು, ಗ್ರಾಹಕರಿಗೆ ಕಾಣದ ಜಾಗ. |
| **Not shelved** | ಸ್ಟೋರ್‌ನಲ್ಲಿ ಇರುವ, ಆದರೆ ಇನ್ನೂ ಯಾವ ಶೆಲ್ಫ್‌ನಲ್ಲೂ ಇಡದ ಪೀಸ್‌ಗಳು. ಶೆಲ್ಫ್‌ಗಳು + Not shelved = ನಿಮ್ಮ ಸ್ಟಾಕ್. |
| **Put away** | ಪೀಸ್‌ಗಳನ್ನು ಶೆಲ್ಫ್‌ನಲ್ಲಿ ಇಟ್ಟು ಶೆಲ್ಫ್ ಲೇಬಲ್ ಸ್ಕ್ಯಾನ್ ಮಾಡುವುದು. |
| **Pick** | ಆರ್ಡರ್‌ಗಳಿಗೆ ಬೇಕಾದ ಪೀಸ್‌ಗಳನ್ನು ಶೆಲ್ಫ್‌ಗಳಿಂದ ಹೋಗಿ ತೆಗೆದುಕೊಳ್ಳುವುದು. |
| **Shelf issue** | ಲೆಕ್ಕ ಸರಿಹೊಂದದ ವಿಷಯ, ಉದಾಹರಣೆಗೆ ಬ್ಯಾಕ್ ರೂಮ್‌ನಿಂದ ಮಾರಾಟವಾದ ಪೀಸ್, ಅಥವಾ ನಿರೀಕ್ಷೆಗಿಂತ ಕಡಿಮೆ ಬಂದ ಎಣಿಕೆ. ಮ್ಯಾನೇಜರ್ ಅದನ್ನು ಪರಿಶೀಲಿಸಿ ಬಗೆಹರಿದಿದೆ ಎಂದು ಗುರುತಿಸುತ್ತಾರೆ. |

## ಖರೀದಿ

| ಪದ | ಅರ್ಥ |
|---|---|
| **Supplier** | ನೀವು ಯಾರಿಂದ ಖರೀದಿಸುತ್ತೀರೋ ಅವರು (ಸಪ್ಲೈಯರ್). |
| **Purchase order (PO)** | ಸಪ್ಲೈಯರ್‌ಗೆ ನೀವು ಆರ್ಡರ್ ಮಾಡುವ ಸಾಮಾನುಗಳ ಪಟ್ಟಿ, ಬೆಲೆಗಳ ಜೊತೆಗೆ (ಖರೀದಿ ಆರ್ಡರ್). |
| **Sent** | ಖರೀದಿ ಆರ್ಡರ್ ಸಪ್ಲೈಯರ್‌ಗೆ ಹೋಗಿದೆ, ನೀವು ಸಾಮಾನಿಗಾಗಿ ಕಾಯುತ್ತಿದ್ದೀರಿ. |
| **Partly received** | ಆರ್ಡರ್‌ನ ಸ್ವಲ್ಪ ಭಾಗ ಬಂದಿದೆ, ಎಲ್ಲವೂ ಅಲ್ಲ. |
| **GRN (Goods Receipt)** | ನೀವು ಸ್ವೀಕರಿಸಿದ ಡೆಲಿವರಿಯ ದಾಖಲೆ: ಏನು ಬಂತು, ಯಾರು ಪರಿಶೀಲಿಸಿದರು, ಸಪ್ಲೈಯರ್‌ನ ಇನ್‌ವಾಯ್ಸ್ ಸಂಖ್ಯೆ. |

## ಮಾರಾಟ

| ಪದ | ಅರ್ಥ |
|---|---|
| **Counter sale** | ನಿಮ್ಮ ಅಂಗಡಿಯಲ್ಲಿ ನಿಂತಿರುವ ಗ್ರಾಹಕರಿಗೆ **New sale** ಮೂಲಕ ಮಾಡುವ ಮಾರಾಟ (ಕೌಂಟರ್ ಮಾರಾಟ). |
| **Order** | ಯಾವುದೇ ಮಾರಾಟ: ಕೌಂಟರ್‌ನಲ್ಲಿ, ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ ಅಥವಾ Shopify ನಿಂದ (ಆರ್ಡರ್). |
| **Confirmed** | ನೀವು ಒಪ್ಪಿಕೊಂಡ ಆರ್ಡರ್. ಅದರ ಸ್ಟಾಕ್ ಅನ್ನು ಅದಕ್ಕಾಗಿ ತೆಗೆದಿಡಲಾಗುತ್ತದೆ. |
| **Reserved (held)** | ಕನ್ಫರ್ಮ್ ಆದ ಆರ್ಡರ್‌ಗಾಗಿ ತೆಗೆದಿಟ್ಟ ಪೀಸ್‌ಗಳು (ರಿಸರ್ವ್). ಅವು ಇನ್ನೂ ಸ್ಟೋರ್‌ನಲ್ಲೇ ಇರುತ್ತವೆ, ಆದರೆ ಬೇರೆ ಯಾರೂ ಅವುಗಳನ್ನು ಮಾರಲು ಆಗುವುದಿಲ್ಲ. |
| **Dispatch / Send out** | ಪೀಸ್‌ಗಳನ್ನು ಕೈಗೆ ಕೊಡುವುದು ಅಥವಾ ಕಳುಹಿಸುವುದು. ಆನ್‌ಲೈನ್ ಆರ್ಡರ್‌ಗೆ ಸ್ಟಾಕ್ ಕಡಿಮೆಯಾಗುವುದು ಆಗಲೇ. |
| **Return** | ಗ್ರಾಹಕರು ಹಿಂದಿರುಗಿಸುವ ಪೀಸ್‌ಗಳು (ರಿಟರ್ನ್). ಅವುಗಳನ್ನು ಪರಿಶೀಲಿಸಿ, ಮತ್ತೆ ಸ್ಟಾಕ್‌ಗೆ ಸೇರಿಸಲಾಗುತ್ತದೆ ಅಥವಾ ಹಾಳಾಗಿದೆ ಎಂದು ಗುರುತಿಸಲಾಗುತ್ತದೆ. |
| **Offer** | ನೀವು ಒಮ್ಮೆ ಸೆಟ್ ಮಾಡುವ ಡಿಸ್ಕೌಂಟ್ (ಆಫರ್). ಇದು ಕೌಂಟರ್‌ನಲ್ಲಿ, ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ ಮತ್ತು Shopify ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ. |
| **Customer group** | ಕೆಲವು ಗ್ರಾಹಕರಿಗೆ ಅವರ ಪುಟದಲ್ಲಿ ನೀವು ಕೊಡುವ *VIP* ಅಥವಾ *Wholesale* ನಂತಹ ಹೆಸರು (ಗ್ರಾಹಕರ ಗುಂಪು). ಒಂದು ಆಫರ್ ಕೆಲವು ಗುಂಪುಗಳಿಗೆ ಮಾತ್ರ ಇರಬಹುದು. |
| **Discount by hand** | ಕೌಂಟರ್‌ನಲ್ಲಿ ಸೇಲ್ಸ್‌ಮನ್ ಕಾರಣ ಬರೆದು ಕೊಡುವ ಡಿಸ್ಕೌಂಟ್, ಮಾಲೀಕರು ಇಟ್ಟ ಮಿತಿಯವರೆಗೆ. |
| **Day Book** | ಒಂದು ದಿನದ ಸಾರಾಂಶ: ಏನು ಬಂತು, ಏನು ಹೋಯಿತು, ಮಾರಾಟ ಮತ್ತು ಲಾಭ. |

## ನಿಮ್ಮ ತಂಡ

| ಪದ | ಅರ್ಥ |
|---|---|
| **Role** | ಒಂದು ಕೆಲಸ, ಉದಾಹರಣೆಗೆ Sales ಅಥವಾ Warehouse (ರೋಲ್). ಒಬ್ಬ ವ್ಯಕ್ತಿ ಏನು ನೋಡಬಹುದು ಮತ್ತು ಏನು ಮಾಡಬಹುದು ಎಂದು ಇದು ನಿರ್ಧರಿಸುತ್ತದೆ. |
| **Permission** | ಒಂದು ರೋಲ್‌ಗೆ ಮಾಡಲು ಅನುಮತಿ ಇರುವ ಒಂದು ಕೆಲಸ, ಉದಾಹರಣೆಗೆ *see what you paid* (ನೀವು ಕೊಟ್ಟ ಬೆಲೆ ನೋಡುವುದು). |
| **Owner (Super Admin)** | ಅಂಗಡಿಯ ಮಾಲೀಕರು. ಎಲ್ಲವನ್ನೂ ಮಾಡಬಹುದು, ಮತ್ತು ಈ ರೋಲ್ ಅನ್ನು ಬದಲಿಸಲು ಆಗುವುದಿಲ್ಲ. |
