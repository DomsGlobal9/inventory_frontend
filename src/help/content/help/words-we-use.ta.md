## பொருட்கள்

| வார்த்தை | அர்த்தம் |
|---|---|
| **Product** | நீங்கள் விற்கும் ஒரு பொருள், உதாரணமாக *Cotton Kurti*. |
| **Variant** | ஒரு பொருளின் ஒரு சைஸ் மற்றும் கலர், உதாரணமாக *Cotton Kurti, Blue, M*. ஸ்டாக் ஒவ்வொரு வேரியண்டுக்கும் தனியாக எண்ணப்படும். |
| **SKU** | ஒரு வேரியண்டின் சிறிய கோடு, உதாரணமாக *KUR-COT-BLU-M*. உங்கள் கடையில் ஒவ்வொன்றுக்கும் தனி. |
| **Barcode** | விலைச் சீட்டில் கோடுகளாகப் பிரிண்ட் ஆன நம்பர். ஸ்கேன் செய்தால் வேரியண்ட் கிடைக்கும். |
| **Department** | பொருள் யாருக்கானது: *Women*, *Men*, *Kids* அல்லது *Unisex*. பொருளைச் சேர்க்கும்போது நீங்கள் தேர்ந்தெடுக்கும் **Product Category** இதுதான். ஒரு ஆஃபர் முழு டிபார்ட்மெண்ட்களையும் சேர்க்கலாம், அல்லது விட்டுவிடலாம். |
| **Barcode scanner** | பார்கோடு அல்லது QR கோடைப் படித்து, நீங்கள் கிளிக் செய்த பெட்டியில் டைப் செய்து, பிறகு Enter அழுத்தும் USB அல்லது Bluetooth ஸ்கேன் கன். [பார்கோடு ஸ்கேனரைப் பயன்படுத்துதல்](/help/start/barcode-scanner) பாருங்கள். |
| **Draft** | சேமிக்கப்பட்ட, ஆனால் இன்னும் விற்பனைக்கு வராத பொருள். |
| **Published** | தயாராக உள்ள, விற்பனைக்கு உள்ள பொருள். |
| **Archived** | நீங்கள் இனி விற்காத பொருள், அதன் பழைய பதிவுகளுக்காக வைக்கப்பட்டது. |
| **You pay / Cost** | ஒரு பீஸ் உங்களுக்கு என்ன விலைக்கு வந்தது. காஸ்ட் பார்க்க அனுமதி உள்ளவர்கள் மட்டுமே இதைப் பார்ப்பார்கள். |
| **You sell at** | விற்கும் விலை. |

## ஸ்டாக்

| வார்த்தை | அர்த்தம் |
|---|---|
| **Store / Location** | ஸ்டாக் வைக்கும் இடம்: கடை, குடோன், வேர்ஹவுஸ். நீங்கள் வேலை செய்யும் இடத்தைத் திரையின் மேலே தேர்ந்தெடுங்கள். |
| **Stock** | ஒரு ஸ்டோரில் இப்போது எத்தனை பீஸ் உள்ளது. |
| **Godown** | ScaleEzy-இல் தனி ஸ்டோராக வைக்கப்படும் ஸ்டோர் ரூம் அல்லது வேர்ஹவுஸ். அதற்குத் தனி ஸ்டாக், ஷெல்ஃப்கள், அலர்ட்கள் உண்டு. [ஒன்றுக்கு மேற்பட்ட ஸ்டோர்களுடன் வேலை செய்தல்](/help/start/more-than-one-store) பாருங்கள். |
| **Reorder level** | ஸ்டாக் இந்த எண்ணுக்கு வந்தால், உங்களுக்கு லோ ஸ்டாக் அலர்ட் வரும். |
| **Low stock / Out of stock** | ரீஆர்டர் லெவலிலோ அதற்குக் கீழோ உள்ளது / எதுவும் மீதி இல்லை. |
| **Receive / Stock in** | உள்ளே வரும் ஸ்டாக். உங்கள் ஸ்டாக் கூடும். |
| **Issue / Stock out** | விற்பனை அல்லாமல் வெளியே போகும் ஸ்டாக்: சேதம், சாம்பிள், சப்ளையருக்குத் திருப்பி அனுப்பியது. |
| **Adjust** | உண்மையில் இருப்பதை எண்ணிய பிறகு எண்ணைச் சரிசெய்தல். |
| **Ledger** | ஒவ்வொரு ஸ்டாக் மாற்றத்தின் முழு ஹிஸ்டரி, யார் செய்தார், எப்போது. இதில் எதுவும் ஒருபோதும் அழித்து மாற்றி எழுதப்படாது. |
| **Stock count (audit)** | ஒரு ஸ்டோரில் உள்ள எல்லாவற்றையும் எண்ணி, வித்தியாசங்களை ஒரே முறையில் சரிசெய்தல். |
| **Transfer** | உங்கள் ஒரு ஸ்டோரிலிருந்து இன்னொரு ஸ்டோருக்கு ஸ்டாக்கை மாற்றுதல். |
| **Dead stock** | நீண்ட காலமாக விற்காத ஸ்டாக். |

## ரேக்குகள் & ஷெல்ஃப்கள்

| வார்த்தை | அர்த்தம் |
|---|---|
| **Shelf address** | ஷெல்ஃபில் உள்ள பெயர், உதாரணமாக *FLOOR-C1-1*: பகுதி FLOOR, அலமாரி C1, ஷெல்ஃப் 1. |
| **Label** | ஷெல்ஃபின் முகவரியும் ஸ்கேன் செய்ய QR கோடும் உள்ள ஸ்டிக்கர். |
| **Shop floor** | வாடிக்கையாளர்கள் பொருட்கள் பார்க்கும் இடத்தில் உள்ள ஷெல்ஃப்கள். கவுண்டர் விற்பனை முதலில் இவற்றிலிருந்து எடுக்கும். |
| **Back room** | ஸ்டோர் ரூம் அல்லது குடோன் ஷெல்ஃப்கள், வாடிக்கையாளர்கள் கண்ணில் படாதவை. |
| **Not shelved** | ஸ்டோரில் உள்ள, ஆனால் இன்னும் எந்த ஷெல்ஃபிலும் வைக்காத பீஸ்கள். ஷெல்ஃப்கள் + Not shelved = உங்கள் ஸ்டாக். |
| **Put away** | பீஸ்களை ஷெல்ஃபில் வைத்து, ஷெல்ஃப் லேபிளை ஸ்கேன் செய்தல். |
| **Pick** | ஆர்டர்களுக்கான பீஸ்களை எடுக்க ஷெல்ஃப்களுக்கு நடந்து போதல். |
| **Shelf issue** | கணக்கு சரியாக வராத ஏதோ ஒன்று, உதாரணமாக பேக் ரூமிலிருந்து விற்ற பீஸ், அல்லது எதிர்பார்த்ததைவிடக் குறைவான எண்ணிக்கை. மேலாளர் அதைச் சரிபார்த்து resolved என்று குறிப்பார். |

## வாங்குதல்

| வார்த்தை | அர்த்தம் |
|---|---|
| **Supplier** | நீங்கள் யாரிடம் வாங்குகிறீர்களோ அவர். |
| **Purchase order (PO)** | ஒரு சப்ளையரிடம் நீங்கள் ஆர்டர் செய்பவற்றின் லிஸ்ட், விலைகளுடன். |
| **Sent** | பர்ச்சேஸ் ஆர்டர் சப்ளையருக்குப் போய்விட்டது, நீங்கள் பொருட்களுக்காகக் காத்திருக்கிறீர்கள். |
| **Partly received** | ஆர்டரில் சில வந்துவிட்டன, எல்லாம் இல்லை. |
| **GRN (Goods Receipt)** | நீங்கள் பெற்ற டெலிவரியின் பதிவு: என்ன வந்தது, யார் சரிபார்த்தார், சப்ளையரின் இன்வாய்ஸ் நம்பர். |

## விற்பனை

| வார்த்தை | அர்த்தம் |
|---|---|
| **Counter sale** | உங்கள் கடையில் நிற்கும் வாடிக்கையாளருக்கு **New sale** மூலம் செய்யும் விற்பனை. |
| **Order** | எந்த விற்பனையும்: கவுண்டரில், ஆன்லைனில் அல்லது Shopify-இலிருந்து. |
| **Confirmed** | நீங்கள் ஏற்றுக்கொண்ட ஆர்டர். அதற்கான ஸ்டாக் ஒதுக்கி வைக்கப்படும். |
| **Reserved (held)** | உறுதிசெய்த ஆர்டருக்காக ஒதுக்கி வைத்த பீஸ்கள். அவை இன்னும் ஸ்டோரில்தான் இருக்கும், ஆனால் வேறு யாரும் அவற்றை விற்க முடியாது. |
| **Dispatch / Send out** | பீஸ்களைக் கையில் கொடுத்தல் அல்லது அனுப்புதல். ஆன்லைன் ஆர்டருக்கு இப்போதுதான் ஸ்டாக் குறையும். |
| **Return** | வாடிக்கையாளர் திருப்பிக் கொண்டுவரும் பீஸ்கள். சரிபார்த்த பிறகு மீண்டும் ஸ்டாக்கில் சேரும், அல்லது சேதம் என்று குறிக்கப்படும். |
| **Offer** | நீங்கள் ஒருமுறை அமைக்கும் டிஸ்கவுண்ட், கவுண்டரிலும் ஆன்லைனிலும் Shopify-இலும் வேலை செய்யும். |
| **Customer group** | சில வாடிக்கையாளர்களின் பக்கத்தில் நீங்கள் கொடுக்கும் *VIP* அல்லது *Wholesale* போன்ற ஒரு பெயர். ஒரு ஆஃபரை சில குரூப்களுக்கு மட்டும் வைக்கலாம். |
| **Discount by hand** | உரிமையாளர் வைத்த லிமிட் வரை, காரணத்துடன், சேல்ஸ்மேன் கவுண்டரில் கொடுக்கும் டிஸ்கவுண்ட். |
| **Day Book** | ஒரு நாளின் சுருக்கம்: என்ன வந்தது, என்ன போனது, விற்பனை மற்றும் லாபம். |

## உங்கள் டீம்

| வார்த்தை | அர்த்தம் |
|---|---|
| **Role** | Sales அல்லது Warehouse போன்ற ஒரு வேலை. ஒருவர் என்ன பார்க்கலாம், என்ன செய்யலாம் என்பதை இது முடிவு செய்யும். |
| **Permission** | ஒரு ரோல் செய்ய அனுமதிக்கப்பட்ட ஒரு விஷயம், உதாரணமாக *நீங்கள் கொடுத்த விலையைப் பார்த்தல்*. |
| **Owner (Super Admin)** | கடை உரிமையாளர். எல்லாவற்றையும் செய்யலாம், இந்த ரோலை மாற்ற முடியாது. |
