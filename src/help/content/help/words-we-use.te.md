## ప్రొడక్ట్‌లు

| పదం | దాని అర్థం |
|---|---|
| **Product** | ప్రొడక్ట్: మీరు అమ్మే ఒక వస్తువు, ఉదాహరణకు *Cotton Kurti*. |
| **Variant** | వేరియంట్: ఒక ప్రొడక్ట్‌లో ఒక సైజు, ఒక రంగు, ఉదాహరణకు *Cotton Kurti, Blue, M*. స్టాక్ ప్రతి వేరియంట్‌కు విడిగా లెక్క పెడతారు. |
| **SKU** | ఒక వేరియంట్ చిన్న కోడ్, ఉదాహరణకు *KUR-COT-BLU-M*. మీ షాప్‌లో ఒక్కో దానికి ఒక్కటే ఉంటుంది, రెండు వస్తువులకు ఒకటే SKU ఉండదు. |
| **Barcode** | బార్‌కోడ్: ధర ట్యాగ్ మీద గీతలుగా ప్రింట్ చేసిన నంబర్. దాన్ని స్కాన్ చేస్తే వేరియంట్ దొరుకుతుంది. |
| **Department** | డిపార్ట్‌మెంట్: ప్రొడక్ట్ ఎవరి కోసం: *Women*, *Men*, *Kids* లేదా *Unisex*. ప్రొడక్ట్ యాడ్ చేసేటప్పుడు మీరు ఎంచుకునే **Product Category** ఇదే. ఒక ఆఫర్ మొత్తం డిపార్ట్‌మెంట్‌లకు వర్తించవచ్చు, లేదా వాటిని వదిలేయవచ్చు. |
| **Barcode scanner** | బార్‌కోడ్ స్కానర్: బార్‌కోడ్ లేదా QR కోడ్ చదివి, మీరు నొక్కిన బాక్స్‌లో టైప్ చేసి, Enter నొక్కే USB లేదా Bluetooth గన్. [బార్‌కోడ్ స్కానర్ వాడండి](/help/start/barcode-scanner) చూడండి. |
| **Draft** | డ్రాఫ్ట్: సేవ్ చేసిన ప్రొడక్ట్, కానీ ఇంకా అమ్మకానికి లేదు. |
| **Published** | పబ్లిష్ అయిన ప్రొడక్ట్: సిద్ధంగా ఉంది, అమ్మకానికి ఉంది. |
| **Archived** | ఆర్కైవ్ చేసిన ప్రొడక్ట్: మీరు ఇక అమ్మనిది, దాని హిస్టరీ కోసం ఉంచుకున్నది. |
| **You pay / Cost** | ఖర్చు / కొన్న ధర: ఒక పీస్ మీకు ఎంతకు పడింది. ఖర్చులు చూసే అనుమతి ఉన్నవారికి మాత్రమే ఇది కనిపిస్తుంది. |
| **You sell at** | అమ్మే ధర. |

## స్టాక్

| పదం | దాని అర్థం |
|---|---|
| **Store / Location** | స్టోర్: స్టాక్ ఉంచే చోటు, అంటే షాప్, గోడౌన్, వేర్‌హౌస్. మీరు పని చేసే స్టోర్‌ను స్క్రీన్ పైన ఎంచుకోండి. |
| **Stock** | స్టాక్: ఇప్పుడు ఒక స్టోర్‌లో ఎన్ని పీస్‌లు ఉన్నాయి. |
| **Godown** | గోడౌన్: ScaleEzy లో సొంత స్టోర్‌గా ఉంచిన స్టోర్ రూమ్ లేదా వేర్‌హౌస్. దానికి సొంత స్టాక్, షెల్ఫ్‌లు, అలర్ట్‌లు ఉంటాయి. [ఒకటి కంటే ఎక్కువ స్టోర్‌లతో పని చేయడం](/help/start/more-than-one-store) చూడండి. |
| **Reorder level** | రీఆర్డర్ లెవెల్: స్టాక్ ఈ నంబర్‌కు తగ్గినప్పుడు, మీకు తక్కువ స్టాక్ అలర్ట్ వస్తుంది. |
| **Low stock / Out of stock** | తక్కువ స్టాక్: రీఆర్డర్ లెవెల్ దగ్గర లేదా దానికంటే తక్కువ. స్టాక్ అయిపోయింది: ఒక్కటీ మిగలలేదు. |
| **Receive / Stock in** | రిసీవ్: లోపలికి వస్తున్న స్టాక్. మీ స్టాక్ పెరుగుతుంది. |
| **Issue / Stock out** | బయటికి వెళ్తున్న స్టాక్, కానీ సేల్ కాదు: పాడైనవి, శాంపిల్, సప్లయర్‌కు తిరిగి పంపినవి. |
| **Adjust** | స్టాక్ సరిచేయండి: నిజంగా ఎన్ని ఉన్నాయో లెక్క పెట్టిన తర్వాత నంబర్ సరిచేయడం. |
| **Ledger** | స్టాక్ హిస్టరీ: స్టాక్‌లో ప్రతి మార్పు, ఎవరు చేశారు, ఎప్పుడు చేశారు, అన్నీ పూర్తిగా. ఇందులో ఏదీ ఎప్పుడూ చెరిపివేయబడదు. |
| **Stock count (audit)** | స్టాక్ కౌంట్: ఒక స్టోర్‌లో ఉన్నదంతా లెక్క పెట్టి, తేడాలన్నీ ఒకేసారి సరిచేయడం. |
| **Transfer** | మీ ఒక స్టోర్ నుండి ఇంకో స్టోర్‌కు స్టాక్ మార్చడం. |
| **Dead stock** | చాలా కాలంగా అమ్ముడుపోని స్టాక్. |

## ర్యాక్‌లు, షెల్ఫ్‌లు

| పదం | దాని అర్థం |
|---|---|
| **Shelf address** | షెల్ఫ్ మీద ఉన్న పేరు, ఉదాహరణకు *FLOOR-C1-1*: ఏరియా FLOOR, అల్మారా C1, షెల్ఫ్ 1. |
| **Label** | లేబుల్: షెల్ఫ్ మీద అతికించే స్టిక్కర్. దాని మీద షెల్ఫ్ అడ్రస్, స్కాన్ చేయడానికి ఒక QR కోడ్ ఉంటాయి. |
| **Shop floor** | కస్టమర్లు చూసి కొనే చోట ఉన్న షెల్ఫ్‌లు. కౌంటర్ సేల్స్ ముందు ఈ షెల్ఫ్‌ల నుండే తీసుకుంటాయి. |
| **Back room** | స్టోర్ రూమ్ లేదా గోడౌన్ షెల్ఫ్‌లు, కస్టమర్లకు కనిపించవు. |
| **Not shelved** | స్టోర్‌లో ఉన్నాయి కానీ ఇంకా ఏ షెల్ఫ్‌లోనూ పెట్టని పీస్‌లు. షెల్ఫ్‌లు + Not shelved = మీ స్టాక్. |
| **Put away** | పీస్‌లను షెల్ఫ్‌లో పెట్టి, షెల్ఫ్ లేబుల్ స్కాన్ చేయడం. |
| **Pick** | పికింగ్: ఆర్డర్ల కోసం షెల్ఫ్‌ల దగ్గరికి వెళ్లి పీస్‌లు తీయడం. |
| **Shelf issue** | లెక్క సరిపోని విషయం, ఉదాహరణకు వెనుక రూమ్ నుండి అమ్మిన పీస్, లేదా అనుకున్నదానికంటే తక్కువ వచ్చిన కౌంట్. మేనేజర్ దాన్ని చెక్ చేసి పరిష్కారమైందని గుర్తిస్తారు. |

## కొనడం

| పదం | దాని అర్థం |
|---|---|
| **Supplier** | సప్లయర్: మీరు ఎవరి దగ్గర కొంటారో వారు. |
| **Purchase order (PO)** | పర్చేస్ ఆర్డర్: మీరు సప్లయర్‌కు ఆర్డర్ చేసే వస్తువుల లిస్ట్, ధరలతో. |
| **Sent** | పర్చేస్ ఆర్డర్ సప్లయర్‌కు వెళ్లింది, మీరు సరుకు కోసం ఎదురు చూస్తున్నారు. |
| **Partly received** | ఆర్డర్‌లో కొంత వచ్చింది, అంతా రాలేదు. |
| **GRN (Goods Receipt)** | మీరు రిసీవ్ చేసుకున్న డెలివరీ రికార్డ్: ఏమి వచ్చింది, ఎవరు చెక్ చేశారు, సప్లయర్ ఇన్వాయిస్ నంబర్. |

## అమ్మకం

| పదం | దాని అర్థం |
|---|---|
| **Counter sale** | కౌంటర్ సేల్: మీ షాప్‌లో నిలబడిన కస్టమర్‌కు **New sale** తో చేసే అమ్మకం. |
| **Order** | ఆర్డర్: ఏ అమ్మకమైనా, కౌంటర్‌లో, ఆన్‌లైన్‌లో లేదా Shopify నుండి. |
| **Confirmed** | మీరు ఒప్పుకున్న ఆర్డర్. దాని స్టాక్ దాని కోసం పక్కన పెట్టబడుతుంది. |
| **Reserved (held)** | కన్ఫర్మ్ అయిన ఆర్డర్ కోసం పక్కన పెట్టిన పీస్‌లు. అవి ఇంకా స్టోర్‌లోనే ఉంటాయి, కానీ ఇంకెవరూ వాటిని అమ్మలేరు. |
| **Dispatch / Send out** | పీస్‌లు చేతికి ఇవ్వడం లేదా పంపడం. ఆన్‌లైన్ ఆర్డర్‌కు స్టాక్ తగ్గేది అప్పుడే. |
| **Return** | రిటర్న్: కస్టమర్ తిరిగి తెచ్చిన పీస్‌లు. వాటిని చెక్ చేసి, మళ్లీ స్టాక్‌లోకి పెడతారు లేదా పాడైనవిగా గుర్తిస్తారు. |
| **Offer** | ఆఫర్: మీరు ఒక్కసారి సెట్ చేసే డిస్కౌంట్. కౌంటర్‌లో, ఆన్‌లైన్‌లో, Shopify లో పనిచేస్తుంది. |
| **Customer group** | కస్టమర్ గ్రూప్: కొంతమంది కస్టమర్లకు వారి పేజీలో మీరు ఇచ్చే *VIP* లేదా *Wholesale* లాంటి పేరు. ఒక ఆఫర్ కొన్ని గ్రూప్‌లకు మాత్రమే ఉండవచ్చు. |
| **Discount by hand** | చేత్తో డిస్కౌంట్: సేల్స్‌మ్యాన్ కౌంటర్‌లో ఒక కారణంతో ఇచ్చే డిస్కౌంట్, యజమాని పెట్టిన లిమిట్ వరకు. |
| **Day Book** | డే బుక్: ఒక రోజు సారాంశం, ఏమి వచ్చింది, ఏమి వెళ్లింది, సేల్స్, లాభం. |

## మీ టీమ్

| పదం | దాని అర్థం |
|---|---|
| **Role** | రోల్: ఒక పని, Sales లేదా Warehouse లాగా. ఒక వ్యక్తి ఏమి చూడగలరు, ఏమి చేయగలరు అనేది ఇది నిర్ణయిస్తుంది. |
| **Permission** | పర్మిషన్: ఒక రోల్ చేయడానికి అనుమతి ఉన్న ఒక పని, ఉదాహరణకు *see what you paid*. |
| **Owner (Super Admin)** | యజమాని: షాప్ ఓనర్. అన్నీ చేయగలరు, ఈ రోల్‌ను మార్చలేరు. |
