An **offer** is a discount rule, for example *10% off every saree until Deepavali*. You write it once. After that nobody at the counter has to remember it or type it in: ScaleEzy takes the money off for you.

## Where to find it

In the menu on the left, click [[1]] **Offers**. You see every offer your shop has.

- [[2]] **New offer** writes a new one. See [Create an offer](/help/offers/create-an-offer).
- [[3]] **Till rules** sets how much a cashier may take off by hand. See [Till rules](/help/offers/till-rules).
- [[4]] The buttons along the top show only offers that are running, starting later, drafts, paused, ended or retired. You can also search by name or code.
- [[5]] Each row says what the offer does, when it ends, how many times it was used and its status. The buttons on the right pause, edit, copy, put on Shopify and retire it.

## Who can do what

| Role | Offers |
|---|---|
| Owner, admin | Create, edit, start, pause, retire, make codes, put on Shopify, set till rules |
| Sales | See the offers, so they can tell customers. Take money off by hand, within the till rules |
| Inventory manager, stock room | See the offers only |

## What an offer is made of

Every offer answers four questions:

1. **The discount.** A percentage off, an amount off, or a set price. Off each item, or off the whole bill.
2. **Applies to.** Everything, or chosen products, types of garment (like Saree or Kurti), particular sizes and colours, or departments. You can leave some things out.
3. **Who gets it.** Everyone **automatically**, or only customers **with a code**. It can also need a minimum spend or number of items, or be only for some customer groups.
4. **When.** A start date, an optional last day, and if you like only certain days and hours.

## Where it comes off

- **At the till.** A running offer comes off by itself when you make a [New sale](/help/orders/new-sale). A code offer comes off when the code is typed in the **Offer code** box.
- **Online.** Orders from your online store get it too. Under **More options** you can make an offer till only or online only, or only for some stores.
- **On Shopify.** Shopify charges its own discounts, so you can put a copy of the offer there. See [Offers on Shopify](/help/offers/offers-on-shopify).

## The status of an offer

| Status | Meaning |
|---|---|
| **Draft** | Saved, but not running. Every new offer starts as a draft. |
| **Starts later** | Started, but its start date is still ahead. It begins by itself. |
| **Running** | Coming off right now. |
| **Paused** | Stopped for now. Start it again at any time. |
| **Ended** | Its last day has passed. |
| **Retired** | Finished for good. It cannot be started again, but you can copy it. |

## When two offers fit the same item

Each offer has a **priority**. When two offers want the same item, the higher number wins, and only the best single offer applies. To let offers add up, tick **Can combine with other offers** on them.

:::note Past bills never change
An order keeps the offer exactly as it was when the order was made. Editing, pausing or retiring an offer only changes future bills.
:::
