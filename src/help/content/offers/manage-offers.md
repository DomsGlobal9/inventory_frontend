Only the owner or an admin can pause, edit, copy or retire offers. Everyone who can see offers can open an offer's page.

## 1. The buttons on each offer

In **Offers**, each offer row has these buttons on the right:

1. [[1]] **Pause** (two bars) stops the offer for now.
2. [[2]] **Edit** opens the offer form.
3. [[3]] **Copy into a new draft** makes a copy, for example to run last Deepavali's sale again.
4. [[4]] **Shopify** opens its Shopify box. See [Offers on Shopify](/help/offers/offers-on-shopify).
5. [[5]] **Retire this offer** ends it for good.

![The row for Festive 10% off silk. Pause is marked 1, Edit 2, Copy into a new draft 3, Shopify 4 and Retire this offer 5.](1-list-buttons.webp "Point at a button to see its name.")

## 2. Pause and start again

Press **Pause**. The status becomes [[1]] **Paused** and the offer stops coming off straight away. The button changes to [[2]] **Start**. Press it to run the offer again.

![The same row after pausing. Paused is marked 1 and the start button is marked 2.](2-paused.webp "Pausing does not change the dates. If the last day has passed, it shows Ended instead.")

## 3. See how the offer did

Click the offer's name to open its page.

- [[1]] What it does, in one line. Under it: what it applies to, what it needs, where it sells, the dates and the limits.
- [[2]] **Times used**: how many orders got it.
- [[3]] **Discount given**: the money it took off in all.
- [[4]] **Sales with this offer**: the bill totals of those orders, after the discount.
- [[5]] **Customers**: how many different customers used it.

![The page for Festive 10% off silk. The line 10% off every Saree is marked 1, Times used 4 is marked 2, Discount given ₹3,500 is 3, Sales with this offer ₹40,030 is 4 and Customers 3 is 5.](3-offer-page.webp "Pause, Edit, copy, Shopify and Retire are also at the top of this page.")

## 4. Orders that used it

Scroll down. Each [[1]] order that got the offer is listed with the customer, the date, the bill and the discount. Click the order number to open it.

![Orders that used it: four orders. SO-000005 for Lakshmi Narayanan, Online, bill ₹11,210, discount ₹890, is marked 1.](4-orders-that-used-it.webp "Till means a counter sale. A cancelled order shows Given back instead of a discount.")

## 5. History

At the bottom, **History** shows when the offer was created and every change to its rule, who made it and why.

![History: Created on 17 Sept 2026 by Priya Reddy.](5-history.webp "Orders keep the version that priced them, so changing an offer never changes a past bill.")

## 6. Edit an offer

1. Press **Edit**, change what you need, as in [Create an offer](/help/offers/create-an-offer).
2. When editing, the form has [[1]] **Why the change? (optional)**. Write a short reason. It is kept in the history.
3. Press [[2]] **Save changes**.

![The bottom of the edit form. Why the change with Extended for the weekend is marked 1 and Save changes is marked 2.](6-edit-say-why.webp "A change to the name only is not added to the history. A change to the discount, the items or the dates is.")

## 7. Retire an offer

Retire an offer when it is finished for good. Press the archive box button, **Retire this offer**, then [[1]] **Retire offer**.

![The question Retire this offer? It says the offer will stop applying and cannot be started again, and orders that used it keep their prices. Retire offer is marked 1.](7-retire.webp "Press Cancel to keep it.")

A retired offer stays in the list under **Retired**, with all its results. To run it again, open it and press the copy button, **Copy into a new draft**. The copy is a new draft: check its dates, then start it.

## Common problems

:::faq "This offer has been archived. Copy it into a new one rather than changing it."
Retired offers cannot be edited or started. Open it and press **Copy into a new draft**.
:::

:::faq My change is not in the history
Only changes to the rule are recorded: the discount, what it applies to, who gets it, the dates and the limits. A new name alone is not.
:::

:::faq "Somebody changed this offer at the same moment."
Two people changed it at once. Refresh the page and check the offer before trying again.
:::

:::faq I don't see Pause, Edit or Retire
Only the owner or an admin can change offers. Everyone else can only look.
:::
