कोड वाला ऑफ़र तभी कटता है जब काउंटर पर **Offer code** बॉक्स में कोड टाइप किया जाए, या ऑनलाइन डाला जाए। सिर्फ़ मालिक या एडमिन कोड वाले ऑफ़र बना सकते हैं।

इस उदाहरण में हम **₹3,000 या उससे ज़्यादा के बिल पर, पूरे बिल से ₹500 कम** वाला ऑफ़र बनाते हैं। ऑफ़र को [ऑफ़र बनाएँ](/help/offers/create-an-offer) की तरह भरें, फिर:

## 1. With a code चुनें

**Who gets it** में:

1. [[1]] **With a code** दबाएँ।
2. अगर सब एक ही कोड इस्तेमाल करेंगे, जैसे पोस्टर पर लिखा कोड, तो [[2]] **One shared code** चुनें।
3. [[3]] कोड टाइप करें, जैसे *WELCOME500*।

![Who gets it। With a code पर 1, One shared code पर 2 और कोड WELCOME500 पर 3 का निशान है। कम से कम खरीद 3000 है।](1-one-shared-code.webp "साझा कोड जिसके पास भी है वह इसे इस्तेमाल कर सकता है, जितनी बार सीमाएँ इजाज़त दें।")

साझा कोड ऑफ़र सेव करके शुरू करते ही तैयार हो जाता है। आप सीधे स्टेप 5 पर जा सकते हैं।

## 2. या एक बार चलने वाले कोड चुनें

गिफ़्ट कार्ड या ग्राहकों की लिस्ट के लिए [[1]] **Single-use codes** दबाएँ। हर कोड सिर्फ़ एक बार चलता है।

![Who gets it में Single-use codes पर 1 का निशान है। नीचे लिखा है कि हर कोड एक बार चलता है, और कोड सेव करने के बाद ऑफ़र के पेज पर बनाएँ।](2-single-use-codes.webp "एक बार चलने वाले कोड सिर्फ़ आपके काउंटर और आपकी अपनी वेबसाइट पर चलते हैं। इन्हें Shopify पर नहीं डाल सकते।")

**Create offer** दबाएँ। ऑफ़र ड्राफ़्ट के रूप में सेव हो जाता है।

## 3. कोड बनाएँ

1. **Offers** में ऑफ़र का नाम दबाकर उसका पेज खोलें।
2. **Single-use codes** बॉक्स में [[1]] **Starts with** हर कोड का पहला शब्द है, जैसे WELCOME।
3. [[2]] **How many**: एक बार में 5,000 तक।
4. [[3]] **Make codes** दबाएँ।

![Single-use codes बॉक्स, अभी 0 बने हैं। Starts with WELCOME पर 1, How many 50 पर 2 और Make codes पर 3 का निशान है।](3-make-codes.webp "कोड WELCOME-7KQ2M9XR जैसे दिखते हैं। इनमें 0, O, 1, I या L कभी नहीं आते, ताकि कोई गलत न पढ़े।")

बाद में और चाहिए? इसी तरह एक और बैच बनाएँ।

## 4. कोड निकालें

- [[1]] गिनती बताती है कि कितने बने, कितने इस्तेमाल हुए और कितने बचे हैं।
- [[2]] **Copy unused** सारे बिना इस्तेमाल हुए कोड कॉपी करता है, हर लाइन में एक, ताकि आप उन्हें मैसेज या प्रिंट वाली फ़ाइल में पेस्ट कर सकें।
- [[3]] **CSV** सारे कोड स्प्रेडशीट के रूप में डाउनलोड करता है, साथ में यह भी कि कब और किस ऑर्डर पर इस्तेमाल हुआ।
- [[4]] **Unused** और **Used** से लिस्ट बदलती है।
- [[5]] **Find a code**: कोड का कुछ हिस्सा टाइप करके देखें कि वह इस्तेमाल हुआ या नहीं।

![कोड: 50 made, 0 used, 50 left पर 1, Copy unused पर 2, CSV पर 3, Unused और Used बटन पर 4 और Find a code पर 5 का निशान है। नीचे कोड की लिस्ट है।](4-your-codes.webp "इस्तेमाल हुए कोड के साथ वह ऑर्डर दिखता है जिस पर वह लगा। ऑर्डर खोलने के लिए उसे दबाएँ।")

## 5. ऑफ़र शुरू करें

ऑफ़र अभी भी [[1]] **Draft** है। उसके पेज के ऊपर [[2]] **Start** दबाएँ।

![Welcome gift 500 off ऑफ़र का पेज, ₹3,000 या उससे ज़्यादा के बिल पर एक बार चलने वाले कोड से पूरे बिल से ₹500 कम। Draft पर 1 और Start पर 2 का निशान है।](5-start-the-offer.webp "अगर शुरू की तारीख अभी आगे है, तो Start की जगह Schedule लिखा आता है।")

काउंटर पर ग्राहक का कोड बिल के **Offer code** बॉक्स में डालें। [काउंटर पर बिक्री करें](/help/orders/new-sale) देखें।

## आम समस्याएँ

:::faq "This offer has no unused codes yet. Make its codes first, then start it." लिखा आ रहा है
एक बार चलने वाले कोड के ऑफ़र को चलने से पहले कोड चाहिए। स्टेप 3 में एक बैच बनाएँ, फिर **Start** दबाएँ।
:::

:::faq "The code … has already been used." लिखा आ रहा है
हर एक बार चलने वाला कोड एक ही बार चलता है। किस ऑर्डर पर लगा, यह देखने के लिए **Find a code** इस्तेमाल करें।
:::

:::faq "Another offer already uses the code …" लिखा आ रहा है
दो ऑफ़र एक ही कोड नहीं रख सकते। कोई दूसरा कोड चुनें।
:::

:::faq मैं साझा कोड और एक बार चलने वाले कोड के बीच बदल नहीं पा रहा
एक बार साझा कोड वाला ऑफ़र शुरू हो गया या इस्तेमाल हो गया, या एक बार चलने वाले कोड बन गए, तो बदलने से ग्राहकों के पास जो कोड हैं वे चलना बंद हो जाएँगे। इसकी जगह ऑफ़र को नए ड्राफ़्ट में कॉपी करें और कॉपी को बदलें।
:::

:::faq मुझे Single-use codes बॉक्स नहीं दिख रहा
कोड सिर्फ़ उन्हें दिखते हैं जो ऑफ़र बदल सकते हैं, क्योंकि बिना इस्तेमाल हुए कोड पैसे के बराबर हैं।
:::
