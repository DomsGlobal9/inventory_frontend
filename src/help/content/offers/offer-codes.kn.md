ಕೋಡ್ ಆಫರ್, ಕೌಂಟರ್‌ನಲ್ಲಿ **Offer code** ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಕೋಡ್ ಟೈಪ್ ಮಾಡಿದಾಗ ಅಥವಾ ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ ಹಾಕಿದಾಗ ಮಾತ್ರ ಕಡಿಮೆಯಾಗುತ್ತದೆ. ಮಾಲೀಕರು ಅಥವಾ ಅಡ್ಮಿನ್ ಮಾತ್ರ ಕೋಡ್ ಆಫರ್ ಮಾಡಬಹುದು.

ಈ ಉದಾಹರಣೆಯಲ್ಲಿ ನಾವು **₹3,000 ಅಥವಾ ಹೆಚ್ಚಿನ ಬಿಲ್‌ಗಳಿಗೆ, ಇಡೀ ಬಿಲ್‌ನಿಂದ ₹500 ಆಫ್** ಮಾಡುತ್ತೇವೆ. [ಹೊಸ ಆಫರ್ ಮಾಡಿ](/help/offers/create-an-offer) ನಲ್ಲಿರುವಂತೆ ಆಫರ್ ತುಂಬಿಸಿ, ನಂತರ:

## 1. With a code ಆರಿಸಿ

**Who gets it** ನಲ್ಲಿ:

1. [[1]] **With a code** ಒತ್ತಿರಿ.
2. ಪೋಸ್ಟರ್ ಮೇಲಿನ ಕೋಡ್ ಹಾಗೆ ಎಲ್ಲರೂ ಒಂದೇ ಕೋಡ್ ಬಳಸುವುದಾದರೆ [[2]] **One shared code** ಆರಿಸಿ.
3. [[3]] ಕೋಡ್ ಟೈಪ್ ಮಾಡಿ, ಉದಾಹರಣೆಗೆ *WELCOME500*.

![Who gets it. With a code ಅನ್ನು 1, One shared code 2 ಮತ್ತು ಕೋಡ್ WELCOME500 ಅನ್ನು 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ. ಕನಿಷ್ಠ ಖರೀದಿ ಮೊತ್ತ 3000.](1-one-shared-code.webp "ಶೇರ್ ಮಾಡಿದ ಕೋಡ್ ಇರುವ ಯಾರಾದರೂ, ಮಿತಿಗಳು ಅನುಮತಿಸುವಷ್ಟು ಬಾರಿ ಅದನ್ನು ಬಳಸಬಹುದು.")

ಆಫರ್ ಸೇವ್ ಮಾಡಿ ಶುರು ಮಾಡಿದ ತಕ್ಷಣ ಶೇರ್ ಮಾಡಿದ ಕೋಡ್ ಸಿದ್ಧ. ನೀವು ಹಂತ 5 ಕ್ಕೆ ಹೋಗಬಹುದು.

## 2. ಅಥವಾ ಒಮ್ಮೆ ಬಳಸುವ ಕೋಡ್‌ಗಳನ್ನು ಆರಿಸಿ

ಗಿಫ್ಟ್ ಕಾರ್ಡ್‌ಗಳಿಗೆ ಅಥವಾ ಗ್ರಾಹಕರ ಪಟ್ಟಿಗೆ [[1]] **Single-use codes** ಒತ್ತಿರಿ. ಪ್ರತಿ ಕೋಡ್ ಒಮ್ಮೆ ಮಾತ್ರ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

![Single-use codes ಅನ್ನು 1 ಎಂದು ಗುರುತಿಸಿರುವ Who gets it. ಪ್ರತಿ ಕೋಡ್ ಒಮ್ಮೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಸೇವ್ ಮಾಡಿದ ನಂತರ ಆಫರ್ ಪೇಜ್‌ನಲ್ಲಿ ಅವುಗಳನ್ನು ಮಾಡಿ ಎಂದು ಸೂಚನೆ ಹೇಳುತ್ತದೆ.](2-single-use-codes.webp "ಒಮ್ಮೆ ಬಳಸುವ ಕೋಡ್‌ಗಳು ನಿಮ್ಮ ಕೌಂಟರ್‌ನಲ್ಲಿ ಮತ್ತು ನಿಮ್ಮದೇ ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ ಮಾತ್ರ ಕೆಲಸ ಮಾಡುತ್ತವೆ. ಅವುಗಳನ್ನು Shopify ಗೆ ಹಾಕಲು ಆಗುವುದಿಲ್ಲ.")

**Create offer** ಒತ್ತಿರಿ. ಆಫರ್ ಡ್ರಾಫ್ಟ್ ಆಗಿ ಸೇವ್ ಆಗುತ್ತದೆ.

## 3. ಕೋಡ್‌ಗಳನ್ನು ಮಾಡಿ

1. **Offers** ನಲ್ಲಿ ಆಫರ್‌ನ ಪೇಜ್ ತೆರೆಯಲು ಅದರ ಹೆಸರು ಒತ್ತಿರಿ.
2. **Single-use codes** ಬಾಕ್ಸ್‌ನಲ್ಲಿ, [[1]] **Starts with** ಪ್ರತಿ ಕೋಡ್‌ನ ಮೊದಲ ಪದ, ಉದಾಹರಣೆಗೆ WELCOME.
3. [[2]] **How many**: ಒಮ್ಮೆಗೆ 5,000 ವರೆಗೆ.
4. [[3]] **Make codes** ಒತ್ತಿರಿ.

![0 ಮಾಡಿರುವ Single-use codes ಬಾಕ್ಸ್. Starts with WELCOME ಅನ್ನು 1, How many 50 ಅನ್ನು 2 ಮತ್ತು Make codes ಅನ್ನು 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-make-codes.webp "ಕೋಡ್‌ಗಳು WELCOME-7KQ2M9XR ಹಾಗೆ ಇರುತ್ತವೆ. ಯಾರೂ ತಪ್ಪಾಗಿ ಓದದಂತೆ ಅವುಗಳಲ್ಲಿ 0, O, 1, I ಅಥವಾ L ಎಂದಿಗೂ ಇರುವುದಿಲ್ಲ.")

ನಂತರ ಇನ್ನಷ್ಟು ಬೇಕೇ? ಇದೇ ರೀತಿ ಇನ್ನೊಂದು ಬ್ಯಾಚ್ ಮಾಡಿ.

## 4. ಕೋಡ್‌ಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳಿ

- [[1]] ಎಷ್ಟು ಮಾಡಲಾಗಿದೆ, ಎಷ್ಟು ಬಳಕೆಯಾಗಿದೆ ಮತ್ತು ಎಷ್ಟು ಉಳಿದಿವೆ ಎಂದು ಎಣಿಕೆ ತೋರಿಸುತ್ತದೆ.
- [[2]] **Copy unused** ಬಳಸದ ಎಲ್ಲಾ ಕೋಡ್‌ಗಳನ್ನು, ಸಾಲಿಗೆ ಒಂದರಂತೆ, ಮೆಸೇಜ್ ಅಥವಾ ಪ್ರಿಂಟ್ ಫೈಲ್‌ಗೆ ಪೇಸ್ಟ್ ಮಾಡಲು ಕಾಪಿ ಮಾಡುತ್ತದೆ.
- [[3]] **CSV** ಎಲ್ಲಾ ಕೋಡ್‌ಗಳನ್ನು ಎಕ್ಸೆಲ್ ಫೈಲ್ ಆಗಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆ, ಯಾವಾಗ ಮತ್ತು ಯಾವ ಆರ್ಡರ್‌ನಲ್ಲಿ ಬಳಕೆಯಾಯಿತು ಎಂಬುದರ ಜೊತೆಗೆ.
- [[4]] **Unused** ಮತ್ತು **Used** ಪಟ್ಟಿಯನ್ನು ಬದಲಿಸುತ್ತವೆ.
- [[5]] **Find a code**: ಕೋಡ್ ಬಳಕೆಯಾಗಿದೆಯೇ ಎಂದು ನೋಡಲು ಕೋಡ್‌ನ ಒಂದು ಭಾಗ ಟೈಪ್ ಮಾಡಿ.

![ಕೋಡ್‌ಗಳು: 50 made, 0 used, 50 left ಅನ್ನು 1, Copy unused 2, CSV 3, Unused ಮತ್ತು Used ಬಟನ್‌ಗಳು 4 ಮತ್ತು Find a code 5 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ. ಕೆಳಗೆ ಕೋಡ್‌ಗಳ ಪಟ್ಟಿ ಇದೆ.](4-your-codes.webp "ಬಳಕೆಯಾದ ಕೋಡ್ ಅದು ಬಳಕೆಯಾದ ಆರ್ಡರ್ ತೋರಿಸುತ್ತದೆ. ಆರ್ಡರ್ ತೆರೆಯಲು ಅದನ್ನು ಒತ್ತಿರಿ.")

## 5. ಆಫರ್ ಶುರು ಮಾಡಿ

ಆಫರ್ ಇನ್ನೂ [[1]] **Draft** ಆಗಿದೆ. ಅದರ ಪೇಜ್‌ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ [[2]] **Start** ಒತ್ತಿರಿ.

![Welcome gift 500 off ಆಫರ್ ಪೇಜ್, ಬಿಲ್ ₹3,000 ಅಥವಾ ಹೆಚ್ಚು ಇದ್ದಾಗ ಒಮ್ಮೆ ಬಳಸುವ ಕೋಡ್‌ನಿಂದ ಇಡೀ ಬಿಲ್‌ಗೆ ₹500 ಆಫ್. Draft ಅನ್ನು 1 ಮತ್ತು Start ಅನ್ನು 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](5-start-the-offer.webp "ಶುರು ದಿನಾಂಕ ಇನ್ನೂ ಮುಂದೆ ಇದ್ದರೆ Start ಬದಲು Schedule ಎಂದು ಇರುತ್ತದೆ.")

ಕೌಂಟರ್‌ನಲ್ಲಿ, ಗ್ರಾಹಕರ ಕೋಡ್ ಅನ್ನು ಬಿಲ್‌ನ **Offer code** ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಹಾಕಿ. [ಹೊಸ ಸೇಲ್](/help/orders/new-sale) ನೋಡಿ.
