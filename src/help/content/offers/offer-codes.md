A code offer only comes off when the code is typed in the **Offer code** box at the till, or entered online. Only the owner or an admin can make code offers.

In this example we make **₹500 off the whole bill, for bills of ₹3,000 or more**. Fill in the offer as in [Create an offer](/help/offers/create-an-offer), then:

## 1. Choose With a code

Under **Who gets it**:

1. Click [[1]] **With a code**.
2. Choose [[2]] **One shared code** if everyone uses the same code, like a code on a poster.
3. [[3]] Type the code, for example *WELCOME500*.

![Who gets it. With a code is marked 1, One shared code 2 and the code WELCOME500 3. The minimum spend is 3000.](1-one-shared-code.webp "Anyone with a shared code can use it, as often as the limits allow.")

A shared code is ready as soon as you save and start the offer. You can skip to step 5.

## 2. Or choose single-use codes

For gift cards or a list of customers, click [[1]] **Single-use codes**. Each code works only once.

![Who gets it with Single-use codes marked 1. The hint says each code works once, make them on the offer page after saving.](2-single-use-codes.webp "Single-use codes work only at your till and on your own website. They cannot be put on Shopify.")

Press **Create offer**. The offer is saved as a draft.

## 3. Make the codes

1. In **Offers**, click the offer's name to open its page.
2. In the **Single-use codes** box, [[1]] **Starts with** is the first word of every code, like WELCOME.
3. [[2]] **How many**: up to 5,000 at a time.
4. Press [[3]] **Make codes**.

![The Single-use codes box with 0 made. Starts with WELCOME is marked 1, How many 50 is marked 2 and Make codes 3.](3-make-codes.webp "Codes look like WELCOME-7KQ2M9XR. They never use 0, O, 1, I or L, so nobody misreads one.")

Need more later? Make another batch the same way.

## 4. Take the codes away

- [[1]] The count shows how many were made, used and are left.
- [[2]] **Copy unused** copies every unused code, one per line, to paste into a message or a print file.
- [[3]] **CSV** downloads every code as a spreadsheet, with when it was used and on which order.
- [[4]] **Unused** and **Used** switch the list.
- [[5]] **Find a code**: type part of a code to check whether it was used.

![The codes: 50 made, 0 used, 50 left is marked 1, Copy unused 2, CSV 3, the Unused and Used buttons 4 and Find a code 5. Below is the list of codes.](4-your-codes.webp "A used code shows the order it was used on. Click it to open the order.")

## 5. Start the offer

The offer is still a [[1]] **Draft**. At the top of its page press [[2]] **Start**.

![The offer page for Welcome gift 500 off, ₹500 off the whole bill with a single-use code when the bill is ₹3,000 or more. Draft is marked 1 and Start is marked 2.](5-start-the-offer.webp "It says Schedule instead of Start when the start date is still ahead.")

At the till, the customer's code goes in the **Offer code** box on the bill. See [New sale](/help/orders/new-sale).

## Common problems

:::faq "This offer has no unused codes yet. Make its codes first, then start it."
A single-use offer needs codes before it can run. Make a batch in step 3, then press **Start**.
:::

:::faq "The code … has already been used."
Each single-use code works once. Use **Find a code** to see which order used it.
:::

:::faq "Another offer already uses the code …"
Two offers cannot share a code. Choose a different code.
:::

:::faq I cannot switch between a shared code and single-use codes
Once a shared code offer has been started or used, or single-use codes have been made, switching would stop the codes customers already have from working. Copy the offer into a new draft and change the copy instead.
:::

:::faq I don't see the Single-use codes box
Only people who can change offers see the codes, because unused codes are worth money.
:::
