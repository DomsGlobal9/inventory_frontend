கோடு ஆஃபர், கவுண்டரில் **Offer code** பெட்டியில் கோடு டைப் செய்தால், அல்லது ஆன்லைனில் கோடு கொடுத்தால் மட்டுமே குறையும். உரிமையாளர் அல்லது அட்மின் மட்டுமே கோடு ஆஃபர்களை உருவாக்க முடியும்.

இந்த உதாரணத்தில் **₹3,000 அல்லது அதற்கு மேல் உள்ள பில்களுக்கு, முழு பில்லில் ₹500 தள்ளுபடி** உருவாக்குகிறோம். [ஆஃபரை உருவாக்குதல்](/help/offers/create-an-offer)-இல் உள்ளது போல ஆஃபரை நிரப்புங்கள், பிறகு:

## 1. With a code தேர்ந்தெடுங்கள்

**Who gets it**-இன் கீழ்:

1. [[1]] **With a code** அழுத்துங்கள்.
2. போஸ்டரில் உள்ள கோடு போல எல்லோரும் ஒரே கோடைப் பயன்படுத்தினால், [[2]] **One shared code** தேர்ந்தெடுங்கள்.
3. [[3]] கோடை டைப் செய்யுங்கள், உதாரணமாக *WELCOME500*.

![Who gets it. With a code 1, One shared code 2, WELCOME500 கோடு 3 எனக் குறிக்கப்பட்டுள்ளன. குறைந்தபட்சத் தொகை 3000.](1-one-shared-code.webp "பொதுக் கோடு தெரிந்த யார் வேண்டுமானாலும், வரம்புகள் அனுமதிக்கும் அளவு பயன்படுத்தலாம்.")

ஆஃபரைச் சேமித்துத் தொடங்கியவுடன் பொதுக் கோடு தயார். நீங்கள் நேராக ஸ்டெப் 5-க்குப் போகலாம்.

## 2. அல்லது ஒருமுறை மட்டும் பயன்படும் கோடுகள்

கிஃப்ட் கார்டுகளுக்கு அல்லது வாடிக்கையாளர் லிஸ்டுக்கு [[1]] **Single-use codes** அழுத்துங்கள். ஒவ்வொரு கோடும் ஒருமுறை மட்டுமே வேலை செய்யும்.

![Single-use codes 1 எனக் குறிக்கப்பட்ட Who gets it. ஒவ்வொரு கோடும் ஒருமுறை வேலை செய்யும், சேமித்த பிறகு ஆஃபர் பக்கத்தில் அவற்றை உருவாக்குங்கள் என்று குறிப்பு சொல்கிறது.](2-single-use-codes.webp "ஒருமுறை கோடுகள் உங்கள் கவுண்டரிலும் வெப்சைட்டிலும் மட்டும் வேலை செய்யும். அவற்றை Shopify-இல் போட முடியாது.")

**Create offer** அழுத்துங்கள். ஆஃபர் டிராஃப்ட் ஆகச் சேமிக்கப்படும்.

## 3. கோடுகளை உருவாக்குங்கள்

1. **Offers**-இல் ஆஃபரின் பெயரை அழுத்தி அதன் பக்கத்தைத் திறங்கள்.
2. **Single-use codes** பெட்டியில், [[1]] **Starts with** என்பது ஒவ்வொரு கோடின் முதல் வார்த்தை, WELCOME போல.
3. [[2]] **How many**: ஒரே நேரத்தில் 5,000 வரை.
4. [[3]] **Make codes** அழுத்துங்கள்.

![0 கோடுகள் உருவான Single-use codes பெட்டி. Starts with WELCOME 1, How many 50 2, Make codes 3 எனக் குறிக்கப்பட்டுள்ளன.](3-make-codes.webp "கோடுகள் WELCOME-7KQ2M9XR போல இருக்கும். யாரும் தவறாகப் படிக்காமல் இருக்க 0, O, 1, I, L பயன்படுத்தப்படாது.")

பிறகு இன்னும் வேண்டுமா? இதே வழியில் இன்னொரு தொகுதி உருவாக்குங்கள்.

## 4. கோடுகளை எடுத்துக்கொள்ளுங்கள்

- [[1]] எத்தனை உருவானது, எத்தனை பயன்படுத்தப்பட்டது, எத்தனை மீதம் என்று எண்ணிக்கை காட்டும்.
- [[2]] **Copy unused** பயன்படுத்தாத எல்லா கோடுகளையும், ஒரு வரிக்கு ஒன்றாகக் காப்பி செய்யும். மெசேஜிலோ பிரிண்ட் ஃபைலிலோ ஒட்டலாம்.
- [[3]] **CSV** எல்லா கோடுகளையும் ஸ்ப்ரெட்ஷீட்டாக டவுன்லோட் செய்யும். எப்போது, எந்த ஆர்டரில் பயன்படுத்தப்பட்டது என்றும் இருக்கும்.
- [[4]] **Unused** மற்றும் **Used** லிஸ்டை மாற்றும்.
- [[5]] **Find a code**: ஒரு கோடு பயன்படுத்தப்பட்டதா என்று பார்க்க, கோடின் ஒரு பகுதியை டைப் செய்யுங்கள்.

![கோடுகள்: 50 made, 0 used, 50 left 1, Copy unused 2, CSV 3, Unused மற்றும் Used பட்டன்கள் 4, Find a code 5 எனக் குறிக்கப்பட்டுள்ளன. கீழே கோடுகளின் லிஸ்ட்.](4-your-codes.webp "பயன்படுத்திய கோடு, அது பயன்பட்ட ஆர்டரைக் காட்டும். ஆர்டரைத் திறக்க அதை அழுத்துங்கள்.")

## 5. ஆஃபரைத் தொடங்குங்கள்

ஆஃபர் இன்னும் [[1]] **Draft** ஆகவே உள்ளது. அதன் பக்கத்தின் மேலே [[2]] **Start** அழுத்துங்கள்.

![Welcome gift 500 off ஆஃபரின் பக்கம், பில் ₹3,000 அல்லது அதற்கு மேல் இருந்தால் ஒருமுறை கோடுடன் முழு பில்லில் ₹500 தள்ளுபடி. Draft 1, Start 2 எனக் குறிக்கப்பட்டுள்ளன.](5-start-the-offer.webp "தொடங்கும் தேதி இன்னும் வரவில்லை என்றால் Start-க்குப் பதிலாக Schedule என்று இருக்கும்.")

கவுண்டரில், வாடிக்கையாளரின் கோடு பில்லில் உள்ள **Offer code** பெட்டியில் போட வேண்டும். [New sale](/help/orders/new-sale) பாருங்கள்.
