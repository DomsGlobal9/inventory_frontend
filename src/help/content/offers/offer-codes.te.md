కోడ్ ఆఫర్ కౌంటర్‌లో **Offer code** బాక్స్‌లో కోడ్ టైప్ చేసినప్పుడు, లేదా ఆన్‌లైన్‌లో కోడ్ ఎంటర్ చేసినప్పుడు మాత్రమే తగ్గుతుంది. యజమాని లేదా అడ్మిన్ మాత్రమే కోడ్ ఆఫర్లు తయారు చేయగలరు.

ఈ ఉదాహరణలో మనం **₹3,000 లేదా అంతకంటే ఎక్కువ బిల్లులకు, మొత్తం బిల్ మీద ₹500 తగ్గింపు** తయారు చేస్తాం. [ఆఫర్ తయారు చేయండి](/help/offers/create-an-offer) లో లాగా ఆఫర్ నింపండి, తర్వాత:

## 1. With a code ఎంచుకోండి

**Who gets it** కింద:

1. [[1]] **With a code** నొక్కండి.
2. పోస్టర్ మీద ఉన్న కోడ్ లాగా అందరూ ఒకే కోడ్ వాడితే, [[2]] **One shared code** ఎంచుకోండి.
3. [[3]] కోడ్ టైప్ చేయండి, ఉదాహరణకు *WELCOME500*.

![Who gets it. With a code 1, One shared code 2, కోడ్ WELCOME500 3 గా గుర్తించబడ్డాయి. కనీస కొనుగోలు 3000.](1-one-shared-code.webp "షేర్డ్ కోడ్ ఉన్న ఎవరైనా దాన్ని వాడవచ్చు, లిమిట్‌లు అనుమతించినన్ని సార్లు.")

మీరు ఆఫర్ సేవ్ చేసి మొదలుపెట్టగానే షేర్డ్ కోడ్ రెడీ అవుతుంది. మీరు నేరుగా స్టెప్ 5 కి వెళ్లవచ్చు.

## 2. లేదా ఒక్కసారి వాడే కోడ్‌లు ఎంచుకోండి

గిఫ్ట్ కార్డ్‌ల కోసం లేదా కస్టమర్ల లిస్ట్ కోసం, [[1]] **Single-use codes** నొక్కండి. ప్రతి కోడ్ ఒక్కసారి మాత్రమే పనిచేస్తుంది.

![Single-use codes 1 గా గుర్తించబడిన Who gets it. ప్రతి కోడ్ ఒక్కసారి పనిచేస్తుంది, సేవ్ చేశాక ఆఫర్ పేజీలో వాటిని తయారు చేయండి అని సూచన చెబుతుంది.](2-single-use-codes.webp "ఒక్కసారి వాడే కోడ్‌లు మీ కౌంటర్‌లో, మీ సొంత వెబ్‌సైట్‌లో మాత్రమే పనిచేస్తాయి. వాటిని Shopify లో పెట్టలేరు.")

**Create offer** నొక్కండి. ఆఫర్ డ్రాఫ్ట్‌గా సేవ్ అవుతుంది.

## 3. కోడ్‌లు తయారు చేయండి

1. **Offers** లో, ఆఫర్ పేజీ తెరవడానికి దాని పేరు నొక్కండి.
2. **Single-use codes** బాక్స్‌లో, [[1]] **Starts with** అంటే ప్రతి కోడ్ మొదటి మాట, WELCOME లాగా.
3. [[2]] **How many**: ఒకేసారి 5,000 వరకు.
4. [[3]] **Make codes** నొక్కండి.

![0 తయారైన Single-use codes బాక్స్. Starts with WELCOME 1, How many 50 2, Make codes 3 గా గుర్తించబడ్డాయి.](3-make-codes.webp "కోడ్‌లు WELCOME-7KQ2M9XR లాగా ఉంటాయి. వాటిలో 0, O, 1, I, L ఎప్పుడూ ఉండవు, కాబట్టి ఎవరూ తప్పుగా చదవరు.")

తర్వాత ఇంకా కావాలా? అదే విధంగా ఇంకో బ్యాచ్ తయారు చేయండి.

## 4. కోడ్‌లు తీసుకోండి

- [[1]] ఎన్ని తయారయ్యాయి, ఎన్ని వాడారు, ఎన్ని మిగిలాయి అని కౌంట్ చూపిస్తుంది.
- [[2]] **Copy unused** వాడని ప్రతి కోడ్‌ను, లైన్‌కు ఒకటి చొప్పున కాపీ చేస్తుంది, మెసేజ్‌లో లేదా ప్రింట్ ఫైల్‌లో పేస్ట్ చేయడానికి.
- [[3]] **CSV** ప్రతి కోడ్‌ను స్ప్రెడ్‌షీట్‌గా డౌన్‌లోడ్ చేస్తుంది, ఎప్పుడు వాడారు, ఏ ఆర్డర్‌లో వాడారు అనే వివరాలతో.
- [[4]] **Unused**, **Used** లిస్ట్ మారుస్తాయి.
- [[5]] **Find a code**: కోడ్ వాడారో లేదో చెక్ చేయడానికి కోడ్‌లో కొంత భాగం టైప్ చేయండి.

![కోడ్‌లు: 50 తయారు, 0 వాడారు, 50 మిగిలాయి 1, Copy unused 2, CSV 3, Unused, Used బటన్లు 4, Find a code 5 గా గుర్తించబడ్డాయి. కింద కోడ్‌ల లిస్ట్ ఉంది.](4-your-codes.webp "వాడిన కోడ్ అది ఏ ఆర్డర్‌లో వాడారో చూపిస్తుంది. ఆర్డర్ తెరవడానికి దాన్ని నొక్కండి.")

## 5. ఆఫర్ మొదలుపెట్టండి

ఆఫర్ ఇంకా [[1]] **Draft** గానే ఉంది. దాని పేజీ పైన [[2]] **Start** నొక్కండి.

![Welcome gift 500 off ఆఫర్ పేజీ, బిల్ ₹3,000 లేదా ఎక్కువ ఉన్నప్పుడు ఒక్కసారి వాడే కోడ్‌తో మొత్తం బిల్ మీద ₹500 తగ్గింపు. Draft 1 గా, Start 2 గా గుర్తించబడ్డాయి.](5-start-the-offer.webp "మొదలయ్యే తేదీ ఇంకా ముందు ఉంటే Start బదులు Schedule అని ఉంటుంది.")

కౌంటర్‌లో, కస్టమర్ కోడ్ బిల్ మీద ఉన్న **Offer code** బాక్స్‌లో టైప్ చేయాలి. [కౌంటర్ సేల్ చేయండి](/help/orders/new-sale) చూడండి.
