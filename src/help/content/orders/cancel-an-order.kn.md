ಅಡ್ಮಿನ್‌ಗಳು ಮತ್ತು ಮಾಲೀಕರು ಮಾತ್ರ ಆರ್ಡರ್ ಕ್ಯಾನ್ಸಲ್ ಮಾಡಬಹುದು.

## 1. ಆರ್ಡರ್ ತೆರೆದು Cancel Order ಒತ್ತಿರಿ

1. ಆರ್ಡರ್ ಹುಡುಕಿ. [ಆರ್ಡರ್ ಹುಡುಕಿ](/help/orders/find-an-order) ನೋಡಿ.
2. ಅದು [[1]] **Confirmed** ಆಗಿದೆಯೇ ಎಂದು ನೋಡಿ. (ಅದರಲ್ಲಿ ಸ್ವಲ್ಪ ಈಗಾಗಲೇ ಕಳುಹಿಸಿದ್ದರೆ, ಬಟನ್ ಹೆಸರು ಬದಲಿಗೆ **Close rest of order** ಆಗಿರುತ್ತದೆ.)
3. [[2]] **Cancel Order** ಒತ್ತಿರಿ.

![Farah Khan ಅವರ ಕನ್ಫರ್ಮ್ ಆದ ಆರ್ಡರ್. Confirmed ಲೇಬಲ್ 1 ಎಂದು, ಕೆಂಪು Cancel Order ಬಟನ್ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-cancel-order.webp "Cancel Order ಬಟನ್ Create Dispatch ಕೆಳಗೆ ಇದೆ.")

## 2. ಹೌದು ಎನ್ನಿ

ಮೆಸೇಜ್ ಓದಿ [[1]] **Cancel order** ಒತ್ತಿರಿ. ಇದನ್ನು ವಾಪಸ್ ಮಾಡಲು ಆಗುವುದಿಲ್ಲ.

![Cancel this order? ಬಾಕ್ಸ್. ಕೆಂಪು Cancel order ಬಟನ್ 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-confirm.webp "ಆರ್ಡರ್ ಇಟ್ಟುಕೊಳ್ಳಲು ಬದಲಿಗೆ Cancel ಒತ್ತಿರಿ.")

## 3. ಆಯಿತೇ ಎಂದು ನೋಡಿ

ಆರ್ಡರ್ ಈಗ [[1]] **Cancelled** ಎಂದು ತೋರಿಸುತ್ತದೆ. ಅದು ಯಾವುದೇ ಸ್ಟಾಕ್ ಹಿಡಿದಿಟ್ಟಿಲ್ಲ: ಪ್ರತಿ ಸಾಲಿನಲ್ಲಿ [[2]] **RESERVED** 0 ಆಗಿದೆ, ಮತ್ತು ಪೀಸ್‌ಗಳನ್ನು ಮತ್ತೆ ಮಾರಬಹುದು.

![ಕ್ಯಾನ್ಸಲ್ ಆದ ಆರ್ಡರ್. Cancelled ಲೇಬಲ್ 1 ಎಂದು, 0 ತೋರಿಸುವ RESERVED ಕಾಲಂ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-cancelled.webp "ಆರ್ಡರ್ Cancelled ಸ್ಟೇಟಸ್‌ನೊಂದಿಗೆ ನಿಮ್ಮ ಪಟ್ಟಿಯಲ್ಲೇ ಇರುತ್ತದೆ.")

## ಅದರಲ್ಲಿ ಸ್ವಲ್ಪ ಈಗಾಗಲೇ ಕಳುಹಿಸಲಾಗಿದೆ

ಕೆಲವು ಪೀಸ್‌ಗಳು ಹೋಗಿದ್ದರೆ, ಬಟನ್ ಬದಲಿಗೆ **Close rest of order** ಎಂದು ಇರುತ್ತದೆ. ಕಳುಹಿಸಿದ್ದು ಸೇಲ್ ಆಗಿಯೇ ಉಳಿಯುತ್ತದೆ. ಕಳುಹಿಸದ ಪೀಸ್‌ಗಳು ಮಾತ್ರ ಮತ್ತೆ ಮಾರಾಟಕ್ಕೆ ಸಿಗುತ್ತವೆ. [ಆನ್‌ಲೈನ್ ಆರ್ಡರ್ ಕಳುಹಿಸಿ](/help/orders/send-online-orders) ನ 5ನೇ ಹಂತ ನೋಡಿ.

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq ನನಗೆ Cancel Order ಕಾಣುತ್ತಿಲ್ಲ
ಅಡ್ಮಿನ್‌ಗಳು ಮತ್ತು ಮಾಲೀಕರು ಮಾತ್ರ ಕ್ಯಾನ್ಸಲ್ ಮಾಡಬಹುದು. ಆರ್ಡರ್ ಕೂಡ **Confirmed** ಅಥವಾ ಸ್ವಲ್ಪ ಕಳುಹಿಸಿದ್ದು ಆಗಿರಬೇಕು.
:::

:::faq ಆರ್ಡರ್ DRAFT ಆಗಿದೆ, ಅದರಲ್ಲಿ Cancel Order ಬಟನ್ ಇಲ್ಲ
ಡ್ರಾಫ್ಟ್ ಯಾವುದೇ ಸ್ಟಾಕ್ ಹಿಡಿದಿಟ್ಟಿಲ್ಲ, ಆದ್ದರಿಂದ ಏನನ್ನೂ ಬಿಡುಗಡೆ ಮಾಡಬೇಕಿಲ್ಲ. ಈ ಸ್ಕ್ರೀನ್‌ನಲ್ಲಿ ಡ್ರಾಫ್ಟ್ ಕ್ಯಾನ್ಸಲ್ ಮಾಡುವ ಬಟನ್ ಇಲ್ಲ. ಅದನ್ನು ಡ್ರಾಫ್ಟ್ ಆಗಿಯೇ ಬಿಡಿ, ಅಥವಾ ತೆಗೆಯಲೇಬೇಕಿದ್ದರೆ ನಿಮ್ಮ ScaleEzy ಸಂಪರ್ಕ ವ್ಯಕ್ತಿಯ ಸಹಾಯ ಕೇಳಿ.
:::

:::faq ಆರ್ಡರ್ ಈಗಾಗಲೇ Dispatched ಆಗಿದೆ
ಎಲ್ಲವೂ ಹೋಗಿದೆ, ಆದ್ದರಿಂದ ಕ್ಯಾನ್ಸಲ್ ಮಾಡಲು ಆಗುವುದಿಲ್ಲ. ಗ್ರಾಹಕರು ಸಾಮಾನು ವಾಪಸ್ ಕಳುಹಿಸಿದರೆ, ರಿಟರ್ನ್ ಬುಕ್ ಮಾಡಿ. [ರಿಟರ್ನ್ ಬುಕ್ ಮಾಡಿ](/help/returns/book-a-return) ನೋಡಿ.
:::

:::faq ಕೌಂಟರ್ ಸೇಲ್ ತಪ್ಪಾಗಿ ಆಗಿದೆ
ಕೌಂಟರ್ ಸೇಲ್ ಮಾಡಿದ ತಕ್ಷಣ ಪೂರ್ತಿ ಆಗುತ್ತದೆ. ಪೀಸ್‌ಗಳನ್ನು ರಿಟರ್ನ್ ಆಗಿ ಬುಕ್ ಮಾಡಿ. [ರಿಟರ್ನ್ ಬುಕ್ ಮಾಡಿ](/help/returns/book-a-return) ನೋಡಿ.
:::
