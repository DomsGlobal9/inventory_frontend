அட்மின்களும் உரிமையாளரும் மட்டுமே ஆர்டரை கேன்சல் செய்ய முடியும்.

## 1. ஆர்டரைத் திறந்து Cancel Order அழுத்துங்கள்

1. ஆர்டரைக் கண்டுபிடியுங்கள். [ஆர்டரைக் கண்டுபிடித்தல்](/help/orders/find-an-order) பாருங்கள்.
2. அது [[1]] **CONFIRMED** ஆக உள்ளதா என்று பாருங்கள். (ஒரு பகுதி ஏற்கனவே அனுப்பப்பட்டிருந்தால், பட்டனின் பெயர் **Close rest of order** என்று இருக்கும்.)
3. [[2]] **Cancel Order** அழுத்துங்கள்.

![Farah Khan-க்கான கன்ஃபர்ம் ஆன ஆர்டர். CONFIRMED லேபிள் 1 எனவும், சிவப்பு Cancel Order பட்டன் 2 எனவும் குறிக்கப்பட்டுள்ளன.](1-cancel-order.webp "Cancel Order பட்டன் Create Dispatch-க்குக் கீழே உள்ளது.")

## 2. சரி என்று சொல்லுங்கள்

மெசேஜைப் படித்துவிட்டு [[1]] **Cancel order** அழுத்துங்கள். இதைத் திரும்ப மாற்ற முடியாது.

![Cancel this order? பெட்டி. சிவப்பு Cancel order பட்டன் 1 எனக் குறிக்கப்பட்டுள்ளது.](2-confirm.webp "ஆர்டரை வைத்துக்கொள்ள வேண்டுமென்றால் Cancel அழுத்துங்கள்.")

## 3. சரியாக நடந்ததா என்று பாருங்கள்

இப்போது ஆர்டரில் [[1]] **CANCELLED** என்று இருக்கும். அது எந்த ஸ்டாக்கையும் ஒதுக்கி வைக்காது: ஒவ்வொரு வரியிலும் [[2]] **RESERVED** 0 ஆக இருக்கும், பீஸ்களை மீண்டும் விற்கலாம்.

![கேன்சல் ஆன ஆர்டர். CANCELLED லேபிள் 1 எனவும், 0 காட்டும் RESERVED காலம் 2 எனவும் குறிக்கப்பட்டுள்ளன.](3-cancelled.webp "ஆர்டர் Cancelled ஸ்டேட்டஸுடன் உங்கள் லிஸ்டிலேயே இருக்கும்.")

## ஒரு பகுதி ஏற்கனவே அனுப்பப்பட்டிருந்தால்

சில பீஸ்கள் ஏற்கனவே அனுப்பப்பட்டிருந்தால், பட்டனில் **Close rest of order** என்று இருக்கும். அனுப்பியது விற்பனையாகவே இருக்கும். அனுப்பாத பீஸ்கள் மட்டும் மீண்டும் விற்பனைக்கு வரும். [ஆன்லைன் ஆர்டரை அனுப்புதல்](/help/orders/send-online-orders) பக்கத்தில் படி 5 பாருங்கள்.

## பொதுவான பிரச்சினைகள்

:::faq Cancel Order எனக்குத் தெரியவில்லை
அட்மின்களும் உரிமையாளரும் மட்டுமே கேன்சல் செய்ய முடியும். ஆர்டரும் **CONFIRMED** அல்லது பாதி அனுப்பியதாக இருக்க வேண்டும்.
:::

:::faq ஆர்டர் DRAFT ஆக உள்ளது, Cancel Order பட்டன் இல்லை
டிராஃப்ட் எந்த ஸ்டாக்கையும் ஒதுக்கி வைப்பதில்லை, அதனால் எதையும் விடுவிக்க வேண்டியதில்லை. இந்தத் திரையில் டிராஃப்டை கேன்சல் செய்யப் பட்டன் இல்லை. அதை டிராஃப்டாகவே விடுங்கள். கட்டாயம் நீக்க வேண்டுமென்றால் உங்கள் ScaleEzy தொடர்பாளரிடம் உதவி கேளுங்கள்.
:::

:::faq ஆர்டர் ஏற்கனவே DISPATCHED ஆகிவிட்டது
எல்லாம் அனுப்பப்பட்டுவிட்டது, அதனால் கேன்சல் செய்ய முடியாது. வாடிக்கையாளர் பொருட்களைத் திருப்பி அனுப்பினால், ரிட்டர்னைப் பதிவு செய்யுங்கள். [ரிட்டர்னைப் பதிவு செய்தல்](/help/returns/book-a-return) பாருங்கள்.
:::

:::faq கவுண்டர் விற்பனை தவறாகச் செய்யப்பட்டது
கவுண்டர் விற்பனை செய்தவுடனேயே முடிந்துவிடும். பீஸ்களை ரிட்டர்னாகத் திரும்பப் பதிவு செய்யுங்கள். [ரிட்டர்னைப் பதிவு செய்தல்](/help/returns/book-a-return) பாருங்கள்.
:::
