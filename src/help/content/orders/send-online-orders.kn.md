ನಿಮ್ಮ ಕೌಂಟರ್‌ನಲ್ಲಿ ಆಗದ ಆರ್ಡರ್ (ಆನ್‌ಲೈನ್, Shopify ಅಥವಾ ಫೋನ್‌ನಲ್ಲಿ ತೆಗೆದುಕೊಂಡದ್ದು) ಈ ಹಂತಗಳ ಮೂಲಕ ಹೋಗುತ್ತದೆ:

**Draft** → **Confirmed** (ಅದಕ್ಕಾಗಿ ಸ್ಟಾಕ್ ಹಿಡಿದಿಡಲಾಗುತ್ತದೆ) → **Partly sent** → **Dispatched** (ಎಲ್ಲವೂ ಕಳುಹಿಸಲಾಗಿದೆ).

ಮೊದಲು ಆರ್ಡರ್ ಹುಡುಕಿ: [ಆರ್ಡರ್ ಹುಡುಕಿ](/help/orders/find-an-order). ಕಳುಹಿಸಲು ಕಾಯುತ್ತಿರುವ *Confirmed* ಆರ್ಡರ್‌ಗಳನ್ನು ಮಾತ್ರ ನೋಡಲು ಸ್ಟೇಟಸ್ ಪಟ್ಟಿ ಬಳಸಿ.

## 1. ಡ್ರಾಫ್ಟ್ ಆರ್ಡರ್ ಕನ್ಫರ್ಮ್ ಮಾಡಿ

**DRAFT** [[1]] ಆರ್ಡರ್ ಇನ್ನೂ ಯಾವುದೇ ಸ್ಟಾಕ್ ಹಿಡಿದಿಟ್ಟಿಲ್ಲ. [[2]] **Confirm Order** ಒತ್ತಿರಿ.

![Meena Iyer ಅವರ ಡ್ರಾಫ್ಟ್ ಆರ್ಡರ್ SO-000006. DRAFT ಲೇಬಲ್ 1 ಎಂದು, Confirm Order ಬಟನ್ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-confirm-order.webp "Shopify ಅಥವಾ ನಿಮ್ಮ ವೆಬ್‌ಸೈಟ್‌ನ ಆರ್ಡರ್‌ಗಳು ಸಾಮಾನ್ಯವಾಗಿ ಕನ್ಫರ್ಮ್ ಆಗಿಯೇ ಬರುತ್ತವೆ. ಆಗ 3ನೇ ಹಂತಕ್ಕೆ ಹೋಗಿ.")

ಸೇಲ್ಸ್ ಸ್ಟಾಫ್, ಅಡ್ಮಿನ್‌ಗಳು ಮತ್ತು ಮಾಲೀಕರು ಆರ್ಡರ್ ಕನ್ಫರ್ಮ್ ಮಾಡಬಹುದು.

## 2. ಹೌದು ಎನ್ನಿ

ಮೆಸೇಜ್ ನೋಡಿ [[1]] **Confirm order** ಒತ್ತಿರಿ.

![Confirm this order? ಬಾಕ್ಸ್. Confirm order ಬಟನ್ 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-confirm-dialog.webp "ಈ ಆರ್ಡರ್‌ನ ಸ್ಟಾಕ್ ಅನ್ನು ಇನ್ನು ಬೇರೆಯವರಿಗೆ ಮಾರಲು ಆಗುವುದಿಲ್ಲ.")

## 3. Create Dispatch ತೆರೆಯಿರಿ

ಪಾರ್ಸೆಲ್ ಪ್ಯಾಕ್ ಆದಾಗ, **Confirmed** [[1]] ಆರ್ಡರ್ ತೆರೆದು [[2]] **Create Dispatch** ಒತ್ತಿರಿ.

![Farah Khan ಅವರ ಕನ್ಫರ್ಮ್ ಆದ ಆರ್ಡರ್ SO-000003. Confirmed ಲೇಬಲ್ 1 ಎಂದು, Create Dispatch ಬಟನ್ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-create-dispatch.webp "ಸ್ಟಾಕ್ ರೂಮ್ ಸ್ಟಾಫ್, ಅಡ್ಮಿನ್‌ಗಳು ಮತ್ತು ಮಾಲೀಕರಿಗೆ Create Dispatch ಕಾಣುತ್ತದೆ.")

:::tip ಶೆಲ್ಫ್‌ಗಳನ್ನು ಬಳಸುತ್ತೀರಾ?
ಮೊದಲು [ಆನ್‌ಲೈನ್ ಆರ್ಡರ್ ಪಿಕ್ ಮಾಡಿ](/help/shelves/pick) ಬಳಸಿ ಪೀಸ್‌ಗಳನ್ನು ಅವುಗಳ ಶೆಲ್ಫ್‌ಗಳಿಂದ ತೆಗೆಯಿರಿ. ನೀವು ಮುಗಿಸಿದಾಗ ಪಿಕ್ ಪಟ್ಟಿಯೇ ಆರ್ಡರ್ ಕಳುಹಿಸಬಹುದು.
:::

## 4. ಈಗ ಎಷ್ಟು ಹೋಗುತ್ತವೆ ಎಂದು ತಿಳಿಸಿ, ನಂತರ Dispatch Items

1. [[1]] **DISPATCH NOW** ನಲ್ಲಿ ಪಾರ್ಸೆಲ್‌ನಲ್ಲಿ ಪ್ರತಿ ಐಟಂ ಎಷ್ಟು ಇವೆ ಎಂದು ಟೈಪ್ ಮಾಡಿ. ಇನ್ನೂ ಎಷ್ಟು ಕಳುಹಿಸಬೇಕು ಎಂದು **REMAINING** ತೋರಿಸುತ್ತದೆ.
2. [[2]] **Dispatch Items** ಒತ್ತಿರಿ.

![Create Dispatch ಬಾಕ್ಸ್. SKU, REMAINING ಮತ್ತು DISPATCH NOW ಇರುವ ಟೇಬಲ್ 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ, ಎರಡೂ ಐಟಂಗಳಿಗೆ 1 ಟೈಪ್ ಮಾಡಲಾಗಿದೆ. Dispatch Items 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-dispatch-items.webp "ಈ ಪಾರ್ಸೆಲ್‌ನಲ್ಲಿ ಇಲ್ಲದ ಐಟಂ ಅನ್ನು 0 ಯಲ್ಲೇ ಬಿಡಿ.")

ಪೀಸ್‌ಗಳು ತಕ್ಷಣ ನಿಮ್ಮ ಸ್ಟಾಕ್‌ನಿಂದ ಕಡಿಮೆ ಆಗುತ್ತವೆ.

## 5. ಸ್ವಲ್ಪ ಮಾತ್ರ ಕಳುಹಿಸಿದ್ದರೆ

ಕೆಲವು ಪೀಸ್‌ಗಳು ಇನ್ನೂ ಹೋಗಬೇಕಿದ್ದರೆ, ಆರ್ಡರ್ **Partly sent** ಎಂದು ತೋರಿಸುತ್ತದೆ (Orders ಪಟ್ಟಿಯಲ್ಲೂ ಇದೇ) ಮತ್ತು ಉಳಿದದ್ದಕ್ಕಾಗಿ ಕಾಯುತ್ತದೆ.

1. [[1]] ಪ್ರತಿ ಐಟಂ ಎಷ್ಟು ಇನ್ನೂ ಹಿಡಿದಿಟ್ಟಿದೆ (**RESERVED**) ಮತ್ತು ಎಷ್ಟು ಹೋಗಿದೆ (**DISPATCHED**) ಎಂದು **Line Items** ತೋರಿಸುತ್ತದೆ.
2. [[2]] ಉಳಿದದ್ದು ಪ್ಯಾಕ್ ಆದಾಗ, ಮತ್ತೆ **Create Dispatch** ಒತ್ತಿರಿ.
3. [[3]] ಉಳಿದದ್ದು ಎಂದಿಗೂ ಕಳುಹಿಸುವುದಿಲ್ಲವಾದರೆ, ಅಡ್ಮಿನ್ ಅಥವಾ ಮಾಲೀಕರು **Close rest of order** ಒತ್ತುತ್ತಾರೆ. ಕಳುಹಿಸಿದ್ದು ಸೇಲ್ ಆಗಿಯೇ ಉಳಿಯುತ್ತದೆ. ಕಳುಹಿಸದ ಪೀಸ್‌ಗಳು ಮತ್ತೆ ಮಾರಾಟಕ್ಕೆ ಸಿಗುತ್ತವೆ.

![ಸ್ವಲ್ಪ ಕಳುಹಿಸಿದ ಆರ್ಡರ್. Line Items 1, Create Dispatch 2 ಮತ್ತು Close rest of order 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](5-part-sent.webp "ಎಲ್ಲವೂ ಹೋದಾಗ ಆರ್ಡರ್ Dispatched ಆಗುತ್ತದೆ.")

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq ನನಗೆ Create Dispatch ಕಾಣುತ್ತಿಲ್ಲ
ಆರ್ಡರ್ ಮೊದಲು **Confirmed** ಅಥವಾ ಸ್ವಲ್ಪ ಕಳುಹಿಸಿದ್ದು ಆಗಿರಬೇಕು. ಅಲ್ಲದೆ, ಸ್ಟಾಕ್ ರೂಮ್ ಸ್ಟಾಫ್, ಅಡ್ಮಿನ್‌ಗಳು ಮತ್ತು ಮಾಲೀಕರು ಮಾತ್ರ ಆರ್ಡರ್ ಕಳುಹಿಸಬಹುದು.
:::

:::faq "Enter a quantity greater than 0 for at least one item." ಎಂದು ಬರುತ್ತಿದೆ
ಎಲ್ಲಾ **DISPATCH NOW** ಬಾಕ್ಸ್‌ಗಳು 0 ಆಗಿದ್ದವು. ಪಾರ್ಸೆಲ್‌ನಲ್ಲಿ ಕನಿಷ್ಠ ಒಂದು ಐಟಂ ಎಷ್ಟು ಇದೆ ಎಂದು ಟೈಪ್ ಮಾಡಿ.
:::

:::faq ನನಗೆ Confirm Order ಕಾಣುತ್ತಿಲ್ಲ
ಅದು **DRAFT** ಆರ್ಡರ್‌ನಲ್ಲಿ ಮಾತ್ರ ಇರುತ್ತದೆ, ಮತ್ತು ಸೇಲ್ಸ್ ಸ್ಟಾಫ್, ಅಡ್ಮಿನ್‌ಗಳು ಮತ್ತು ಮಾಲೀಕರು ಮಾತ್ರ ಕನ್ಫರ್ಮ್ ಮಾಡಬಹುದು. ಸ್ಟಾಕ್ ರೂಮ್ ಸ್ಟಾಫ್‌ಗೆ ಆಗುವುದಿಲ್ಲ.
:::

:::faq ಗ್ರಾಹಕರು ಪಾರ್ಸೆಲ್ ವಾಪಸ್ ಕಳುಹಿಸಿದ್ದಾರೆ
ಗ್ರಾಹಕರ ಪೇಜ್‌ನಿಂದ ಅದನ್ನು ಬುಕ್ ಮಾಡಿ. [ರಿಟರ್ನ್ ಬುಕ್ ಮಾಡಿ](/help/returns/book-a-return) ನೋಡಿ.
:::
