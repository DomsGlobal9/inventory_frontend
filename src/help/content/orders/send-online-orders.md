An order that did not happen at your counter (online, Shopify or taken by phone) goes through these stages:

**Draft** → **Confirmed** (stock is held for it) → **Partly sent** → **Dispatched** (everything has gone out).

Find the order first: [Find an order](/help/orders/find-an-order). Use the status list to see only *Confirmed* orders waiting to go out.

## 1. Confirm a draft order

A **DRAFT** [[1]] order does not hold any stock yet. Click [[2]] **Confirm Order**.

![A draft order SO-000006 for Meena Iyer. The DRAFT label is marked 1 and the Confirm Order button is marked 2.](1-confirm-order.webp "Orders from Shopify or your website usually arrive already confirmed. Then skip to step 3.")

Sales staff, admins and owners can confirm orders.

## 2. Say yes

Check the message and click [[1]] **Confirm order**.

![The Confirm this order? box. The Confirm order button is marked 1.](2-confirm-dialog.webp "The stock for this order can no longer be sold to someone else.")

## 3. Open Create Dispatch

When the parcel is packed, open the **CONFIRMED** [[1]] order and click [[2]] **Create Dispatch**.

![A confirmed order SO-000003 for Farah Khan. The CONFIRMED label is marked 1 and the Create Dispatch button is marked 2.](3-create-dispatch.webp "Stock room staff, admins and owners see Create Dispatch.")

:::tip Using shelves?
Pick the pieces from their shelves first with [Pick online orders](/help/shelves/pick). The pick list can send the order out for you when you finish.
:::

## 4. Say how many go now, then Dispatch Items

1. [[1]] In **DISPATCH NOW**, type how many of each item are in the parcel. **REMAINING** shows how many are still to send.
2. Click [[2]] **Dispatch Items**.

![The Create Dispatch box. The table with SKU, REMAINING and DISPATCH NOW is marked 1, with 1 typed for both items. Dispatch Items is marked 2.](4-dispatch-items.webp "Leave an item at 0 if it is not in this parcel.")

The pieces come off your stock straight away.

## 5. If only part was sent

If some pieces are still to come, the order page shows **PARTIALLY_DISPATCHED** (the Orders list calls it **Partly sent**) and waits for the rest.

1. [[1]] **Line Items** shows how many of each item are still held (**RESERVED**) and how many went out (**DISPATCHED**).
2. [[2]] When the rest is packed, click **Create Dispatch** again.
3. [[3]] If the rest will never be sent, an admin or owner clicks **Close rest of order**. What was sent stays a sale. The pieces not sent go back on sale.

![A partly sent order. Line Items is marked 1, Create Dispatch 2 and Close rest of order 3.](5-part-sent.webp "When everything has gone out, the order becomes DISPATCHED.")

## Common problems

:::faq I don't see Create Dispatch
The order must be **CONFIRMED** or partly sent first. Also, only stock room staff, admins and owners can send orders out.
:::

:::faq "Enter a quantity greater than 0 for at least one item."
Every **DISPATCH NOW** box was 0. Type how many of at least one item are in the parcel.
:::

:::faq I don't see Confirm Order
Only a **DRAFT** order has it, and only sales staff, admins and owners can confirm. Stock room staff cannot.
:::

:::faq A customer sent a parcel back
Book it in from the customer's page. See [Book in a return](/help/returns/book-a-return).
:::
