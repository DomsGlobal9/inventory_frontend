**Import Updates** ನಿಮ್ಮ ಬಳಿ ಈಗಾಗಲೇ ಇರುವ ಐಟಂಗಳನ್ನು ಬದಲಿಸುತ್ತದೆ. ಅದು ಪ್ರತಿ ಐಟಂ ಅನ್ನು ಅದರ **SKU** ಮೂಲಕ ಹುಡುಕುತ್ತದೆ (ಐಟಂ ಕೋಡ್, ಉದಾಹರಣೆಗೆ *SAR-MYS-GRN*). ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗಳನ್ನು ಸೇರಿಸಲು ಇದರ ಬದಲು [ಶೀಟ್‌ನಿಂದ ಪ್ರಾಡಕ್ಟ್‌ಗಳನ್ನು ಇಂಪೋರ್ಟ್ ಮಾಡಿ](/help/products/import-products) ಬಳಸಿ.

## 1. Import Updates ತೆರೆಯಿರಿ

1. ಎಡಗಡೆಯ ಮೆನುವಿನಲ್ಲಿ [[1]] **Products** ಒತ್ತಿರಿ.
2. ಮೇಲ್ಭಾಗದಲ್ಲಿ [[2]] **Import Updates** ಒತ್ತಿರಿ.

![Products ಸ್ಕ್ರೀನ್. ಮೆನುವಿನಲ್ಲಿ Products ಅನ್ನು 1 ಎಂದು, Import Updates ಅನ್ನು 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-open.webp "Import Updates ಬಟನ್ Export ಪಕ್ಕದಲ್ಲಿದೆ.")

## 2. ನಿಮ್ಮ ಫೈಲ್ ಮಾಡಿ

ನಿಮ್ಮ ಫೈಲ್‌ಗೆ ಬೇಕಾದ ಕಾಲಂಗಳನ್ನು ವಿಂಡೋ [[1]] ತೋರಿಸುತ್ತದೆ. ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು ಟೆಂಪ್ಲೇಟ್ ಇಲ್ಲ. ಎಕ್ಸೆಲ್ ಅಥವಾ Google Sheets ನಲ್ಲಿ ನೀವೇ ಫೈಲ್ ಮಾಡಿ:

- ಮೊದಲ ಸಾಲಿನಲ್ಲಿ ಕಾಲಂ ಹೆಸರುಗಳು: **sku**, **quantity**, **priceOverride**, **reorderLevel**. ಇವುಗಳನ್ನು ಇದೇ ರೀತಿ ಟೈಪ್ ಮಾಡಿ. ಬೇರೆ ಸ್ಪೆಲ್ಲಿಂಗ್‌ಗಳಲ್ಲಿ ಇವು ಮಾತ್ರ ಕೆಲಸ ಮಾಡುತ್ತವೆ: **SKU**, **Quantity**, **PriceOverride** ಮತ್ತು **ReorderLevel**. *Reorder Level* ಅಥವಾ *QTY* ಅಂತಹ ಹೆಸರನ್ನು ಓದುವುದಿಲ್ಲ.
- ನಂತರ ಪ್ರತಿ ಐಟಂಗೆ ಒಂದು ಸಾಲು. **sku** ಮಾತ್ರ ಕಡ್ಡಾಯ. ಯಾವುದೇ ವಿವರ ಹಾಗೆಯೇ ಇರಬೇಕಾದರೆ ಆ ಸೆಲ್ ಖಾಲಿ ಬಿಡಿ.
- **quantity**: **ಒಂದು ಸ್ಟೋರ್‌ನಲ್ಲಿ** ಇರುವ ಹೊಸ ಪೀಸ್ ಸಂಖ್ಯೆ (ಸ್ಟೋರ್ ಅನ್ನು ಮುಂದಿನ ಹಂತದಲ್ಲಿ ಆರಿಸುತ್ತೀರಿ). ಇದು ಅಲ್ಲಿನ ಹೊಸ ಒಟ್ಟು ಸಂಖ್ಯೆ, ಸೇರಿಸಬೇಕಾದ ಪೀಸ್‌ಗಳಲ್ಲ.
- **reorderLevel**: ಸ್ಟಾಕ್ ಈ ಸಂಖ್ಯೆಗೆ ಇಳಿದಾಗ ನನಗೆ ಎಚ್ಚರಿಸಿ. ಇದು ಎಲ್ಲಾ ಸ್ಟೋರ್‌ಗಳಿಗೂ ಅನ್ವಯಿಸುತ್ತದೆ.
- ಅದನ್ನು **CSV** ಆಗಿ ಸೇವ್ ಮಾಡಿ.

ಉದಾಹರಣೆಗೆ:

| sku | quantity | priceOverride | reorderLevel |
|---|---|---|---|
| SAR-MYS-GRN | 8 | | |
| KUR-COT-BLU-L | 6 | | 4 |

:::warning ಪ್ರಾಡಕ್ಟ್‌ನ Variants ಟ್ಯಾಬ್‌ನ Export ಬಳಸುತ್ತಿದ್ದೀರಾ?
ಅದರ **Quantity** ಕಾಲಂ ನಿಮ್ಮ **ಎಲ್ಲಾ** ಸ್ಟೋರ್‌ಗಳ ಸ್ಟಾಕ್‌ನ ಒಟ್ಟು ಮೊತ್ತ. ಆದರೆ ಇಲ್ಲಿ **quantity** ಎಂದರೆ **ಒಂದು** ಸ್ಟೋರ್‌ನ ಸ್ಟಾಕ್. ಫೈಲ್ ಇಂಪೋರ್ಟ್ ಮಾಡುವ ಮೊದಲು ಆ ಕಾಲಂ ಡಿಲೀಟ್ ಮಾಡಿ. ಇಲ್ಲದಿದ್ದರೆ ನೀವು ಆರಿಸಿದ ಸ್ಟೋರ್‌ಗೆ ಎಲ್ಲಾ ಸ್ಟೋರ್‌ಗಳ ಒಟ್ಟು ಸಂಖ್ಯೆ ಬರುತ್ತದೆ.
:::

![Import Bulk Updates ವಿಂಡೋ. ಉದಾಹರಣೆ ಕಾಲಂಗಳನ್ನು 1 ಎಂದು, Click to select CSV file ಅನ್ನು 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-the-format.webp "ಕಾಲಂ ಹೆಸರುಗಳನ್ನು ಇಲ್ಲಿ ತೋರಿಸಿದಂತೆಯೇ ಟೈಪ್ ಮಾಡಿ.")

:::note priceOverride ಕಾಲಂ ನಿಮ್ಮ ಮಾರುವ ಬೆಲೆಯನ್ನು ಬದಲಿಸುವುದಿಲ್ಲ
**priceOverride** ನಲ್ಲಿನ ಸಂಖ್ಯೆ ಹಳೆಯ, ಅಡ್ಡಗೆರೆ ಹಾಕಿದ ಬೆಲೆಯಾಗಿ ಸೇವ್ ಆಗುತ್ತದೆ. ಸಂಪರ್ಕಿಸಿರುವ ವೆಬ್‌ಸೈಟ್ ಅದನ್ನು ನಿಮ್ಮ ಬೆಲೆಯ ಪಕ್ಕದಲ್ಲಿ ತೋರಿಸಬಹುದು. ಇದು ಕೌಂಟರ್‌ನಲ್ಲಿ ಅಥವಾ ಪ್ರಾಡಕ್ಟ್ ಪೇಜ್‌ನಲ್ಲಿರುವ ಬೆಲೆಯನ್ನು ಬದಲಿಸುವುದಿಲ್ಲ. ಹಲವು ಐಟಂಗಳ ಮಾರುವ ಬೆಲೆ ಬದಲಿಸಲು **SellingPrice** ಕಾಲಂ ಜೊತೆ [ಶೀಟ್‌ನಿಂದ ಪ್ರಾಡಕ್ಟ್‌ಗಳನ್ನು ಇಂಪೋರ್ಟ್ ಮಾಡಿ](/help/products/import-products) ಬಳಸಿ. ಒಂದು ಐಟಂ ಬದಲಿಸಲು [ಸೈಜ್‌ಗಳು, ಬಣ್ಣಗಳು ಮತ್ತು ಬಾರ್‌ಕೋಡ್‌ಗಳು](/help/products/variants-and-barcodes) ನೋಡಿ.
:::

## 3. ಸ್ಟೋರ್ ಆರಿಸಿ ಇಂಪೋರ್ಟ್ ಮಾಡಿ

1. ನಿಮ್ಮ ಫೈಲ್‌ನಲ್ಲಿ **quantity** ಕಾಲಂ ಇದ್ದರೆ, **Apply these quantities to** ಕೆಳಗೆ [[1]] ಸ್ಟೋರ್ ಆರಿಸಿ. ಮೊದಲಿಗೆ ಸ್ಕ್ರೀನ್‌ನ ಮೇಲೆ ಆರಿಸಿರುವ ಸ್ಟೋರ್ ಇರುತ್ತದೆ.
2. ಹಸಿರು ಸಾಲು [[2]] ನೋಡಿ, ಉದಾಹರಣೆಗೆ *Ready to import 2 valid updates into Main Store.*
3. [[3]] **Import Updates** ಒತ್ತಿರಿ.

![ಫೈಲ್ ಆರಿಸಿದ ನಂತರದ ವಿಂಡೋ. ಸ್ಟೋರ್ 1, ಹಸಿರು Ready to import ಸಾಲು 2 ಮತ್ತು Import Updates ಬಟನ್ 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-choose-store-and-import.webp "ಈ ಸಂಖ್ಯೆ ಈ ಸ್ಟೋರ್‌ನ ಸ್ಟಾಕ್ ಮಾತ್ರ.")

## 4. ಫಲಿತಾಂಶ ನೋಡಿ

ಎಷ್ಟು ಐಟಂಗಳು ಬದಲಾದವು ಎಂದು ಸ್ಕ್ರೀನ್‌ನ ಕೆಳಗೆ ಮೆಸೇಜ್ ಬರುತ್ತದೆ, ಉದಾಹರಣೆಗೆ *Successfully updated 2 variants.*

![Successfully updated 2 variants ಎಂಬ ಮೆಸೇಜ್.](4-result.webp)

ಕೆಲವು ಸಾಲುಗಳು ಬದಲಾಗದಿದ್ದರೆ, ಕೆಂಪು ಮೆಸೇಜ್ ಅವುಗಳನ್ನು ತೋರಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ *1 of 2 rows applied. 1 failed — SAR-XYZ: SKU not found.* ಆ ಸಾಲುಗಳನ್ನು ಸರಿಪಡಿಸಿ ಮತ್ತೆ ಇಂಪೋರ್ಟ್ ಮಾಡಿ.

ಹೊಸ ಸಂಖ್ಯೆ ನೋಡಲು **Inventory** ತೆರೆದು SKU ಹುಡುಕಿ. [[1]] ನಿಮ್ಮ ಫೈಲ್‌ನಲ್ಲಿರುವ ಸಂಖ್ಯೆಯೇ ಸ್ಟಾಕ್‌ನಲ್ಲಿ ಕಾಣುತ್ತದೆ.

![SAR-MYS-GRN ಹುಡುಕಿದ Inventory Overview. ಸ್ಟಾಕ್ 8 ಇರುವ ಸಾಲನ್ನು 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](5-check.webp "ಪ್ರತಿ ಬದಲಾವಣೆ ಸ್ಟಾಕ್ ಇತಿಹಾಸದಲ್ಲಿ ಕೈಯಾರೆ ಮಾಡಿದ ತಿದ್ದುಪಡಿಯಾಗಿ ಸೇವ್ ಆಗುತ್ತದೆ.")

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq "Row 2 (SKU-001): No valid update fields provided." ಎಂದು ಬರುತ್ತಿದೆ
ಆ ಸಾಲಿನಲ್ಲಿ SKU ಇದೆ, ಆದರೆ ಬೇರೆ ಎಲ್ಲಾ ಸೆಲ್‌ಗಳು ಖಾಲಿ ಇವೆ. ಸಂಖ್ಯೆ ಅಥವಾ ರೀಆರ್ಡರ್ ಲೆವೆಲ್ ಸೇರಿಸಿ, ಅಥವಾ ಆ ಸಾಲು ಡಿಲೀಟ್ ಮಾಡಿ.
:::

:::faq "SKU not found" ಎಂದು ಬರುತ್ತಿದೆ
ನಿಮ್ಮ ಫೈಲ್‌ನಲ್ಲಿರುವ SKU ಯಾವ ಐಟಂಗೂ ಹೊಂದುತ್ತಿಲ್ಲ. ಸ್ಪೆಲ್ಲಿಂಗ್ ನೋಡಿ. ಪ್ರಾಡಕ್ಟ್‌ನ **Variants** ಟ್ಯಾಬ್‌ನಿಂದ ಸರಿಯಾದ SKU ಕಾಪಿ ಮಾಡಬಹುದು.
:::

:::faq "Invalid quantity." ಎಂದು ಬರುತ್ತಿದೆ
ಸಂಖ್ಯೆ 0 ಅಥವಾ ಅದಕ್ಕಿಂತ ಹೆಚ್ಚು ಇರಬೇಕು. ಅಕ್ಷರಗಳು, ಖಾಲಿ ಜಾಗಗಳು ಮತ್ತು ಮೈನಸ್ ಗುರುತುಗಳನ್ನು ತೆಗೆಯಿರಿ.
:::

:::faq ಇಂಪೋರ್ಟ್ ಬಟನ್ ನನಗೆ ಕೆಲಸ ಮಾಡುತ್ತಿಲ್ಲ
ಒಂದೇ ಸಲ ಸ್ಟಾಕ್ ಬದಲಿಸಲು ಸ್ಟಾಕ್ ಸರಿಪಡಿಸುವ ಪರ್ಮಿಷನ್ ಬೇಕು. ಮಾಲೀಕರು, ಅಡ್ಮಿನ್ ಅಥವಾ ಇನ್ವೆಂಟರಿ ಮ್ಯಾನೇಜರ್ ಇದನ್ನು ಮಾಡಬಹುದು. ನಿಮ್ಮ ಅಂಗಡಿ ಮಾಲೀಕರನ್ನು ಕೇಳಿ.
:::
