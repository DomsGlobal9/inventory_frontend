**Import Updates** ஏற்கனவே உள்ள ஐட்டங்களை மாற்றும். ஒவ்வொரு ஐட்டத்தையும் அதன் **SKU** (ஐட்டம் கோடு, உதாரணமாக *SAR-MYS-GRN*) மூலம் கண்டுபிடிக்கும். புதிய பொருட்களைச் சேர்க்க, இதற்குப் பதிலாக [ஷீட்டிலிருந்து பொருட்களை இம்போர்ட் செய்தல்](/help/products/import-products) பயன்படுத்துங்கள்.

## 1. Import Updates-ஐத் திறக்கவும்

1. இடது பக்க மெனுவில் [[1]] **Products** அழுத்துங்கள்.
2. மேலே [[2]] **Import Updates** அழுத்துங்கள்.

![Products திரை. மெனுவில் Products 1 எனவும், Import Updates 2 எனவும் குறிக்கப்பட்டுள்ளன.](1-open.webp "Import Updates, Export-க்குப் பக்கத்தில் உள்ளது.")

## 2. உங்கள் ஃபைலைத் தயார் செய்யுங்கள்

உங்கள் ஃபைலில் தேவையான காலம்களை [[1]] விண்டோ காட்டும். டவுன்லோட் செய்ய டெம்ப்ளேட் எதுவும் இல்லை. Excel அல்லது Google Sheets-இல் நீங்களே ஃபைலைத் தயார் செய்யுங்கள்:

- முதல் வரியில் காலம் பெயர்கள்: **sku**, **quantity**, **priceOverride**, **reorderLevel**. இவற்றை அப்படியே டைப் செய்யுங்கள். இந்த மாற்று எழுத்துகள் மட்டும் கூட வேலை செய்யும்: **SKU**, **Quantity**, **PriceOverride**, **ReorderLevel**. *Reorder Level* அல்லது *QTY* போன்ற பெயர்கள் படிக்கப்படாது.
- பிறகு ஒவ்வொரு ஐட்டத்துக்கும் ஒரு வரி. **sku** மட்டுமே கட்டாயம். ஒரு விவரத்தை அப்படியே வைக்க, அந்த செல்லைக் காலியாக விடுங்கள்.
- **quantity**: **ஒரு ஸ்டோரில்** உள்ள புதிய பீஸ் எண்ணிக்கை (ஸ்டோரை அடுத்த படியில் தேர்ந்தெடுப்பீர்கள்). அது அங்கே உள்ள புதிய மொத்தம், கூட்ட வேண்டிய பீஸ்கள் அல்ல.
- **reorderLevel**: ஸ்டாக் இந்த எண்ணுக்கு இறங்கும்போது எனக்கு அலர்ட் கொடு. இது எல்லா ஸ்டோர்களுக்கும் பொருந்தும்.
- **CSV** ஆகச் சேமியுங்கள்.

உதாரணமாக:

| sku | quantity | priceOverride | reorderLevel |
|---|---|---|---|
| SAR-MYS-GRN | 8 | | |
| KUR-COT-BLU-L | 6 | | 4 |

:::warning பொருளின் Variants டேபில் உள்ள Export ஃபைலைப் பயன்படுத்துகிறீர்களா?
அதில் உள்ள **Quantity** காலம், உங்கள் **எல்லா** ஸ்டோர்களின் ஸ்டாக்கையும் கூட்டிய மொத்தம். ஆனால் இங்கே **quantity** என்றால் **ஒரு** ஸ்டோரின் ஸ்டாக் மட்டும். ஃபைலை இம்போர்ட் செய்வதற்கு முன் அந்த காலத்தை நீக்குங்கள். இல்லையென்றால், நீங்கள் தேர்ந்தெடுக்கும் ஸ்டோருக்கு எல்லா ஸ்டோர்களின் மொத்தமும் போய்விடும்.
:::

[[2]] **Click to select CSV file** அழுத்தி உங்கள் ஃபைலைத் தேர்ந்தெடுங்கள்.

![Import Bulk Updates விண்டோ. உதாரண காலம்கள் 1 எனவும், Click to select CSV file 2 எனவும் குறிக்கப்பட்டுள்ளன.](2-the-format.webp "காலம் பெயர்களைக் காட்டியபடியே சரியாக டைப் செய்யுங்கள்.")

:::note priceOverride காலம் உங்கள் விற்பனை விலையை மாற்றாது
**priceOverride**-இல் உள்ள எண், பழைய அடித்த விலையாகச் சேமிக்கப்படும். இணைக்கப்பட்ட வெப்சைட் அதை உங்கள் விலைக்குப் பக்கத்தில் காட்டலாம். கவுண்டரிலோ பொருளின் பக்கத்திலோ உள்ள விலையை இது மாற்றாது. பல ஐட்டங்களின் விற்பனை விலையை மாற்ற, **SellingPrice** காலத்துடன் [ஷீட்டிலிருந்து பொருட்களை இம்போர்ட் செய்தல்](/help/products/import-products) பயன்படுத்துங்கள். ஒரு ஐட்டத்தை மாற்ற, [சைஸ், கலர் மற்றும் பார்கோடுகள்](/help/products/variants-and-barcodes) பாருங்கள்.
:::

## 3. ஸ்டோரைத் தேர்ந்தெடுத்து இம்போர்ட் செய்யுங்கள்

1. உங்கள் ஃபைலில் **quantity** காலம் இருந்தால், **Apply these quantities to**-க்குக் கீழே [[1]] ஸ்டோரைத் தேர்ந்தெடுங்கள். திரையின் மேலே தேர்ந்தெடுத்த ஸ்டோரே முதலில் இருக்கும்.
2. பச்சை வரியைச் [[2]] சரிபாருங்கள், உதாரணமாக *Ready to import 2 valid updates into Main Store.*
3. [[3]] **Import Updates** அழுத்துங்கள்.

![ஃபைலைத் தேர்ந்தெடுத்த பிறகு விண்டோ. ஸ்டோர் 1, பச்சை Ready to import வரி 2, Import Updates பட்டன் 3 எனக் குறிக்கப்பட்டுள்ளன.](3-choose-store-and-import.webp "இந்த அளவு இந்த ஸ்டோரின் ஸ்டாக் மட்டுமே.")

## 4. முடிவைப் பாருங்கள்

எத்தனை ஐட்டங்கள் மாற்றப்பட்டன என்று திரையின் கீழே ஒரு மெசேஜ் சொல்லும், உதாரணமாக *Successfully updated 2 variants.*

![Successfully updated 2 variants என்ற மெசேஜ்.](4-result.webp)

சில வரிகளை மாற்ற முடியவில்லை என்றால், ஒரு சிவப்பு மெசேஜ் அவற்றைக் காட்டும், உதாரணமாக *1 of 2 rows applied. 1 failed — SAR-XYZ: SKU not found.* அந்த வரிகளைச் சரிசெய்து மீண்டும் இம்போர்ட் செய்யுங்கள்.

புதிய எண்ணைப் பார்க்க, **Inventory** திறந்து SKU-வைத் தேடுங்கள். [[1]] உங்கள் ஃபைலில் உள்ள எண் ஸ்டாக்கில் தெரியும்.

![SAR-MYS-GRN தேடப்பட்ட Inventory Overview. ஸ்டாக் 8 உள்ள வரி 1 எனக் குறிக்கப்பட்டுள்ளது.](5-check.webp "ஒவ்வொரு மாற்றமும் ஸ்டாக் ஹிஸ்டரியில் கைமுறைத் திருத்தமாகச் சேமிக்கப்படும்.")

## பொதுவான பிரச்சினைகள்

:::faq "Row 2 (SKU-001): No valid update fields provided." என்று வருகிறது
அந்த வரியில் SKU உள்ளது, ஆனால் மற்ற எல்லா செல்களும் காலியாக உள்ளன. அளவு அல்லது ரீஆர்டர் லெவலைச் சேருங்கள், அல்லது அந்த வரியை நீக்குங்கள்.
:::

:::faq "SKU not found" என்று வருகிறது
உங்கள் ஃபைலில் உள்ள SKU எந்த ஐட்டத்துடனும் பொருந்தவில்லை. எழுத்துப்பிழையைப் பாருங்கள். பொருளின் **Variants** டேபிலிருந்து சரியான SKU-வை காப்பி செய்யலாம்.
:::

:::faq "Invalid quantity." என்று வருகிறது
அளவு 0 அல்லது அதற்கு மேற்பட்ட எண்ணாக இருக்க வேண்டும். எழுத்துகள், இடைவெளிகள், மைனஸ் குறிகளை நீக்குங்கள்.
:::

:::faq இம்போர்ட் பட்டன் எனக்கு வேலை செய்யவில்லை
ஸ்டாக்கை மொத்தமாக மாற்ற, ஸ்டாக்கைத் திருத்தும் அனுமதி வேண்டும். உரிமையாளர், அட்மின் அல்லது இன்வென்டரி மேலாளர் இதைச் செய்யலாம். உங்கள் கடை உரிமையாளரிடம் கேளுங்கள்.
:::
