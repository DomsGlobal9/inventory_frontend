ಸೇರಿಸಲು ಹಲವು ಪ್ರಾಡಕ್ಟ್‌ಗಳಿದ್ದಾಗ ಇದನ್ನು ಬಳಸಿ, ಉದಾಹರಣೆಗೆ ಎಕ್ಸೆಲ್‌ನಲ್ಲಿರುವ ನಿಮ್ಮ ಪೂರ್ತಿ ಕ್ಯಾಟಲಾಗ್. ಶೀಟ್‌ನ ಪ್ರತಿ ಸಾಲು ಒಂದು ವೇರಿಯಂಟ್: ಒಂದು ಪ್ರಾಡಕ್ಟ್‌ನ ಒಂದು ಬಣ್ಣ ಮತ್ತು ಸೈಜ್.

## 1. Import Products ತೆರೆಯಿರಿ

1. ಎಡಗಡೆಯ ಮೆನುವಿನಲ್ಲಿ [[1]] **Products** ಒತ್ತಿರಿ.
2. ಮೇಲ್ಭಾಗದಲ್ಲಿ [[2]] **Import Products** ಒತ್ತಿರಿ.

![Products ಸ್ಕ್ರೀನ್. ಮೆನುವಿನಲ್ಲಿ Products ಅನ್ನು 1 ಎಂದು, Import Products ಬಟನ್ ಅನ್ನು 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-open.webp "Import Products ಬಟನ್ Add Product ಪಕ್ಕದಲ್ಲಿದೆ.")

## 2. ಟೆಂಪ್ಲೇಟ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ತುಂಬಿರಿ

1. [[1]] **Download template** ಒತ್ತಿರಿ. *product-import-template.csv* ಎಂಬ ಫೈಲ್ ಸಿಗುತ್ತದೆ. ಅದನ್ನು ಎಕ್ಸೆಲ್ ಅಥವಾ Google Sheets ನಲ್ಲಿ ತೆರೆಯಿರಿ.
2. ಟೆಂಪ್ಲೇಟ್‌ನಲ್ಲಿ ಈಗಾಗಲೇ ಮೂರು ಉದಾಹರಣೆ ಸಾಲುಗಳಿವೆ. ಅವುಗಳ ಬದಲು ನಿಮ್ಮ ಪ್ರಾಡಕ್ಟ್‌ಗಳನ್ನು ಹಾಕಿ. ಮೊದಲ ಸಾಲನ್ನು (ಕಾಲಂ ಹೆಸರುಗಳು) ಹಾಗೆಯೇ ಇಡಿ.
3. ಫೈಲ್ ಅನ್ನು **.xlsx** ಅಥವಾ **.csv** ಆಗಿ ಸೇವ್ ಮಾಡಿ.
4. ScaleEzy ಗೆ ಹಿಂದಿರುಗಿ, [[2]] **Choose a file, or drop one here** ಒತ್ತಿ ನಿಮ್ಮ ಫೈಲ್ ಆರಿಸಿ. ಫೈಲ್ ಅನ್ನು ಬಾಕ್ಸ್‌ನ ಮೇಲೆ ಎಳೆದು ಬಿಡಲೂಬಹುದು.

![Import products ವಿಂಡೋ. Download template ಅನ್ನು 1 ಎಂದು, ಫೈಲ್ ಬಾಕ್ಸ್ ಅನ್ನು 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-template-and-file.webp "ಇಂಪೋರ್ಟ್ ಬಟನ್ ಒತ್ತುವವರೆಗೆ ಏನೂ ಸೇವ್ ಆಗುವುದಿಲ್ಲ.")

### ಪ್ರತಿ ಕಾಲಂನಲ್ಲಿ ಏನು ಹಾಕಬೇಕು

| ಕಾಲಂ | ಏನು ಟೈಪ್ ಮಾಡಬೇಕು |
|---|---|
| **ProductKey** | ನೀವೇ ಇಡುವ ಒಂದು ಸಣ್ಣ ಹೆಸರು, ಉದಾಹರಣೆಗೆ *kanchi-silk*. ಒಂದೇ ಪ್ರಾಡಕ್ಟ್‌ನ ಎಲ್ಲಾ ಸಾಲುಗಳಿಗೆ ಇದೇ ಕೀ ಕೊಡಿ. ಸಾಲುಗಳನ್ನು ಗುಂಪು ಮಾಡಲು ಮಾತ್ರ ಇದು ಬಳಕೆಯಾಗುತ್ತದೆ. |
| **Title** | ಪ್ರಾಡಕ್ಟ್‌ನ ಹೆಸರು. ಪ್ರತಿ ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗೆ ಒಮ್ಮೆ ಬೇಕು. |
| **Category** | WOMEN, MEN, KIDS ಅಥವಾ UNISEX. ಪ್ರತಿ ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗೆ ಬೇಕು. |
| **DressType**, **Fabric**, **Brand** | ಕಡ್ಡಾಯವಲ್ಲ. |
| **BasePrice** | ಮಾರುವ ಬೆಲೆ. ಪ್ರತಿ ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗೆ ಬೇಕು. |
| **Size**, **Color** | ಪ್ರತಿ ಸಾಲಿನಲ್ಲಿ ಕನಿಷ್ಠ ಸೈಜ್ ಅಥವಾ ಬಣ್ಣ ಇರಬೇಕು. ಸೀರೆಗೆ *Free Size* ಹಾಕಿ. |
| **Quantity** | ಈಗ ನಿಮ್ಮ ಬಳಿ ಎಷ್ಟು ಪೀಸ್ ಇವೆ. ಪೂರ್ಣ ಸಂಖ್ಯೆ ಮಾತ್ರ. ಇದು ಒಂದೇ ಸ್ಟೋರ್‌ಗೆ ಹೋಗುತ್ತದೆ, ಕೆಳಗಿನ *ಯಾವ ಸ್ಟೋರ್‌ಗೆ ಸ್ಟಾಕ್ ಹೋಯಿತು ಎಂದು ನೋಡಿ* ನೋಡಿ. |
| **CostPrice** | ಒಂದು ಪೀಸ್‌ಗೆ ನಿಮಗೆ ಆದ ಖರ್ಚು. |
| **SellingPrice** | ಈ ಬಣ್ಣ ಅಥವಾ ಸೈಜ್ BasePrice ಗಿಂತ ಬೇರೆ ಬೆಲೆಗೆ ಮಾರಾಟವಾದರೆ ಮಾತ್ರ. |
| **ReorderLevel** | ಸ್ಟಾಕ್ ಈ ಸಂಖ್ಯೆಗೆ ಇಳಿದಾಗ ನನಗೆ ಎಚ್ಚರಿಸಿ. |
| **SKU** | ಖಾಲಿ ಬಿಡಿ. ScaleEzy ತಾನೇ ಮಾಡುತ್ತದೆ. |
| **ProductCode** | ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗಳಿಗೆ ಖಾಲಿ ಬಿಡಿ. ಈಗಾಗಲೇ ಇರುವ ಪ್ರಾಡಕ್ಟ್‌ಗೆ ಸೈಜ್‌ಗಳು ಮತ್ತು ಬಣ್ಣಗಳನ್ನು ಸೇರಿಸಲು, ಅಥವಾ ಅವುಗಳ ಬೆಲೆ ಬದಲಿಸಲು, ಅದರ ಪ್ರಾಡಕ್ಟ್ ಕೋಡ್ ಇಲ್ಲಿ ಟೈಪ್ ಮಾಡಿ (ಉದಾಹರಣೆಗೆ *PRD-000012*, ಪ್ರಾಡಕ್ಟ್ ಹೆಸರಿನ ಕೆಳಗೆ ಕಾಣುತ್ತದೆ). |

:::tip ಖಾಲಿ ಸೆಲ್ ಏನನ್ನೂ ಬದಲಿಸುವುದಿಲ್ಲ
ಒಂದು ಸೆಲ್ ಖಾಲಿ ಬಿಟ್ಟರೆ, ScaleEzy ಆ ವಿವರವನ್ನು ಹಾಗೆಯೇ ಬಿಡುತ್ತದೆ.
:::

:::note ಪ್ರಾಡಕ್ಟ್ ಕೋಡ್ ಏನನ್ನು ಬದಲಿಸಬಹುದು
ಈಗಾಗಲೇ ಇರುವ ಪ್ರಾಡಕ್ಟ್‌ಗೆ, ಇಂಪೋರ್ಟ್ ಪ್ರತಿ ಸೈಜ್ ಮತ್ತು ಬಣ್ಣದ ಮೂರು ವಿಷಯಗಳನ್ನು ಮಾತ್ರ ಬದಲಿಸುತ್ತದೆ: **SellingPrice**, **CostPrice** ಮತ್ತು **ReorderLevel**. ಹೊಸ ಸೈಜ್ ಅಥವಾ ಬಣ್ಣ ಇದ್ದರೆ, ಅದನ್ನು ಅದರ **Quantity** ಜೊತೆ ಸೇರಿಸುತ್ತದೆ.

**Title**, **BasePrice**, **Category**, **DressType**, **Fabric** ಮತ್ತು **Brand** ನೀವು ಹೊಸದಾಗಿ ಏನು ಟೈಪ್ ಮಾಡಿದರೂ ಹಿಂದಿನಂತೆಯೇ ಇರುತ್ತವೆ. ಈಗಾಗಲೇ ಇರುವ ಸೈಜ್ ಅಥವಾ ಬಣ್ಣದ **Quantity** ಅನ್ನು ಕಡೆಗಣಿಸಲಾಗುತ್ತದೆ. ಆ ಸ್ಟಾಕ್ ಬದಲಿಸಲು [ಸ್ಟಾಕ್ ಅಥವಾ ರೀಆರ್ಡರ್ ಲೆವೆಲ್ ಒಂದೇ ಸಲ ಬದಲಿಸಿ](/help/products/bulk-updates) ಬಳಸಿ.
:::

## 3. ಏನಾಗುತ್ತದೆ ಎಂದು ನೋಡಿ

ScaleEzy ಫೈಲ್ ಓದಿ, ತಾನು ಏನು ಮಾಡುತ್ತದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ. ಇನ್ನೂ ಏನೂ ಸೇವ್ ಆಗಿಲ್ಲ.

1. [[1]] **New** ಎಷ್ಟು ಹೊಸ ವೇರಿಯಂಟ್‌ಗಳು ಮತ್ತು ಪ್ರಾಡಕ್ಟ್‌ಗಳು ಸೇರುತ್ತವೆ ಎಂದು ತೋರಿಸುತ್ತದೆ. **Update** ಈಗಾಗಲೇ ಇರುವ ಯಾವ ಸೈಜ್ ಮತ್ತು ಬಣ್ಣಗಳ ಮಾರುವ ಬೆಲೆ, ಖರ್ಚು ಅಥವಾ ರೀಆರ್ಡರ್ ಲೆವೆಲ್ ಬದಲಾಗುತ್ತದೆಯೋ ಅವುಗಳನ್ನು ಎಣಿಸುತ್ತದೆ. **Unchanged** ಹಾಗೆಯೇ ಉಳಿಯುವವುಗಳನ್ನು ಎಣಿಸುತ್ತದೆ.
2. [[2]] **Worth checking** ನೀವು ಓದಬೇಕಾದ ವಿಷಯಗಳನ್ನು ತೋರಿಸುತ್ತದೆ. **Must be fixed** (ಕೆಂಪು ಬಣ್ಣದಲ್ಲಿ) ತಪ್ಪುಗಳನ್ನು ತೋರಿಸುತ್ತದೆ. ನಿಮ್ಮ ಶೀಟ್‌ನ ಯಾವ ಸಾಲು ಸರಿಪಡಿಸಬೇಕು ಎಂದು ಸಾಲಿನ ಸಂಖ್ಯೆ ಹೇಳುತ್ತದೆ.
3. ಎಚ್ಚರಿಕೆಗಳಿದ್ದರೆ, ಅವುಗಳನ್ನು ಓದಿ [[3]] **I have read the warnings above and want to import anyway.** ಟಿಕ್ ಮಾಡಿ.

![ಪ್ರಿವ್ಯೂ. New ನಲ್ಲಿ 3 ವೇರಿಯಂಟ್‌ಗಳು ಮತ್ತು 2 ಪ್ರಾಡಕ್ಟ್‌ಗಳು, 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ. ಎಚ್ಚರಿಕೆ ಪಟ್ಟಿ 2 ಮತ್ತು ಟಿಕ್ ಬಾಕ್ಸ್ 3.](3-check-the-preview.webp "ಶೀಟ್‌ನಲ್ಲಿ ಫೋಟೋ ಇರಲು ಸಾಧ್ಯವಿಲ್ಲದ ಕಾರಣ ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗಳು ಯಾವಾಗಲೂ ಡ್ರಾಫ್ಟ್ ಆಗಿ ಬರುತ್ತವೆ.")

:::note ಏನಾದರೂ ಸರಿಪಡಿಸಬೇಕೇ?
ನಿಮ್ಮ ಶೀಟ್‌ನಲ್ಲಿ ಆ ಸಾಲುಗಳನ್ನು ಸರಿಪಡಿಸಿ, ಸೇವ್ ಮಾಡಿ, ಮತ್ತೆ ಲೋಡ್ ಮಾಡಲು **Choose another file** ಒತ್ತಿರಿ.
:::

## 4. ಇಂಪೋರ್ಟ್ ಮಾಡಿ

[[1]] **Import 3 variants** ಒತ್ತಿರಿ. ಎಷ್ಟು ವೇರಿಯಂಟ್‌ಗಳು ಸೇರುತ್ತವೆ ಅಥವಾ ಬದಲಾಗುತ್ತವೆ ಎಂಬುದೇ ಈ ಸಂಖ್ಯೆ.

![ಎಚ್ಚರಿಕೆ ಬಾಕ್ಸ್ ಟಿಕ್ ಮಾಡಿದ ನಂತರ ಇಂಪೋರ್ಟ್ ಬಟನ್, 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-import.webp "ದೊಡ್ಡ ಫೈಲ್‌ಗೆ ಕೆಲವು ಸೆಕೆಂಡುಗಳು ಬೇಕು.")

## 5. ನಿಮ್ಮ ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗಳನ್ನು ಹುಡುಕಿ

ಹೊಸ ಪ್ರಾಡಕ್ಟ್‌ಗಳು **ಡ್ರಾಫ್ಟ್‌ಗಳು**. ಅವುಗಳನ್ನು ನೋಡಲು **Products** ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ **Drafts only** ಆರಿಸಿ. [[1]] ನೀವು ಇಂಪೋರ್ಟ್ ಮಾಡಿದ ಪ್ರಾಡಕ್ಟ್‌ಗಳು ಪಟ್ಟಿಯಲ್ಲಿವೆ.

![Drafts only ಫಿಲ್ಟರ್ ಮಾಡಿದ Products ಪಟ್ಟಿ, Printed Cotton Kurti ಮತ್ತು Chanderi Cotton Saree ಅನ್ನು 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](5-drafts.webp "ಸ್ಟೇಟಸ್ DRAFT: ಇನ್ನೂ ಮಾರಾಟಕ್ಕೆ ಇಲ್ಲ.")

ಮುಂದೆ: ಫೋಟೋಗಳನ್ನು ಸೇರಿಸಿ ಪಬ್ಲಿಷ್ ಮಾಡಿ. [ಪ್ರಾಡಕ್ಟ್ ಫೋಟೋಗಳು](/help/products/photos) ಮತ್ತು [ಪಬ್ಲಿಷ್, ಆರ್ಕೈವ್ ಮತ್ತು ಡಿಲೀಟ್](/help/products/publish-archive-delete) ನೋಡಿ.

:::warning ಯಾವ ಸ್ಟೋರ್‌ಗೆ ಸ್ಟಾಕ್ ಹೋಯಿತು ಎಂದು ನೋಡಿ
ಇಂಪೋರ್ಟ್ ಮಾಡಿದ ಸ್ಟಾಕ್ **ಒಂದೇ** ಲೊಕೇಶನ್‌ಗೆ ಹೋಗುತ್ತದೆ: ಸ್ಟೋರ್ ಕೋಡ್‌ಗಳನ್ನು A ಯಿಂದ Z ವರೆಗೆ ಜೋಡಿಸಿದಾಗ ಮೊದಲು ಬರುವ ಆಕ್ಟಿವ್ ಸ್ಟೋರ್. ಸ್ಕ್ರೀನ್‌ನ ಮೇಲೆ ಆರಿಸಿರುವ ಸ್ಟೋರ್ ಅನ್ನು ಇದು ಬಳಸುವುದಿಲ್ಲ. *GODOWN* ಮತ್ತು *MAIN* ಇರುವ ಅಂಗಡಿಯಲ್ಲಿ ಸ್ಟಾಕ್ ಗೋಡೌನ್‌ಗೆ ಹೋಗುತ್ತದೆ. **Inventory** ನಲ್ಲಿ ನೋಡಿ, ಬೇಕಿದ್ದರೆ ಸ್ಥಳಾಂತರಿಸಲು [ಟ್ರಾನ್ಸ್‌ಫರ್](/help/transfers/transfers) ಬಳಸಿ.
:::

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq "This file creates new products. You do not have permission to add products." ಎಂದು ಬರುತ್ತಿದೆ
ನಿಮ್ಮ ರೋಲ್‌ಗೆ ಪ್ರಾಡಕ್ಟ್ ಸೇರಿಸಲು ಆಗುವುದಿಲ್ಲ. ಮಾಲೀಕರು, ಅಡ್ಮಿನ್ ಅಥವಾ ಇನ್ವೆಂಟರಿ ಮ್ಯಾನೇಜರ್ ಮಾತ್ರ ಸೇರಿಸಬಹುದು. ಬೆಲೆಗಳಿಗೆ (*This file sets selling prices*) ಮತ್ತು ಖರ್ಚುಗಳಿಗೆ (*This file sets cost prices*) ಇದೇ ರೀತಿಯ ಮೆಸೇಜ್ ಬರುತ್ತದೆ.
:::

:::faq "…already exists, so its Quantity is ignored" ಎಂದು ಬರುತ್ತಿದೆ

:::faq "You already have a product called …" ಎಂದು ಬರುತ್ತಿದೆ
ಈ ಹೆಸರಿನ ಪ್ರಾಡಕ್ಟ್ ಈಗಾಗಲೇ ಇದೆ, ಆದ್ದರಿಂದ ಫೈಲ್ ಇನ್ನೊಂದು ಪ್ರಾಡಕ್ಟ್ ಸೇರಿಸುತ್ತದೆ. ಇರುವ ಪ್ರಾಡಕ್ಟ್‌ಗೇ ಸೈಜ್‌ಗಳು ಮತ್ತು ಬಣ್ಣಗಳನ್ನು ಸೇರಿಸಲು, ಅಥವಾ ಅವುಗಳ ಬೆಲೆ ಬದಲಿಸಲು, ಅದರ ಪ್ರಾಡಕ್ಟ್ ಕೋಡ್ ಅನ್ನು **ProductCode** ಕಾಲಂನಲ್ಲಿ ಹಾಕಿ. ಈ ರೀತಿ ಹೆಸರು ಮತ್ತು ಬೇಸ್ ಪ್ರೈಸ್ ಬದಲಿಸಲು ಆಗುವುದಿಲ್ಲ.
:::
