சேர்க்க நிறைய பொருட்கள் இருக்கும்போது இதைப் பயன்படுத்துங்கள், உதாரணமாக Excel-இல் உள்ள உங்கள் முழு கேட்டலாக். ஷீட்டின் ஒவ்வொரு வரியும் ஒரு வேரியண்ட்: ஒரு பொருளின் ஒரு கலர் மற்றும் சைஸ்.

## 1. Import Products-ஐத் திறக்கவும்

1. இடது பக்க மெனுவில் [[1]] **Products** அழுத்துங்கள்.
2. மேலே [[2]] **Import Products** அழுத்துங்கள்.

![Products திரை. மெனுவில் Products 1 எனவும், Import Products பட்டன் 2 எனவும் குறிக்கப்பட்டுள்ளன.](1-open.webp "Import Products, Add Product-க்குப் பக்கத்தில் உள்ளது.")

## 2. டெம்ப்ளேட்டை டவுன்லோட் செய்து நிரப்புங்கள்

1. [[1]] **Download template** அழுத்துங்கள். *product-import-template.csv* என்ற ஃபைல் கிடைக்கும். அதை Excel அல்லது Google Sheets-இல் திறக்கவும்.
2. டெம்ப்ளேட்டில் ஏற்கனவே மூன்று உதாரண வரிகள் உள்ளன. அவற்றுக்குப் பதிலாக உங்கள் பொருட்களை எழுதுங்கள். முதல் வரியை (காலம் பெயர்கள்) அப்படியே விடுங்கள்.
3. ஃபைலை **.xlsx** அல்லது **.csv** ஆகச் சேமியுங்கள்.
4. மீண்டும் ScaleEzy-இல் [[2]] **Choose a file, or drop one here** அழுத்தி உங்கள் ஃபைலைத் தேர்ந்தெடுங்கள். ஃபைலை இழுத்து அந்தப் பெட்டியில் போடவும் செய்யலாம்.

![Import products விண்டோ. Download template 1 எனவும், ஃபைல் பெட்டி 2 எனவும் குறிக்கப்பட்டுள்ளன.](2-template-and-file.webp "இம்போர்ட் பட்டனை அழுத்தும் வரை எதுவும் சேமிக்கப்படாது.")

### ஒவ்வொரு காலத்திலும் என்ன எழுத வேண்டும்

| காலம் | என்ன டைப் செய்ய வேண்டும் |
|---|---|
| **ProductKey** | நீங்களே வைக்கும் ஒரு சின்ன பெயர், உதாரணமாக *kanchi-silk*. ஒரே பொருளின் எல்லா வரிகளுக்கும் ஒரே key கொடுங்கள். வரிகளை ஒன்றாகச் சேர்க்க மட்டுமே இது பயன்படும். |
| **Title** | பொருளின் பெயர். ஒவ்வொரு புதிய பொருளுக்கும் ஒருமுறை தேவை. |
| **Category** | WOMEN, MEN, KIDS அல்லது UNISEX. ஒவ்வொரு புதிய பொருளுக்கும் தேவை. |
| **DressType**, **Fabric**, **Brand** | கட்டாயம் இல்லை. |
| **BasePrice** | விற்பனை விலை. ஒவ்வொரு புதிய பொருளுக்கும் தேவை. |
| **Size**, **Color** | ஒவ்வொரு வரியிலும் குறைந்தது ஒரு சைஸ் அல்லது ஒரு கலர் வேண்டும். சேலைக்கு *Free Size* போடுங்கள். |
| **Quantity** | இப்போது உங்களிடம் எத்தனை பீஸ் உள்ளன. முழு எண்கள் மட்டும். இது ஒரே ஸ்டோருக்குப் போகும், கீழே உள்ள *எந்த ஸ்டோருக்கு ஸ்டாக் போனது என்று பாருங்கள்* பாருங்கள். |
| **CostPrice** | ஒரு பீஸை நீங்கள் வாங்கிய விலை. |
| **SellingPrice** | இந்தக் கலர் அல்லது சைஸ் BasePrice-இலிருந்து வேறு விலையில் விற்றால் மட்டும். |
| **ReorderLevel** | ஸ்டாக் இந்த எண்ணுக்கு இறங்கும்போது எனக்கு அலர்ட் கொடு. |
| **SKU** | காலியாக விடுங்கள். ScaleEzy உருவாக்கும். |
| **ProductCode** | புதிய பொருட்களுக்குக் காலியாக விடுங்கள். ஏற்கனவே உள்ள பொருளுக்கு சைஸ், கலர் சேர்க்க அல்லது அவற்றின் விலையை மாற்ற, அதன் புராடக்ட் கோடை இங்கே டைப் செய்யுங்கள் (உதாரணமாக *PRD-000012*, பொருளின் பெயருக்குக் கீழே தெரியும்). |

:::tip காலியான செல் எதையும் மாற்றாது
ஒரு செல்லைக் காலியாக விட்டால், அந்த விவரத்தை ScaleEzy அப்படியே விட்டுவிடும்.
:::

:::note புராடக்ட் கோடு மூலம் என்ன மாற்றலாம்
ஏற்கனவே உள்ள பொருளுக்கு, இம்போர்ட் ஒவ்வொரு சைஸ் மற்றும் கலரிலும் மூன்றை மட்டுமே மாற்றும்: **SellingPrice**, **CostPrice**, **ReorderLevel**. புதிய சைஸ் அல்லது கலர் இருந்தால், அதன் **Quantity**-உடன் சேர்க்கும்.

**Title**, **BasePrice**, **Category**, **DressType**, **Fabric**, **Brand** ஆகியவற்றில் புதிதாக ஏதாவது டைப் செய்தாலும் அவை முன்பு இருந்தபடியே இருக்கும். ஏற்கனவே உள்ள சைஸ் அல்லது கலரின் **Quantity** கணக்கில் எடுக்கப்படாது. அந்த ஸ்டாக்கை மாற்ற, [ஸ்டாக் அல்லது ரீஆர்டர் லெவலை மொத்தமாக மாற்றுதல்](/help/products/bulk-updates) பயன்படுத்துங்கள்.
:::

## 3. என்ன நடக்கும் என்று பாருங்கள்

ScaleEzy ஃபைலைப் படித்து, என்ன செய்யப் போகிறது என்று காட்டும். இன்னும் எதுவும் சேமிக்கப்படவில்லை.

1. [[1]] **New** எத்தனை புதிய வேரியண்ட்கள் மற்றும் பொருட்கள் சேர்க்கப்படும் என்று காட்டும். **Update**, ஏற்கனவே உள்ள சைஸ் மற்றும் கலர்களில் விற்பனை விலை, காஸ்ட் அல்லது ரீஆர்டர் லெவல் மாறப்போகும் எண்ணிக்கையைக் காட்டும். **Unchanged**, எதுவும் மாறாதவற்றின் எண்ணிக்கையைக் காட்டும்.
2. [[2]] **Worth checking** நீங்கள் படிக்க வேண்டியவற்றைக் காட்டும். **Must be fixed** (சிவப்பில்) தவறுகளைக் காட்டும். உங்கள் ஷீட்டில் எந்த வரியைச் சரிசெய்ய வேண்டும் என்று வரி எண் சொல்லும்.
3. எச்சரிக்கைகள் இருந்தால், அவற்றைப் படித்து [[3]] **I have read the warnings above and want to import anyway.** டிக் செய்யுங்கள்.

![முன்னோட்டம். New 3 வேரியண்ட்கள், 2 பொருட்கள் எனக் காட்டுகிறது, 1 எனக் குறிக்கப்பட்டுள்ளது. எச்சரிக்கை லிஸ்ட் 2, டிக் பெட்டி 3.](3-check-the-preview.webp "ஷீட்டில் போட்டோக்கள் வர முடியாது, அதனால் புதிய பொருட்கள் எப்போதும் டிராஃப்டாகவே வரும்.")

:::note ஏதாவது சரிசெய்ய வேண்டுமா?
உங்கள் ஷீட்டில் அந்த வரிகளைச் சரிசெய்து, சேமித்து, மீண்டும் லோட் செய்ய **Choose another file** அழுத்துங்கள்.
:::

## 4. இம்போர்ட் செய்யுங்கள்

[[1]] **Import 3 variants** அழுத்துங்கள். எத்தனை வேரியண்ட்கள் சேர்க்கப்படும் அல்லது மாற்றப்படும் என்பதே அந்த எண்.

![எச்சரிக்கை பெட்டியை டிக் செய்த பிறகு இம்போர்ட் பட்டன், 1 எனக் குறிக்கப்பட்டுள்ளது.](4-import.webp "பெரிய ஃபைலுக்குச் சில விநாடிகள் ஆகும்.")

திரையின் கீழே *Imported 2 products and 3 variants* போன்ற மெசேஜ் தெரியும்.

## 5. உங்கள் புதிய பொருட்களைப் பாருங்கள்

புதிய பொருட்கள் **டிராஃப்ட்கள்**. அவற்றைப் பார்க்க **Products**-இன் மேலே **Drafts only** தேர்ந்தெடுங்கள். [[1]] நீங்கள் இம்போர்ட் செய்த பொருட்கள் லிஸ்டில் இருக்கும்.

![Drafts only ஃபில்டருடன் Products லிஸ்ட். Printed Cotton Kurti மற்றும் Chanderi Cotton Saree 1 எனக் குறிக்கப்பட்டுள்ளன.](5-drafts.webp "நிலை DRAFT: இன்னும் விற்பனைக்கு இல்லை.")

அடுத்து: போட்டோக்களைச் சேர்த்து பப்ளிஷ் செய்யுங்கள். [பொருளின் போட்டோக்கள்](/help/products/photos) மற்றும் [பப்ளிஷ், ஆர்கைவ் மற்றும் டெலீட்](/help/products/publish-archive-delete) பாருங்கள்.

:::warning எந்த ஸ்டோருக்கு ஸ்டாக் போனது என்று பாருங்கள்
இம்போர்ட் செய்த ஸ்டாக் **ஒரே** இடத்துக்குப் போகும்: லொகேஷன் கோடுகளை A முதல் Z வரை வரிசைப்படுத்தும்போது முதலில் வரும் ஆக்டிவ் இடம். திரையின் மேலே தேர்ந்தெடுத்த ஸ்டோரை இது பயன்படுத்தாது. *GODOWN* மற்றும் *MAIN* உள்ள கடையில், ஸ்டாக் குடோனுக்குப் போகும். **Inventory**-இல் சரிபாருங்கள், தேவைப்பட்டால் நகர்த்த [டிரான்ஸ்ஃபர்](/help/transfers/transfers) பயன்படுத்துங்கள்.
:::

## பொதுவான பிரச்சினைகள்

:::faq "This file creates new products. You do not have permission to add products." என்று வருகிறது
உங்கள் ரோலால் பொருட்களைச் சேர்க்க முடியாது. உரிமையாளர், அட்மின் அல்லது இன்வென்டரி மேலாளர் மட்டுமே சேர்க்க முடியும். விலைகளுக்கும் (*This file sets selling prices*) காஸ்ட்களுக்கும் (*This file sets cost prices*) இதே மாதிரி மெசேஜ் வரும்.
:::

:::faq "…already exists, so its Quantity is ignored" என்று வருகிறது
இந்த வரி ஏற்கனவே உள்ள ஒரு வேரியண்ட்டுக்கானது. மீண்டும் இம்போர்ட் செய்தாலும் ஸ்டாக் இரண்டு முறை சேராது. ஏற்கனவே உள்ள பொருட்களின் ஸ்டாக்கை மாற்ற, [ஸ்டாக் அல்லது ரீஆர்டர் லெவலை மொத்தமாக மாற்றுதல்](/help/products/bulk-updates) பயன்படுத்துங்கள்.
:::

:::faq "You already have a product called …" என்று வருகிறது
இந்தப் பெயரில் ஏற்கனவே ஒரு பொருள் உள்ளது, அதனால் ஃபைல் இரண்டாவது ஒன்றைச் சேர்த்துவிடும். உள்ள பொருளுக்கே சைஸ், கலர் சேர்க்க அல்லது அவற்றின் விலையை மாற்ற, அதன் புராடக்ட் கோடை **ProductCode** காலத்தில் போடுங்கள். பெயரையும் அடிப்படை விலையையும் இப்படி மாற்ற முடியாது.
