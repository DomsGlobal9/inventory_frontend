ರಿಟರ್ನ್ ನಾಲ್ಕು ಹಂತಗಳಲ್ಲಿ ಹೋಗುತ್ತದೆ: **Requested** (ಬುಕ್ ಆಗಿದೆ) → **Received** (ಸಾಮಾನು ಬಂದಿದೆ) → **Inspected** (ಚೆಕ್ ಆಗಿದೆ) → **Completed** (ಮುಗಿದಿದೆ). ಕೊನೆಯ ಹಂತದಲ್ಲಿ ಮಾತ್ರ ಸ್ಟಾಕ್ ಬದಲಾಗುತ್ತದೆ.

ಮೊದಲು ರಿಟರ್ನ್ ಬುಕ್ ಮಾಡಲು, [ರಿಟರ್ನ್ ಬುಕ್ ಮಾಡಿ](/help/returns/book-a-return) ನೋಡಿ.

:::note ಯಾರು ಇದನ್ನು ಮಾಡಬಹುದು
ಸಾಮಾನ್ಯ ರೋಲ್‌ಗಳಲ್ಲಿ, **ಸ್ಟಾಕ್ ರೂಮ್ ಸ್ಟಾಫ್, ಅಡ್ಮಿನ್‌ಗಳು ಮತ್ತು ಮಾಲೀಕರು**. ಸೇಲ್ಸ್ ಸ್ಟಾಫ್ ಮತ್ತು ಇನ್ವೆಂಟರಿ ಮ್ಯಾನೇಜರ್‌ಗಳಿಗೆ Returns ಕಾಣುವುದಿಲ್ಲ.
:::

## 1. ರಿಟರ್ನ್ ತೆರೆಯಿರಿ

1. ಎಡಗಡೆಯ ಮೆನುವಿನಲ್ಲಿ [[1]] **Returns** ಒತ್ತಿರಿ.
2. ಬಂದಿರುವ ರಿಟರ್ನ್ [[2]] ಒತ್ತಿರಿ. ಹೊಸ ರಿಟರ್ನ್‌ಗಳಲ್ಲಿ **Requested** ಎಂದಿರುತ್ತದೆ.

![Customer Returns ಪಟ್ಟಿ. ಎಡ ಮೆನುವಿನಲ್ಲಿ Returns 1 ಎಂದು, Lakshmi Narayanan ಅವರ Requested ರಿಟರ್ನ್ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-open.webp "ಹೊಸ ರಿಟರ್ನ್ ಮೇಲೆ ಇರುತ್ತದೆ.")

## 2. ಪಡೆದಿದ್ದೇವೆ ಎಂದು ಗುರುತಿಸಿ

ಪಾರ್ಸೆಲ್ ಅಥವಾ ಗ್ರಾಹಕರ ಬ್ಯಾಗ್ ನಿಮ್ಮ ಕೈಗೆ ಬಂದಾಗ:

1. [[1]] ಸ್ಟೇಟಸ್ **Requested** ಎಂದಿದೆಯೇ ಎಂದು ನೋಡಿ.
2. [[2]] **Mark as Received** ಒತ್ತಿರಿ.

![ರಿಟರ್ನ್ ಪೇಜ್. Requested ಸ್ಟೇಟಸ್ 1 ಎಂದು, Mark as Received ಬಟನ್ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-mark-as-received.webp "ಪಾರ್ಸೆಲ್‌ನಲ್ಲಿ ಏನು ಇರಬೇಕು ಎಂದು Returned Items ತೋರಿಸುತ್ತದೆ. ಎಣಿಸಿ ನೋಡಿ.")

ಸ್ಟೇಟಸ್ **Received** ಗೆ ಬದಲಾಗುತ್ತದೆ.

## 3. ಪ್ರತಿ ಪೀಸ್ ಚೆಕ್ ಮಾಡಿ

1. **Inspect Items** ಒತ್ತಿರಿ.
2. [[1]] ಪ್ರತಿ ಐಟಂಗೆ ಏನು ಮಾಡಬೇಕು ಎಂದು ಆರಿಸಿ:
   - **Restock (Add to Inventory)**: ಅದು ಸರಿಯಾಗಿದೆ. ಸ್ಟಾಕ್‌ಗೆ ವಾಪಸ್ ಹೋಗುತ್ತದೆ.
   - **Damaged**: ಅದನ್ನು ಮಾರಲು ಆಗುವುದಿಲ್ಲ. ಸ್ಟಾಕ್‌ಗೆ ವಾಪಸ್ ಹೋಗುವುದಿಲ್ಲ.
   - **Scrap**: ಅದನ್ನು ಬಿಸಾಡಲಾಗುತ್ತದೆ. ಸ್ಟಾಕ್‌ಗೆ ವಾಪಸ್ ಹೋಗುವುದಿಲ್ಲ.

![ಪಟ್ಟಿ ತೆರೆದಿರುವ Inspect Items ಬಾಕ್ಸ್. ಪಟ್ಟಿ 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ, ಅದರಲ್ಲಿ Choose, Restock (Add to Inventory), Damaged ಮತ್ತು Scrap ಇವೆ.](3-choose-list.webp "ಪ್ರತಿ ಐಟಂಗೂ ಒಂದು ಆಯ್ಕೆ ಬೇಕು.")

3. [[2]] **Save Dispositions** ಒತ್ತಿರಿ.

![Inspect Items ಬಾಕ್ಸ್. Restock ಗೆ ಇಟ್ಟ DUP-CHA-PCH 1 ಎಂದು, Save Dispositions ಬಟನ್ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-inspect-items.webp "ಪ್ರತಿ ಐಟಂಗೂ ಆಯ್ಕೆ ಆಗುವವರೆಗೆ Save Dispositions ಬೂದು ಬಣ್ಣದಲ್ಲೇ ಇರುತ್ತದೆ.")

ಸ್ಟೇಟಸ್ **Inspected** ಗೆ ಬದಲಾಗುತ್ತದೆ.

## 4. ರಿಟರ್ನ್ ಮುಗಿಸಿ

1. [[1]] **Disposition** ಕಾಲಂನಲ್ಲಿ ಪ್ರತಿ ಐಟಂನ ಆಯ್ಕೆ ನೋಡಿ. ತಪ್ಪಾಗಿದೆಯೇ? ಮತ್ತೆ **Inspect Items** ಒತ್ತಿ ಬದಲಿಸಿ.
2. [[2]] **Complete Return** ಒತ್ತಿರಿ.

![ಚೆಕ್ ಮಾಡಿದ ನಂತರದ ರಿಟರ್ನ್ ಪೇಜ್. Disposition ಕಾಲಂನ Restock 1 ಎಂದು, Complete Return ಬಟನ್ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-complete-return.webp "Complete Return ನಂತರ ಆಯ್ಕೆಗಳನ್ನು ಬದಲಿಸಲು ಆಗುವುದಿಲ್ಲ.")

ಸ್ಟೇಟಸ್ **Completed** ಗೆ ಬದಲಾಗುತ್ತದೆ. Restock ಎಂದು ಗುರುತಿಸಿದ ಪೀಸ್‌ಗಳು, ಆರ್ಡರ್ ಮಾರಿದ ಸ್ಟೋರ್‌ನ ಸ್ಟಾಕ್‌ಗೆ ವಾಪಸ್ ಸೇರುತ್ತವೆ.

## 5. ಶೆಲ್ಫ್‌ನಲ್ಲಿ ಇಡಿ ಮತ್ತು ಹಣ ವಾಪಸ್ ಕೊಡಿ

1. [[1]] ನಿಮ್ಮ ಅಂಗಡಿ ಶೆಲ್ಫ್‌ಗಳನ್ನು ಬಳಸಿದರೆ, ಎಷ್ಟು ಪೀಸ್‌ಗಳು ಇನ್ನೂ ಶೆಲ್ಫ್‌ನಲ್ಲಿ ಇಲ್ಲ ಎಂದು ಹಳದಿ ಬಾಕ್ಸ್ ಹೇಳುತ್ತದೆ. **Put away** ಒತ್ತಿರಿ. [ಸ್ಟಾಕ್ ಶೆಲ್ಫ್‌ನಲ್ಲಿ ಇಡಿ](/help/shelves/put-away) ನೋಡಿ.
2. [[2]] ಗ್ರಾಹಕರು ಈ ಐಟಂಗಳಿಗೆ ಡಿಸ್ಕೌಂಟ್ ನಂತರ ಎಷ್ಟು ಹಣ ಕೊಟ್ಟಿದ್ದರು ಎಂದು **Refund owed to the customer** ತೋರಿಸುತ್ತದೆ.

![ಮುಗಿದ ರಿಟರ್ನ್. 1 piece of this return is not on a shelf yet at Main Store ಎಂದಿರುವ ಹಳದಿ ಬಾಕ್ಸ್ ಮತ್ತು Put away ಬಟನ್ 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ. Refund owed to the customer, 980 ರೂಪಾಯಿ, 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](5-put-away.webp "ರೀಫಂಡ್ ಎಂದರೆ ಗ್ರಾಹಕರು ಕೊಟ್ಟ ಹಣ, ಟ್ಯಾಗ್ ಮೇಲಿನ ಬೆಲೆ ಅಲ್ಲ.")

:::warning ScaleEzy ತಾನೇ ಹಣ ಕಳಿಸುವುದಿಲ್ಲ
ನಿಮ್ಮ ಅಂಗಡಿ ಯಾವಾಗಲೂ ಕೊಡುವ ರೀತಿಯಲ್ಲಿ ಹಣ ವಾಪಸ್ ಕೊಡಿ, ನಂತರ ಹೇಗೆ ಕೊಟ್ಟಿರಿ ಆ ಬಟನ್ ಒತ್ತಿರಿ: **Cash**, **UPI**, **Card** ಅಥವಾ **Store credit**, ನಂತರ **Paid back**. ಅದು ಬಿಲ್ ಮೇಲೆ ಮತ್ತು Day Book ನಲ್ಲಿ ದಾಖಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ ಕ್ಯಾಶ್ ಡ್ರಾಯರ್ ಲೆಕ್ಕ ಸರಿಹೊಂದುತ್ತದೆ. Shopify ಯಲ್ಲಿ ರೀಫಂಡ್ ಆದ Shopify ಆರ್ಡರ್‌ಗೆ **Refunded through Shopify** ಎಂದು ಬರುತ್ತದೆ.
:::

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq ಮೆನುವಿನಲ್ಲಿ Returns ಕಾಣುತ್ತಿಲ್ಲ
ನಿಮ್ಮ ರೋಲ್‌ಗೆ ರಿಟರ್ನ್‌ಗಳನ್ನು ನೋಡುವ ಅನುಮತಿ ಇಲ್ಲ. ಅಂಗಡಿಯ ಮಾಲೀಕರನ್ನು ಕೇಳಿ.
:::

:::faq ಗ್ರಾಹಕರು ಪೀಸ್ ಹಿಡಿದು ಕೌಂಟರ್ ಬಳಿಯೇ ನಿಂತಿದ್ದಾರೆ
ಅದರ ಬದಲು [ಕೌಂಟರ್‌ನಲ್ಲಿ ರಿಟರ್ನ್ ತೆಗೆದುಕೊಳ್ಳಿ](/help/returns/take-a-return) ಬಳಸಿ. ಅದು ನಾಲ್ಕೂ ಸ್ಟೆಪ್‌ಗಳನ್ನು ಮತ್ತು ಹಣವನ್ನು ಒಂದೇ ಬಾರಿಗೆ ಮಾಡುತ್ತದೆ.
:::

:::faq Save Dispositions ಬೂದು ಬಣ್ಣದಲ್ಲಿದೆ
ಒಂದು ಅಥವಾ ಹೆಚ್ಚು ಐಟಂಗಳಲ್ಲಿ ಇನ್ನೂ **Choose…** ಎಂದಿದೆ. ಪ್ರತಿ ಐಟಂಗೂ Restock, Damaged ಅಥವಾ Scrap ಆರಿಸಿ.
:::

:::faq ಸಾಮಾನು ಬರಲೇ ಇಲ್ಲ, ಅಥವಾ ರಿಟರ್ನ್ ತಪ್ಪಾಗಿ ಬುಕ್ ಆಗಿದೆ
ರಿಟರ್ನ್ ತೆರೆದು **Turn down** ಒತ್ತಿರಿ, ನಂತರ ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಮತ್ತೆ **Turn down** ಒತ್ತಿರಿ. ಏನೂ ಸ್ಟಾಕ್‌ಗೆ ವಾಪಸ್ ಹೋಗುವುದಿಲ್ಲ ಮತ್ತು ಯಾವುದೇ ಹಣ ಬಾಕಿ ಇರುವುದಿಲ್ಲ. ನಂತರ ರಿಟರ್ನ್ **Turned down** ಎಂದು ತೋರಿಸುತ್ತದೆ. ರಿಟರ್ನ್ ಮುಗಿಯುವವರೆಗೆ ಇದನ್ನು ಮಾಡಬಹುದು.
:::

:::faq Restock ಆರಿಸಿದೆ, ಆದರೆ ಪೀಸ್ ಹಾಳಾಗಿದೆ
**Complete Return** ಮೊದಲು, **Inspect Items** ಒತ್ತಿ ಬದಲಿಸಿ. ಮುಗಿಸಿದ ನಂತರ ಪೀಸ್ ಈಗಾಗಲೇ ಸ್ಟಾಕ್‌ಗೆ ಬಂದಿರುತ್ತದೆ. [ಸ್ಟಾಕ್ ತೆಗೆಯಿರಿ](/help/inventory/remove-stock) ಬಳಸಿ ಅದನ್ನು ತೆಗೆಯಿರಿ.
:::

:::faq ಹಳದಿ Put away ಬಾಕ್ಸ್ ಇಲ್ಲ
ನಿಮ್ಮ ಅಂಗಡಿ ಶೆಲ್ಫ್‌ಗಳನ್ನು ಬಳಸುವುದಿಲ್ಲ, ನಿಮ್ಮ ರೋಲ್‌ಗೆ ಸ್ಟಾಕ್ ಶೆಲ್ಫ್‌ನಲ್ಲಿ ಇಡುವ ಅನುಮತಿ ಇಲ್ಲ, ಯಾವ ಪೀಸ್‌ಗೂ Restock ಆಯ್ಕೆ ಮಾಡಿಲ್ಲ, ಅಥವಾ ಪೀಸ್‌ಗಳು ಈಗಾಗಲೇ ಶೆಲ್ಫ್‌ನಲ್ಲಿವೆ.
:::
