ಪ್ರಾಡಕ್ಟ್ ಸೇರಿಸುವಾಗ ಅದರ ಕ್ಯಾಟಗರಿ, ಡ್ರೆಸ್ ಟೈಪ್, ಫ್ಯಾಬ್ರಿಕ್, ಸೈಜ್ ಮತ್ತು ಬಣ್ಣಗಳನ್ನು ಪಟ್ಟಿಗಳಿಂದ ಆರಿಸುತ್ತೀರಿ. ನಿಮ್ಮ ಅಂಗಡಿಗೆ ಮೊದಲೇ ಸಿದ್ಧವಾದ ಪಟ್ಟಿಗಳು ಇರುತ್ತವೆ. ಇಲ್ಲಿ ನೀವು ನಿಮ್ಮದೇ ಹೆಸರುಗಳನ್ನು ಸೇರಿಸಬಹುದು, ಹೆಸರು ಬದಲಿಸಬಹುದು, ಅಥವಾ ಎಂದೂ ಬಳಸದವುಗಳನ್ನು ನಿಲ್ಲಿಸಬಹುದು.

## 1. Catalog Configuration ತೆರೆಯಿರಿ

1. ಎಡಗಡೆಯ ಮೆನುವಿನಲ್ಲಿ [[1]] **Settings** ಒತ್ತಿರಿ.
2. [[2]] **Catalog Configuration** ಒತ್ತಿರಿ.

![Settings ಸ್ಕ್ರೀನ್. ಮೆನುವಿನಲ್ಲಿ Settings ಗೆ 1 ಮತ್ತು Catalog Configuration ಗೆ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-open.webp "ಕ್ಯಾಟಲಾಗ್ ನೋಡಿಕೊಳ್ಳಲು ಅನುಮತಿ ಇರುವ ರೋಲ್‌ಗಳಿಗೆ ಮಾತ್ರ Catalog Configuration ಕಾಣುತ್ತದೆ.")

## 2. ಒಂದು ಪಟ್ಟಿ ಆರಿಸಿ

1. [[1]] ಬೇಕಾದ ಪಟ್ಟಿ ಒತ್ತಿರಿ: **Sizes**, **Colors**, **Dress Types**, **Materials**, **Design Types**, **Categories** ಅಥವಾ **Product Types**.
2. [[2]] **Add New** ಈ ಪಟ್ಟಿಗೆ ಹೊಸ ಹೆಸರು ಸೇರಿಸುತ್ತದೆ.
3. [[3]] ಪ್ರತಿ ಹೆಸರೂ ಒಂದು ಬಟನ್. ಹೆಸರು ಬದಲಿಸಲು, ನಿಲ್ಲಿಸಲು ಅಥವಾ ಡಿಲೀಟ್ ಮಾಡಲು ಅದನ್ನು ಒತ್ತಿರಿ.

![Catalog Configuration ನಲ್ಲಿ Dress Types. ಪಟ್ಟಿಯ ಬಟನ್‌ಗಳಿಗೆ 1, Add New ಗೆ 2 ಮತ್ತು Saree ಗೆ 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-lists.webp "ಡ್ರೆಸ್ ಟೈಪ್‌ಗಳನ್ನು Women, Men ಮತ್ತು Kids ಎಂದು ಗುಂಪು ಮಾಡಲಾಗಿದೆ.")

ಒಂದು ಹೆಸರಿನ ಮೇಲೆ ಚಿಕ್ಕ ಬೀಗದ ಗುರುತು ಇದ್ದರೆ ಅದು ScaleEzy ಜೊತೆ ಬಂದದ್ದು. ಹೆಸರಿನ ಮೇಲೆ ಅಡ್ಡಗೆರೆ ಇದ್ದರೆ ಅದನ್ನು ನಿಲ್ಲಿಸಲಾಗಿದೆ.

## 3. ಹೊಸ ಹೆಸರು ಸೇರಿಸಿ

1. **Add New** ಒತ್ತಿರಿ.
2. [[1]] **Label** ಟೈಪ್ ಮಾಡಿ, ಅಂದರೆ ಜನರಿಗೆ ಕಾಣುವ ಹೆಸರು, ಉದಾಹರಣೆಗೆ *Half Saree*. **Value/Code (Optional)** ಖಾಲಿ ಬಿಟ್ಟರೆ ತಾನಾಗಿಯೇ ತುಂಬುತ್ತದೆ.
3. [[2]] ಡ್ರೆಸ್ ಟೈಪ್‌ಗೆ **Category** ಆರಿಸಿ: Women, Men ಅಥವಾ Kids. ಆಗ ಆ ಡ್ರೆಸ್ ಟೈಪ್ ಆ ಕ್ಯಾಟಗರಿಯ ಪ್ರಾಡಕ್ಟ್‌ಗಳಿಗೆ ಕಾಣುತ್ತದೆ.
4. [[3]] **Save** ಒತ್ತಿರಿ.

![Add Dress Type. Half Saree ಲೇಬಲ್‌ಗೆ 1, Women ಕ್ಯಾಟಗರಿಗೆ 2 ಮತ್ತು Save ಗೆ 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-add-new.webp "ಈಗ Dress Type ಪಟ್ಟಿಯಲ್ಲಿ Women ಅಡಿಯಲ್ಲಿ Half Saree ಕಾಣುತ್ತದೆ.")

## 4. ಬಣ್ಣ ಮತ್ತು ಅದರ ಶೇಡ್‌ಗಳನ್ನು ಸೇರಿಸಿ

1. **Colors** ಆರಿಸಿ, ನಂತರ **Add New** ಒತ್ತಿರಿ.
2. [[1]] **Label** ಟೈಪ್ ಮಾಡಿ, ಉದಾಹರಣೆಗೆ *Maroon*.
3. [[2]] **Hex Color** ಟೈಪ್ ಮಾಡಿ, ಅಂದರೆ *#800000* ನಂತಹ ಬಣ್ಣದ ಕೋಡ್. ಅಥವಾ ಬಣ್ಣದ ಚೌಕ ಒತ್ತಿ ಬಣ್ಣ ಆರಿಸಿ.
4. [[3]] ಪ್ರತಿ ಶೇಡ್‌ಗೆ **Add shade** ಒತ್ತಿರಿ. ಶೇಡ್‌ನ ಬಣ್ಣ ಆರಿಸಲು ಚಿಕ್ಕ ಚೌಕ ಒತ್ತಿರಿ.
5. [[4]] ಶೇಡ್‌ನ ಹೆಸರು ಟೈಪ್ ಮಾಡಿ, ಉದಾಹರಣೆಗೆ *Wine*. ಖಾಲಿ ಬಿಟ್ಟರೆ ScaleEzy ತಾನೇ ಹೆಸರು ಇಡುತ್ತದೆ.
6. [[5]] **Save** ಒತ್ತಿರಿ.

![Add Color. Maroon ಲೇಬಲ್‌ಗೆ 1, ಬಣ್ಣದ ಕೋಡ್‌ಗೆ 2, Add shade ಗೆ 3, Wine ಶೇಡ್ ಹೆಸರಿಗೆ 4 ಮತ್ತು Save ಗೆ 5 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-colour-and-shades.webp "ಯಾರಾದರೂ ಪ್ರಾಡಕ್ಟ್ ಸೇರಿಸುವಾಗ Maroon ಕೆಳಗೆ ಶೇಡ್‌ಗಳು ಕಾಣುತ್ತವೆ.")

:::tip ಶೇಡ್ ಹೆಸರು ಯಾಕೆ ಮುಖ್ಯ
ಶೇಡ್‌ನ ಹೆಸರು ಐಟಮ್ ಮೇಲೆ ಸೇವ್ ಆಗುತ್ತದೆ, ಖರೀದಿ ಆರ್ಡರ್‌ಗಳ ಮೇಲೆ ಪ್ರಿಂಟ್ ಆಗುತ್ತದೆ ಮತ್ತು SKU ನಲ್ಲಿ ಬಳಕೆಯಾಗುತ್ತದೆ. *Wine* ನಂತಹ ಸ್ಪಷ್ಟ ಹೆಸರುಗಳು ಸಪ್ಲೈಯರ್ ಸರಿಯಾದ ಬಣ್ಣ ಕಳುಹಿಸಲು ಸಹಾಯ ಮಾಡುತ್ತವೆ.
:::

## 5. ಹೆಸರು ಬದಲಿಸಿ, ನಿಲ್ಲಿಸಿ ಅಥವಾ ಡಿಲೀಟ್ ಮಾಡಿ

ತೆರೆಯಲು ಒಂದು ಹೆಸರನ್ನು ಒತ್ತಿರಿ.

- ಹೆಸರು ಬದಲಿಸಲು **Label** ಬದಲಿಸಿ **Save** ಒತ್ತಿರಿ. ಅದನ್ನು ಬಳಸುವ ಪ್ರಾಡಕ್ಟ್‌ಗಳಲ್ಲೂ ಬದಲಾಗುತ್ತದೆ.
- [[1]] ಈ ಹೆಸರನ್ನು ಪ್ರಾಡಕ್ಟ್‌ಗಳು ಬಳಸುತ್ತಿವೆಯೇ ಎಂದು ಬಾಕ್ಸ್ ತಿಳಿಸುತ್ತದೆ. ಬಳಕೆಯಲ್ಲಿರುವ ಹೆಸರನ್ನು ಡಿಲೀಟ್ ಮಾಡಲು ಆಗುವುದಿಲ್ಲ.
- [[2]] **Disable** ಒತ್ತಿದರೆ ಪ್ರಾಡಕ್ಟ್ ಸೇರಿಸುವಾಗ ಅದು ಪಟ್ಟಿಗಳಲ್ಲಿ ಕಾಣುವುದಿಲ್ಲ. ಈಗಾಗಲೇ ಅದನ್ನು ಬಳಸುವ ಪ್ರಾಡಕ್ಟ್‌ಗಳಲ್ಲಿ ಅದು ಹಾಗೆಯೇ ಇರುತ್ತದೆ. **Enable** ಅದನ್ನು ಮತ್ತೆ ತರುತ್ತದೆ.
- ಯಾವ ಪ್ರಾಡಕ್ಟ್ ಕೂಡ ಆ ಹೆಸರನ್ನು ಬಳಸದಿದ್ದಾಗ ಮಾತ್ರ **Delete** ಕಾಣುತ್ತದೆ. ಇದನ್ನು ಹಿಂಪಡೆಯಲು ಆಗುವುದಿಲ್ಲ.

![Edit Silk. ಎಷ್ಟು ಪ್ರಾಡಕ್ಟ್‌ಗಳು ಇದನ್ನು ಬಳಸುತ್ತಿವೆ ಎಂಬ ಸಾಲಿಗೆ 1 ಮತ್ತು Disable ಬಟನ್‌ಗೆ 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](5-in-use.webp "ಏನೂ ಬದಲಿಸದೆ ಮುಚ್ಚಲು Cancel ಒತ್ತಿರಿ.")

:::warning ಕ್ಯಾಟಗರಿ ಮತ್ತು ಸೈಜ್‌ಗಳು
ಪ್ರಾಡಕ್ಟ್‌ಗಳನ್ನು **WOMEN**, **MEN**, **KIDS** ಮತ್ತು **UNISEX** ಕ್ಯಾಟಗರಿಗಳಲ್ಲಿ ಮಾತ್ರ ಸೇವ್ ಮಾಡಬಹುದು. ಹೊಸ ಕ್ಯಾಟಗರಿಗಳನ್ನು ಸೇರಿಸಬೇಡಿ. ಇಲ್ಲಿ ಸೇರಿಸಿದ ಸೈಜ್ ಪ್ರಾಡಕ್ಟ್ ಪೇಜ್‌ನ **Generate Variants** ನಲ್ಲಿ ಕಾಣುತ್ತದೆ. ಆದರೆ **Add Product** ಸ್ಕ್ರೀನ್‌ನಲ್ಲಿ Women, Men ಅಥವಾ Kids ಗೆ ಅದು ಕಾಣದಿರಬಹುದು, ಏಕೆಂದರೆ ಆ ಕ್ಯಾಟಗರಿಗಳಿಗೆ ತಮ್ಮದೇ ಸೈಜ್ ಪಟ್ಟಿಗಳು ಇವೆ.
:::

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq ನನಗೆ Catalog Configuration ಕಾಣುತ್ತಿಲ್ಲ
ಮಾಲೀಕರು, ಅಡ್ಮಿನ್ ಅಥವಾ ಇನ್ವೆಂಟರಿ ಮ್ಯಾನೇಜರ್ ಮಾತ್ರ ಕ್ಯಾಟಲಾಗ್ ನೋಡಿಕೊಳ್ಳಬಹುದು. ಬೇರೆ ರೋಲ್‌ಗಳಿಗೆ Settings ನಲ್ಲಿ ಇದು ಕಾಣುವುದಿಲ್ಲ.
:::

:::faq "No shades yet — add them in Settings → Catalog." ಎಂದು ಬರುತ್ತಿದೆ
ನೀವು ಸೇರಿಸಿದ ಒಂದು ಬಣ್ಣಕ್ಕೆ ಶೇಡ್‌ಗಳಿಲ್ಲ. ಅದನ್ನು ಇಲ್ಲಿ ತೆರೆದು **Add shade** ಒತ್ತಿ, ಸೇವ್ ಮಾಡಿ. ಪ್ರಾಡಕ್ಟ್‌ನ **Variants** ಟ್ಯಾಬ್‌ನಲ್ಲಿ, **Generate Variants** ಕೆಳಗಿನ ಬಣ್ಣದ ಬಟನ್‌ಗಳಲ್ಲಿ, ಶೇಡ್ ಇಲ್ಲದೆಯೇ ಆ ಬಣ್ಣ ಬಳಸಲು ಅದರ ಮೇಲೆ ಎರಡು ಬಾರಿ ಒತ್ತಬಹುದು.
:::

:::faq "Shade 2 is the same colour as one above it." ಎಂದು ಬರುತ್ತಿದೆ
ಹೊಸ ಶೇಡ್ ಮೊದಲಿಗೆ ಮುಖ್ಯ ಬಣ್ಣದಂತೆಯೇ ಇರುತ್ತದೆ. ಚಿಕ್ಕ ಚೌಕದಿಂದ ಅದಕ್ಕೆ ಬೇರೆ ಬಣ್ಣ ಆರಿಸಿ, ಅಥವಾ **✕** ಒತ್ತಿ ತೆಗೆಯಿರಿ.
:::

:::faq "Use a hex colour like #FF69B4." ಎಂದು ಬರುತ್ತಿದೆ
ಬಣ್ಣದ ಕೋಡ್ **#** ನಿಂದ ಶುರುವಾಗಬೇಕು, ನಂತರ 3 ಅಥವಾ 6 ಅಕ್ಷರಗಳು ಮತ್ತು ಅಂಕಿಗಳು ಇರಬೇಕು. ಅಥವಾ ಬಣ್ಣದ ಚೌಕ ಒತ್ತಿ ಬಣ್ಣ ಆರಿಸಿ.
:::
