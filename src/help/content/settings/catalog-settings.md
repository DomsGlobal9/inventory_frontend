When you add a product you choose its category, dress type, fabric, sizes and colours from lists. Your shop starts with ready-made lists. Here you can add your own entries, rename them, or switch off the ones you never use.

## 1. Open Catalog Configuration

1. In the menu on the left, click [[1]] **Settings**.
2. Click [[2]] **Catalog Configuration**.

![The Settings screen. Settings is marked 1 in the menu and Catalog Configuration is marked 2.](1-open.webp "Only roles that may manage the catalog see Catalog Configuration.")

## 2. Choose a list

1. [[1]] Click the list you want: **Sizes**, **Colors**, **Dress Types**, **Materials**, **Design Types**, **Categories** or **Product Types**.
2. [[2]] **Add New** adds an entry to this list.
3. [[3]] Each entry is a button. Click it to rename, switch off or delete it.

![Dress Types in Catalog Configuration. The list buttons are marked 1, Add New 2 and the Saree entry 3.](2-lists.webp "Dress types are grouped by Women, Men and Kids.")

A small lock on an entry means it came with ScaleEzy. An entry with a line through it is switched off.

## 3. Add a new entry

1. Click **Add New**.
2. [[1]] Type the **Label**, the name people will see, for example *Half Saree*. **Value/Code (Optional)** is made for you when you leave it empty.
3. [[2]] For a dress type, choose the **Category**: Women, Men or Kids. The dress type then shows for products in that category.
4. Click [[3]] **Save**.

![Add Dress Type. The label Half Saree is marked 1, the category Women 2 and Save 3.](3-add-new.webp "Half Saree now shows under Women in the Dress Type list.")

## 4. Add a colour with its shades

1. Choose **Colors**, then click **Add New**.
2. [[1]] Type the **Label**, for example *Maroon*.
3. [[2]] Type the **Hex Color**, a colour code such as *#800000*, or click the colour square to pick it.
4. [[3]] Click **Add shade** for each shade. Click the small square to pick the shade's colour.
5. [[4]] Type the name of the shade, for example *Wine*. Leave it empty and ScaleEzy names it for you.
6. Click [[5]] **Save**.

![Add Color. Label Maroon is marked 1, the colour code 2, Add shade 3, the shade name Wine 4 and Save 5.](4-colour-and-shades.webp "Shades show under Maroon when someone adds a product.")

:::tip Why shade names matter
The shade name is saved on the item, printed on purchase orders and used in the SKU. Clear names such as *Wine* help your supplier send the right colour.
:::

## 5. Rename, switch off or delete

Click an entry to open it.

- Change the **Label** and press **Save** to rename it. Products that use it change too.
- [[1]] The box tells you if products use this entry. An entry in use cannot be deleted.
- [[2]] **Disable** takes it out of the lists when someone adds a product. Products that already use it keep it. **Enable** brings it back.
- **Delete** shows only when no product uses the entry. It cannot be undone.

![Edit Silk. The line about how many products use it is marked 1 and the Disable button is marked 2.](5-in-use.webp "Press Cancel to close without changes.")

:::warning Categories and sizes
Products can only be saved in the categories **WOMEN**, **MEN**, **KIDS** and **UNISEX**. Do not add new categories. A size you add here shows under **Generate Variants** on a product page, but the **Add Product** screen may not show it for Women, Men or Kids, because those categories have their own size lists.
:::

## Common problems

:::faq I don't see Catalog Configuration
Only the owner, an admin or an inventory manager can manage the catalog. Other roles do not see it in Settings.
:::

:::faq "No shades yet — add them in Settings → Catalog."
A colour you added has no shades. Open it here, click **Add shade**, and save. On the product's **Variants** tab, in the colour buttons under **Generate Variants**, you can still double-click the colour to use it without a shade.
:::

:::faq "Shade 2 is the same colour as one above it."
A new shade starts as the same colour as the main colour. Pick a different colour for it with the small square, or remove it with the **✕**.
:::

:::faq "Use a hex colour like #FF69B4."
The colour code must start with **#** followed by 3 or 6 letters and numbers. Or click the colour square and pick the colour.
:::
