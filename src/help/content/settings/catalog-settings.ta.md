ஒரு பொருளைச் சேர்க்கும்போது அதன் கேட்டகரி, டிரஸ் வகை, துணி, சைஸ், கலர் ஆகியவற்றை லிஸ்ட்களில் இருந்து தேர்ந்தெடுக்கிறீர்கள். உங்கள் கடைக்குத் தொடக்கத்திலேயே தயாரான லிஸ்ட்கள் இருக்கும். இங்கே உங்கள் சொந்த என்ட்ரிகளைச் சேர்க்கலாம், பெயரை மாற்றலாம், அல்லது நீங்கள் பயன்படுத்தாதவற்றை நிறுத்தி வைக்கலாம்.

## 1. Catalog Configuration-ஐத் திறக்கவும்

1. இடது பக்க மெனுவில் [[1]] **Settings** அழுத்துங்கள்.
2. [[2]] **Catalog Configuration** அழுத்துங்கள்.

![Settings திரை. மெனுவில் Settings 1 எனவும், Catalog Configuration 2 எனவும் குறிக்கப்பட்டுள்ளன.](1-open.webp "கேட்டலாக்கை நிர்வகிக்க அனுமதி உள்ள ரோல்களுக்கு மட்டுமே Catalog Configuration தெரியும்.")

## 2. ஒரு லிஸ்டைத் தேர்ந்தெடுங்கள்

1. [[1]] உங்களுக்கு வேண்டிய லிஸ்டை அழுத்துங்கள்: **Sizes**, **Colors**, **Dress Types**, **Materials**, **Design Types**, **Categories** அல்லது **Product Types**.
2. [[2]] **Add New** இந்த லிஸ்டில் ஒரு என்ட்ரியைச் சேர்க்கும்.
3. [[3]] ஒவ்வொரு என்ட்ரியும் ஒரு பட்டன். பெயரை மாற்ற, நிறுத்த அல்லது டெலீட் செய்ய அதை அழுத்துங்கள்.

![Catalog Configuration-இல் Dress Types. லிஸ்ட் பட்டன்கள் 1, Add New 2, Saree என்ட்ரி 3 எனக் குறிக்கப்பட்டுள்ளன.](2-lists.webp "டிரஸ் வகைகள் Women, Men, Kids என்று பிரிக்கப்பட்டுள்ளன.")

ஒரு என்ட்ரியில் சிறிய பூட்டு இருந்தால், அது ScaleEzy உடன் வந்தது என்று அர்த்தம். குறுக்குக் கோடு போட்ட என்ட்ரி நிறுத்தப்பட்டுள்ளது.

## 3. புதிய என்ட்ரியைச் சேர்க்கவும்

1. **Add New** அழுத்துங்கள்.
2. [[1]] **Label** டைப் செய்யுங்கள். இது எல்லோரும் பார்க்கும் பெயர், உதாரணமாக *Half Saree*. **Value/Code (Optional)**-ஐக் காலியாக விட்டால் அது தானாக உருவாகும்.
3. [[2]] டிரஸ் வகைக்கு **Category**-ஐத் தேர்ந்தெடுங்கள்: Women, Men அல்லது Kids. அந்த கேட்டகரியில் உள்ள பொருட்களுக்கு அந்த டிரஸ் வகை காட்டப்படும்.
4. [[3]] **Save** அழுத்துங்கள்.

![Add Dress Type. Half Saree என்ற லேபிள் 1, Women கேட்டகரி 2, Save 3 எனக் குறிக்கப்பட்டுள்ளன.](3-add-new.webp "இப்போது Dress Type லிஸ்டில் Women கீழ் Half Saree காட்டப்படும்.")

## 4. ஷேடுகளுடன் ஒரு கலரைச் சேர்க்கவும்

1. **Colors** தேர்ந்தெடுத்து, **Add New** அழுத்துங்கள்.
2. [[1]] **Label** டைப் செய்யுங்கள், உதாரணமாக *Maroon*.
3. [[2]] **Hex Color** டைப் செய்யுங்கள். இது *#800000* போன்ற ஒரு கலர் கோடு. அல்லது கலர் சதுரத்தை அழுத்தித் தேர்ந்தெடுங்கள்.
4. [[3]] ஒவ்வொரு ஷேடுக்கும் **Add shade** அழுத்துங்கள். ஷேடின் கலரைத் தேர்ந்தெடுக்க சிறிய சதுரத்தை அழுத்துங்கள்.
5. [[4]] ஷேடின் பெயரை டைப் செய்யுங்கள், உதாரணமாக *Wine*. காலியாக விட்டால் ScaleEzy தானே பெயர் வைக்கும்.
6. [[5]] **Save** அழுத்துங்கள்.

![Add Color. Maroon என்ற லேபிள் 1, கலர் கோடு 2, Add shade 3, Wine என்ற ஷேடு பெயர் 4, Save 5 எனக் குறிக்கப்பட்டுள்ளன.](4-colour-and-shades.webp "யாராவது பொருள் சேர்க்கும்போது Maroon கீழ் ஷேடுகள் காட்டப்படும்.")

:::tip ஷேடு பெயர்கள் ஏன் முக்கியம்
ஷேடு பெயர் ஐட்டத்தில் சேவ் ஆகும், பர்ச்சேஸ் ஆர்டர்களில் பிரிண்ட் ஆகும், SKU-விலும் பயன்படும். *Wine* போன்ற தெளிவான பெயர்கள் இருந்தால் சப்ளையர் சரியான கலரை அனுப்புவார்.
:::

## 5. பெயர் மாற்றுதல், நிறுத்துதல் அல்லது டெலீட் செய்தல்

ஒரு என்ட்ரியைத் திறக்க அதை அழுத்துங்கள்.

- பெயரை மாற்ற **Label**-ஐ மாற்றி **Save** அழுத்துங்கள். அதைப் பயன்படுத்தும் பொருட்களிலும் பெயர் மாறும்.
- [[1]] இந்த என்ட்ரியைப் பொருட்கள் பயன்படுத்துகின்றனவா என்று பெட்டி சொல்லும். பயன்பாட்டில் உள்ள என்ட்ரியை டெலீட் செய்ய முடியாது.
- [[2]] **Disable** அழுத்தினால், பொருள் சேர்க்கும்போது வரும் லிஸ்ட்களில் இருந்து அது நீங்கும். ஏற்கனவே அதைப் பயன்படுத்தும் பொருட்களில் அது அப்படியே இருக்கும். **Enable** அதைத் திரும்பக் கொண்டுவரும்.
- எந்தப் பொருளும் அந்த என்ட்ரியைப் பயன்படுத்தாதபோது மட்டுமே **Delete** தெரியும். டெலீட் செய்ததைத் திரும்பப் பெற முடியாது.

![Edit Silk. எத்தனை பொருட்கள் இதைப் பயன்படுத்துகின்றன என்ற வரி 1 எனவும், Disable பட்டன் 2 எனவும் குறிக்கப்பட்டுள்ளன.](5-in-use.webp "மாற்றம் இல்லாமல் மூட Cancel அழுத்துங்கள்.")

:::warning கேட்டகரிகளும் சைஸ்களும்
பொருட்களை **WOMEN**, **MEN**, **KIDS**, **UNISEX** என்ற கேட்டகரிகளில் மட்டுமே சேவ் செய்ய முடியும். புதிய கேட்டகரிகளைச் சேர்க்காதீர்கள். இங்கே நீங்கள் சேர்க்கும் சைஸ் பொருள் பக்கத்தில் **Generate Variants** கீழ் காட்டப்படும். ஆனால் Women, Men, Kids-க்கு **Add Product** திரையில் அது தெரியாமல் போகலாம், ஏனென்றால் அந்த கேட்டகரிகளுக்குத் தனி சைஸ் லிஸ்ட்கள் உள்ளன.
:::

## பொதுவான பிரச்சினைகள்

:::faq எனக்கு Catalog Configuration தெரியவில்லை
உரிமையாளர், அட்மின் அல்லது இன்வென்டரி மேனேஜர் மட்டுமே கேட்டலாக்கை நிர்வகிக்க முடியும். மற்ற ரோல்களுக்கு Settings-இல் இது தெரியாது.
:::

:::faq "No shades yet — add them in Settings → Catalog." என்று வருகிறது
நீங்கள் சேர்த்த ஒரு கலருக்கு ஷேடுகள் இல்லை. அதை இங்கே திறந்து, **Add shade** அழுத்தி, சேவ் செய்யுங்கள். பொருளின் **Variants** டேபில், **Generate Variants** கீழ் உள்ள கலர் பட்டன்களில், ஷேடு இல்லாமலேயே கலரைப் பயன்படுத்த அந்தக் கலரை இருமுறை அழுத்தலாம் (double-click).
:::

:::faq "Shade 2 is the same colour as one above it." என்று வருகிறது
புதிய ஷேடு முதன்மைக் கலரின் அதே கலருடன் தொடங்கும். சிறிய சதுரத்தை அழுத்தி அதற்கு வேறு கலரைத் தேர்ந்தெடுங்கள், அல்லது **✕** அழுத்தி நீக்குங்கள்.
:::

:::faq "Use a hex colour like #FF69B4." என்று வருகிறது
கலர் கோடு **#** உடன் தொடங்கி, அதன் பின் 3 அல்லது 6 எழுத்துகளும் எண்களும் இருக்க வேண்டும். அல்லது கலர் சதுரத்தை அழுத்திக் கலரைத் தேர்ந்தெடுங்கள்.
:::
