ಇದು **ನಿಮ್ಮ ಸ್ವಂತ ಡೆವಲಪರ್** ಮಾಡಿದ ವೆಬ್‌ಸೈಟ್‌ಗಾಗಿ. Shopify ಸ್ಟೋರ್ ಇದ್ದರೆ, ಇದರ ಬದಲು [Shopify ಜೋಡಿಸಿ](/help/settings/connect-shopify) ನೋಡಿ.

ಜೋಡಿಸಿದ ಮೇಲೆ ನಿಮ್ಮ ವೆಬ್‌ಸೈಟ್ ತಾನಾಗಿಯೇ ಅಪ್‌ಡೇಟ್ ಆಗುತ್ತಿರುತ್ತದೆ. ಏನೂ ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಬೇಕಿಲ್ಲ, ನಂತರ ಏನೂ ಒತ್ತಬೇಕಿಲ್ಲ. ಎರಡು ವಿಷಯಗಳಿಗೆ ನಿಮ್ಮ ಡೆವಲಪರ್ ಬೇಕು: ಅಪ್‌ಡೇಟ್‌ಗಳನ್ನು ಪಡೆಯುವ **ವಿಳಾಸ**, ಮತ್ತು **ಕೀ** ಇಡಲು ಒಂದು ಜಾಗ.

## 1. Storefront ತೆರೆಯಿರಿ

1. **Settings** ತೆರೆದು [[1]] **Storefront** ಒತ್ತಿರಿ.
2. Shopify ಕಾರ್ಡ್‌ನ ಕೆಳಗೆ [[2]] **Connect a storefront** ಒತ್ತಿರಿ. ಈಗಾಗಲೇ ಒಂದು ಇದ್ದರೆ, ಬಟನ್‌ನಲ್ಲಿ **Connect another storefront** ಎಂದು ಇರುತ್ತದೆ.

![Storefront ಸ್ಕ್ರೀನ್. Storefront 1 ಮತ್ತು Connect a storefront 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-open.webp "ನೀವು ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ವೆಬ್‌ಸೈಟ್ ಜೋಡಿಸಬಹುದು.")

## 2. ಫಾರ್ಮ್ ತುಂಬಿರಿ

1. [[1]] **Name**: ಯಾವುದೇ ಹೆಸರು, ನಿಮಗೆ ಮಾತ್ರ. ಉದಾಹರಣೆಗೆ *ನನ್ನ ವೆಬ್‌ಸೈಟ್*.
2. [[2]] **Where should we send updates?**: ನಿಮ್ಮ ಡೆವಲಪರ್ ಕೊಡುವ ವಿಳಾಸ. ಇದು **https** ನಿಂದ ಶುರುವಾಗಬೇಕು.
3. [[3]] **Which locations does this website sell from?**: ಯಾವ ಸ್ಟೋರ್‌ಗಳ ಸ್ಟಾಕ್ ಮತ್ತು ಬೆಲೆಗಳನ್ನು ವೆಬ್‌ಸೈಟ್ ತೋರಿಸಬೇಕೋ ಅವುಗಳಿಗೆ ಟಿಕ್ ಮಾಡಿ. ಎಲ್ಲಾ ಲೊಕೇಶನ್‌ಗಳಿಂದ ಮಾರಾಟ ಮಾಡಲು **ಯಾವುದಕ್ಕೂ ಟಿಕ್ ಮಾಡಬೇಡಿ**.
4. [[4]] **Connect** ಒತ್ತಿರಿ.

![Connect a storefront ಫಾರ್ಮ್. Name 1, ವಿಳಾಸ 2, ಟಿಕ್ ಮಾಡಿದ Main Store 3 ಮತ್ತು Connect 4 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](2-fill-in.webp "ಜೋಡಿಸುವ ಮೊದಲು ಆ ವಿಳಾಸ ಇದೆಯೇ ಎಂದು ScaleEzy ನೋಡುತ್ತದೆ.")

## 3. ಕೀ ಅನ್ನು ಈಗಲೇ ಸೇವ್ ಮಾಡಿ

ScaleEzy ಈ ವೆಬ್‌ಸೈಟ್‌ಗಾಗಿ ಒಂದು **ಕೀ** ತೋರಿಸುತ್ತದೆ. ನಿಮ್ಮ ಡೆವಲಪರ್‌ಗೆ ಇದು ಬೇಕು.

1. [[1]] **Copy** ಒತ್ತಿ, ಕೀ ಅನ್ನು ಸುರಕ್ಷಿತವಾಗಿ ನಿಮ್ಮ ಡೆವಲಪರ್‌ಗೆ ಕಳುಹಿಸಿ.
2. ಕೀ ಸುರಕ್ಷಿತವಾಗಿ ಇಟ್ಟ ನಂತರವೇ [[2]] **I have saved it** ಒತ್ತಿರಿ.

![Lakshmi Silks website ನ ಕೀ ಬಾಕ್ಸ್. ಈ ಚಿತ್ರದಲ್ಲಿ ಕೀ ಮಸುಕಾಗಿದೆ. Copy 1 ಮತ್ತು I have saved it 2 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-save-the-key.webp "ಈ ಚಿತ್ರದಲ್ಲಿ ಕೀ ಮಸುಕಾಗಿದೆ. ನಿಮ್ಮ ಸ್ಕ್ರೀನ್‌ನಲ್ಲಿ ಪೂರ್ತಿ ಕೀ ಕಾಣುತ್ತದೆ.")

:::warning ಕೀ ಒಂದೇ ಸಲ ಕಾಣುತ್ತದೆ
ScaleEzy ಕೀ ಅನ್ನು ತನ್ನ ಬಳಿ ಇಟ್ಟುಕೊಳ್ಳುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ಯಾರೂ ಅದನ್ನು ಮತ್ತೆ ತೋರಿಸಲು ಆಗುವುದಿಲ್ಲ. ಕಳೆದುಹೋದರೆ **New key** ನಿಂದ ಹೊಸದು ಮಾಡಿ.
:::

## 4. ನಿಮ್ಮ ಕನೆಕ್ಷನ್

ಈಗ ವೆಬ್‌ಸೈಟ್‌ಗೆ ತನ್ನದೇ ಕಾರ್ಡ್ ಇರುತ್ತದೆ.

1. [[1]] ಸ್ಟೇಟಸ್. **WAITING FOR FIRST SYNC** ಎಂದರೆ ನಿಮ್ಮ ವೆಬ್‌ಸೈಟ್ ಇನ್ನೂ ನಿಮ್ಮ ಕ್ಯಾಟಲಾಗ್ ತೆಗೆದುಕೊಂಡಿಲ್ಲ. ಅದು ತೆಗೆದುಕೊಳ್ಳುವವರೆಗೆ ScaleEzy ಅಪ್‌ಡೇಟ್‌ಗಳನ್ನು ತಡೆಹಿಡಿಯುತ್ತದೆ. ನಂತರ ಸ್ಟೇಟಸ್ **CONNECTED** ಆಗುತ್ತದೆ.
2. [[2]] **Send test** ನಿಮ್ಮ ವೆಬ್‌ಸೈಟ್‌ಗೆ ನಿಜವಾದ ಟೆಸ್ಟ್ ಅಪ್‌ಡೇಟ್ ಕಳುಹಿಸಿ, ವೆಬ್‌ಸೈಟ್ ಉತ್ತರಿಸಿತೇ ಎಂದು ತಿಳಿಸುತ್ತದೆ.
3. [[3]] **New key** ಹೊಸ ಕೀ ಮಾಡುತ್ತದೆ. **ಹಳೆಯ ಕೀ ತಕ್ಷಣ ಕೆಲಸ ನಿಲ್ಲಿಸುತ್ತದೆ**, ಆದ್ದರಿಂದ ಹೊಸ ಕೀ ಅನ್ನು ನಿಮ್ಮ ಡೆವಲಪರ್‌ಗೆ ಕೊಡಿ.
4. [[4]] **Pause** ಸ್ವಲ್ಪ ಸಮಯ ಅಪ್‌ಡೇಟ್‌ಗಳನ್ನು ನಿಲ್ಲಿಸುತ್ತದೆ. ಮತ್ತೆ ಶುರು ಮಾಡಲು **Resume** ಒತ್ತಿರಿ.
5. [[5]] **Revoke** ಕನೆಕ್ಷನ್ ಅನ್ನು ಶಾಶ್ವತವಾಗಿ ಮುಗಿಸುತ್ತದೆ. ಇದನ್ನು ವಾಪಸ್ ಮಾಡಲು ಆಗುವುದಿಲ್ಲ.
6. [[6]] **Show what has been sent** ಪ್ರತಿ ಅಪ್‌ಡೇಟ್ ಅನ್ನು ತೋರಿಸುತ್ತದೆ: ಅದು **Delivered** ಆಯಿತೇ, ಮತ್ತು ಯಾವುದಾದರೂ ಏಕೆ ಫೇಲ್ ಆಯಿತು.

![Lakshmi Silks website ನ ಕಾರ್ಡ್. WAITING FOR FIRST SYNC 1, Send test 2, New key 3, Pause 4, Revoke 5 ಮತ್ತು Show what has been sent 6 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-the-connection.webp "ವಿಳಾಸದ ಕೆಳಗೆ ಅದು ಮಾರಾಟ ಮಾಡುವ ಲೊಕೇಶನ್‌ಗಳು ಮತ್ತು ಕೀಯ ಮೊದಲ ಭಾಗ ಕಾಣುತ್ತದೆ.")

ಅಪ್‌ಡೇಟ್‌ಗಳ ಪಟ್ಟಿಯಲ್ಲಿ, ಫೇಲ್ ಆದ ಅಪ್‌ಡೇಟ್ ಕಾರಣವನ್ನು ಮತ್ತು **Send again** ಬಟನ್ ತೋರಿಸುತ್ತದೆ.

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq Send test ನಲ್ಲಿ "Your storefront did not accept the test" ಎಂದು ಬರುತ್ತಿದೆ
ವೆಬ್‌ಸೈಟ್ ಸರಿಯಾಗಿ ಉತ್ತರಿಸಲಿಲ್ಲ. ಪೂರ್ತಿ ಮೆಸೇಜ್ ಅನ್ನು, ಅದರ HTTP ನಂಬರ್ ಸಹಿತ, ನಿಮ್ಮ ಡೆವಲಪರ್‌ಗೆ ಕಳುಹಿಸಿ.
:::

:::faq "That address resolves to a private network and cannot be reached from here" ಎಂದು ಬರುತ್ತಿದೆ
ಆ ವಿಳಾಸ ನಿಮ್ಮ ಆಫೀಸ್‌ನ ಒಳಗಿನ ನೆಟ್‌ವರ್ಕ್‌ಗೆ ಹೋಗುತ್ತದೆ. ScaleEzy https ನಿಂದ ಶುರುವಾಗುವ ಸಾರ್ವಜನಿಕ ವೆಬ್ ವಿಳಾಸಕ್ಕೆ ಮಾತ್ರ ಕಳುಹಿಸಬಲ್ಲದು.
:::

:::faq Connect ಒತ್ತಿದರೆ ಏನೂ ಆಗುತ್ತಿಲ್ಲ
**Name** ಮತ್ತು **Where should we send updates?** ಎರಡೂ ತುಂಬಿರಬೇಕು.
:::

:::faq ನಮ್ಮ ಡೆವಲಪರ್ ಕೀ ಕಳೆದುಕೊಂಡಿದ್ದಾರೆ
ಕಾರ್ಡ್‌ನಲ್ಲಿ **New key** ಒತ್ತಿ, ಹೊಸ ಕೀ ಅನ್ನು ಅವರಿಗೆ ಕೊಡಿ. ಹಳೆಯದು ತಕ್ಷಣ ಕೆಲಸ ನಿಲ್ಲಿಸುತ್ತದೆ.
:::

:::faq ಸ್ಟೇಟಸ್ WAITING FOR FIRST SYNC ಆಗಿಯೇ ಇದೆ
ನಿಮ್ಮ ವೆಬ್‌ಸೈಟ್ ಇನ್ನೂ ಕ್ಯಾಟಲಾಗ್ ತೆಗೆದುಕೊಂಡಿಲ್ಲ. ಕೀ ಬಳಸಿ ಮೊದಲ ಸಿಂಕ್ ಮಾಡಲು ನಿಮ್ಮ ಡೆವಲಪರ್‌ಗೆ ಹೇಳಿ.
:::
