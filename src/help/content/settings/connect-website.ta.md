இது **உங்கள் சொந்த டெவலப்பர்** உருவாக்கிய வெப்சைட்டுக்கானது. Shopify ஸ்டோர் என்றால், இதற்குப் பதிலாக [Shopify-ஐ இணைக்கவும்](/help/settings/connect-shopify) பாருங்கள்.

இணைத்த பிறகு, உங்கள் வெப்சைட் தானாகவே அப்டேட்டாக இருக்கும். எக்ஸ்போர்ட் செய்யவோ, பிறகு எதையும் அழுத்தவோ தேவையில்லை. இரண்டு விஷயங்களுக்கு உங்கள் டெவலப்பர் தேவை: அப்டேட்களைப் பெறும் **முகவரி**, மற்றும் **கீ**-யைப் பாதுகாப்பாக வைக்க ஒரு இடம்.

## 1. Storefront-ஐத் திறக்கவும்

1. **Settings** திறந்து [[1]] **Storefront** அழுத்துங்கள்.
2. Shopify கார்டுக்குக் கீழே [[2]] **Connect a storefront** அழுத்துங்கள். ஏற்கனவே ஒன்று இருந்தால், பட்டனில் **Connect another storefront** என்று இருக்கும்.

![Storefront திரை. Storefront 1, Connect a storefront 2 எனக் குறிக்கப்பட்டுள்ளன.](1-open.webp "ஒன்றுக்கு மேற்பட்ட வெப்சைட்டுகளை இணைக்கலாம்.")

## 2. ஃபார்மை நிரப்புங்கள்

1. [[1]] **Name**: எந்தப் பெயரும் போடலாம், உங்களுக்கு மட்டும்தான். உதாரணமாக *My website*.
2. [[2]] **Where should we send updates?**: உங்கள் டெவலப்பர் கொடுக்கும் முகவரி. இது **https** என்று தொடங்க வேண்டும்.
3. [[3]] **Which locations does this website sell from?**: வெப்சைட் எந்த ஸ்டோர்களின் ஸ்டாக்கையும் விலையையும் காட்ட வேண்டுமோ, அவற்றை டிக் செய்யுங்கள். எல்லா இடங்களிலிருந்தும் விற்க, **எதையும் டிக் செய்யாமல் விடுங்கள்**.
4. [[4]] **Connect** அழுத்துங்கள்.

![Connect a storefront ஃபார்ம். Name 1, முகவரி 2, டிக் செய்யப்பட்ட Main Store 3, Connect 4 எனக் குறிக்கப்பட்டுள்ளன.](2-fill-in.webp "இணைப்பதற்கு முன், அந்த முகவரி உண்மையில் இருக்கிறதா என்று ScaleEzy பார்க்கும்.")

## 3. கீ-யை இப்போதே சேமிக்கவும்

இந்த வெப்சைட்டுக்கான ஒரு **கீ**-யை ScaleEzy காட்டும். உங்கள் டெவலப்பருக்கு இது தேவை.

1. [[1]] **Copy** அழுத்தி, கீ-யை உங்கள் டெவலப்பருக்குப் பாதுகாப்பான வழியில் அனுப்புங்கள்.
2. கீ பாதுகாப்பாகச் சேமிக்கப்பட்ட பிறகுதான் [[2]] **I have saved it** அழுத்துங்கள்.

![Lakshmi Silks website-க்கான கீ பெட்டி. இந்தப் படத்தில் கீ மங்கலாக்கப்பட்டுள்ளது. Copy 1, I have saved it 2 எனக் குறிக்கப்பட்டுள்ளன.](3-save-the-key.webp "இந்தப் படத்தில் கீ மங்கலாக உள்ளது. உங்கள் திரையில் முழுவதும் தெரியும்.")

:::warning கீ ஒரே ஒரு முறை மட்டுமே தெரியும்
ScaleEzy கீ-யைத் தன்னிடம் வைத்துக்கொள்வதில்லை. அதனால் யாராலும் அதை மீண்டும் காட்ட முடியாது. தொலைந்துவிட்டால், **New key** மூலம் புதியது உருவாக்குங்கள்.
:::

## 4. உங்கள் இணைப்பு

இப்போது வெப்சைட்டுக்குத் தனியாக ஒரு கார்டு இருக்கும்.

1. [[1]] ஸ்டேட்டஸ். **WAITING FOR FIRST SYNC** என்றால், உங்கள் வெப்சைட் இன்னும் உங்கள் கேட்டலாக்கை எடுக்கவில்லை. அது எடுக்கும் வரை ScaleEzy அப்டேட்களை அனுப்பாது. அதன் பிறகு ஸ்டேட்டஸ் **CONNECTED** ஆகும்.
2. [[2]] **Send test** உங்கள் வெப்சைட்டுக்கு உண்மையான டெஸ்ட் அப்டேட் ஒன்றை அனுப்பி, வெப்சைட் பதில் சொன்னதா என்று காட்டும்.
3. [[3]] **New key** புதிய கீ உருவாக்கும். **பழைய கீ உடனே வேலை செய்யாமல் போகும்**. அதனால் புதியதை உங்கள் டெவலப்பருக்குக் கொடுங்கள்.
4. [[4]] **Pause** கொஞ்ச நேரம் அப்டேட்களை நிறுத்தும். மீண்டும் தொடங்க **Resume** அழுத்துங்கள்.
5. [[5]] **Revoke** இணைப்பை நிரந்தரமாக முடித்துவிடும். இதைத் திரும்பப் பெற முடியாது.
6. [[6]] **Show what has been sent** ஒவ்வொரு அப்டேட்டையும் காட்டும்: அது **Delivered** ஆனதா, ஒன்று ஏன் தோல்வியடைந்தது என்பதையும் காட்டும்.

![Lakshmi Silks website-க்கான கார்டு. WAITING FOR FIRST SYNC 1, Send test 2, New key 3, Pause 4, Revoke 5, Show what has been sent 6 எனக் குறிக்கப்பட்டுள்ளன.](4-the-connection.webp "முகவரிக்குக் கீழே, அது எந்த இடங்களிலிருந்து விற்கிறது என்பதும், கீ-யின் தொடக்கமும் தெரியும்.")

அப்டேட்களின் லிஸ்டில், தோல்வியடைந்த அப்டேட் அதற்கான காரணத்தையும் **Send again** பட்டனையும் காட்டும்.

## பொதுவான பிரச்சினைகள்

:::faq Send test அழுத்தினால் "Your storefront did not accept the test" என்று வருகிறது
வெப்சைட் சரியாகப் பதில் சொல்லவில்லை. முழு மெசேஜையும், அதன் HTTP எண்ணுடன், உங்கள் டெவலப்பருக்கு அனுப்புங்கள்.
:::

:::faq "That address resolves to a private network and cannot be reached from here" என்று வருகிறது
அந்த முகவரி உங்கள் சொந்த ஆபீஸ் நெட்வொர்க்கின் உள்ளே இருக்கிறது. https என்று தொடங்கும் பொது வெப் முகவரிக்கு மட்டுமே ScaleEzy அனுப்ப முடியும்.
:::

:::faq Connect அழுத்தினால் எதுவும் நடக்கவில்லை
**Name**, **Where should we send updates?** இரண்டையும் நிரப்ப வேண்டும்.
:::

:::faq எங்கள் டெவலப்பர் கீ-யைத் தொலைத்துவிட்டார்
கார்டில் **New key** அழுத்தி, புதிய கீ-யை அவருக்குக் கொடுங்கள். பழைய கீ உடனே வேலை செய்யாமல் போகும்.
:::

:::faq ஸ்டேட்டஸ் WAITING FOR FIRST SYNC என்றே இருக்கிறது
உங்கள் வெப்சைட் இன்னும் கேட்டலாக்கை எடுக்கவில்லை. கீ-யைப் பயன்படுத்தி முதல் சிங்க் செய்யச் சொல்லி உங்கள் டெவலப்பரிடம் கேளுங்கள்.
:::
