**మీ సొంత డెవలపర్** తయారు చేసిన వెబ్‌సైట్ కోసం దీన్ని వాడండి. Shopify స్టోర్ అయితే, బదులుగా [Shopify కనెక్ట్ చేయండి](/help/settings/connect-shopify) చూడండి.

కనెక్ట్ అయిన తర్వాత, మీ వెబ్‌సైట్ తనంతట తానే అప్‌డేట్ అవుతుంది. ఏదీ ఎక్స్‌పోర్ట్ చేయాల్సిన పని లేదు, తర్వాత ఏదీ నొక్కాల్సిన పని లేదు. రెండు విషయాలకు మీకు మీ డెవలపర్ కావాలి: అప్‌డేట్‌లు అందుకునే **అడ్రస్**, **కీ** ని భద్రంగా ఉంచే చోటు.

## 1. Storefront తెరవండి

1. **Settings** తెరిచి [[1]] **Storefront** నొక్కండి.
2. Shopify కార్డ్ కింద [[2]] **Connect a storefront** నొక్కండి. ఇప్పటికే ఒకటి ఉంటే, బటన్ మీద **Connect another storefront** అని ఉంటుంది.

![Storefront స్క్రీన్. Storefront 1 గా, Connect a storefront 2 గా గుర్తించబడ్డాయి.](1-open.webp "మీరు ఒకటి కంటే ఎక్కువ వెబ్‌సైట్‌లు కనెక్ట్ చేయవచ్చు.")

## 2. ఫారమ్ నింపండి

1. [[1]] **Name**: ఏదైనా పేరు, మీ కోసం మాత్రమే. ఉదాహరణకు *My website*.
2. [[2]] **Where should we send updates?**: మీ డెవలపర్ ఇచ్చే అడ్రస్. ఇది **https** తో మొదలవ్వాలి.
3. [[3]] **Which locations does this website sell from?**: వెబ్‌సైట్ ఏ స్టోర్‌ల స్టాక్, ధరలు చూపించాలో ఆ స్టోర్‌లను టిక్ చేయండి. అన్ని లొకేషన్‌ల నుండి అమ్మాలంటే **ఏదీ టిక్ చేయకుండా వదిలేయండి**.
4. [[4]] **Connect** నొక్కండి.

![Connect a storefront ఫారమ్. Name 1, అడ్రస్ 2, టిక్ చేసిన Main Store 3, Connect 4 గా గుర్తించబడ్డాయి.](2-fill-in.webp "కనెక్ట్ చేసే ముందు ఆ అడ్రస్ ఉందో లేదో ScaleEzy చెక్ చేస్తుంది.")

## 3. కీ ని ఇప్పుడే సేవ్ చేసుకోండి

ScaleEzy ఈ వెబ్‌సైట్ కోసం ఒక **కీ** చూపిస్తుంది. అది మీ డెవలపర్‌కు కావాలి.

1. [[1]] **Copy** నొక్కి, కీ ని భద్రమైన పద్ధతిలో మీ డెవలపర్‌కు పంపండి.
2. కీ భద్రంగా దాచిన తర్వాతే [[2]] **I have saved it** నొక్కండి.

![Lakshmi Silks website కోసం Key బాక్స్. ఈ బొమ్మలో కీ మసకగా ఉంది. Copy 1 గా, I have saved it 2 గా గుర్తించబడ్డాయి.](3-save-the-key.webp "ఈ బొమ్మలో కీ మసకగా ఉంది. మీ స్క్రీన్‌లో పూర్తిగా కనిపిస్తుంది.")

:::warning కీ ఒక్కసారి మాత్రమే కనిపిస్తుంది
ScaleEzy కీ ని దాచి ఉంచదు, అందుకే ఎవరూ దాన్ని మళ్లీ మీకు చూపించలేరు. కీ పోతే, **New key** తో కొత్తది తయారు చేయండి.
:::

## 4. మీ కనెక్షన్

ఇప్పుడు వెబ్‌సైట్‌కు దాని సొంత కార్డ్ ఉంటుంది.

1. [[1]] స్టేటస్. **WAITING FOR FIRST SYNC** అంటే మీ వెబ్‌సైట్ ఇంకా మీ క్యాటలాగ్ తీసుకోలేదు. అది తీసుకునే వరకు ScaleEzy అప్‌డేట్‌లు ఆపి ఉంచుతుంది. ఆ తర్వాత స్టేటస్ **CONNECTED** అవుతుంది.
2. [[2]] **Send test** మీ వెబ్‌సైట్‌కు నిజమైన టెస్ట్ అప్‌డేట్ పంపి, వెబ్‌సైట్ జవాబు ఇచ్చిందో లేదో చెబుతుంది.
3. [[3]] **New key** కొత్త కీ తయారు చేస్తుంది. **పాత కీ వెంటనే పనిచేయడం ఆగిపోతుంది**, కాబట్టి కొత్తది మీ డెవలపర్‌కు ఇవ్వండి.
4. [[4]] **Pause** కొంత సేపు అప్‌డేట్‌లు ఆపుతుంది. మళ్లీ మొదలుపెట్టడానికి **Resume** నొక్కండి.
5. [[5]] **Revoke** కనెక్షన్‌ను శాశ్వతంగా ముగిస్తుంది. దీన్ని వెనక్కి తీసుకోలేరు.
6. [[6]] **Show what has been sent** ప్రతి అప్‌డేట్‌ను లిస్ట్ చేస్తుంది, అది **Delivered** అయిందో లేదో, ఏదైనా ఎందుకు ఫెయిల్ అయిందో చూపిస్తుంది.

![Lakshmi Silks website కార్డ్. WAITING FOR FIRST SYNC 1, Send test 2, New key 3, Pause 4, Revoke 5, Show what has been sent 6 గా గుర్తించబడ్డాయి.](4-the-connection.webp "అడ్రస్ కింద అది అమ్మే లొకేషన్‌లు, దాని కీ మొదటి భాగం కనిపిస్తాయి.")

అప్‌డేట్‌ల లిస్ట్‌లో, ఫెయిల్ అయిన అప్‌డేట్ కారణం, **Send again** బటన్ చూపిస్తుంది.

## సాధారణ సమస్యలు

:::faq Send test లో "Your storefront did not accept the test" అని వస్తోంది
వెబ్‌సైట్ సరిగ్గా జవాబు ఇవ్వలేదు. పూర్తి మెసేజ్‌ను, దాని HTTP నంబర్‌తో సహా, మీ డెవలపర్‌కు పంపండి.
:::

:::faq "That address resolves to a private network and cannot be reached from here" అని వస్తోంది
ఆ అడ్రస్ మీ ఆఫీస్ లోపలి నెట్‌వర్క్‌ను చూపిస్తోంది. ScaleEzy https తో మొదలయ్యే పబ్లిక్ వెబ్ అడ్రస్‌కు మాత్రమే పంపగలదు.
:::

:::faq Connect నొక్కితే ఏమీ జరగడం లేదు
**Name**, **Where should we send updates?** రెండూ తప్పనిసరిగా నింపాలి.
:::

:::faq మా డెవలపర్ కీ పోగొట్టారు
కార్డ్ మీద **New key** నొక్కి, కొత్త కీ వారికి ఇవ్వండి. పాతది వెంటనే పనిచేయడం ఆగిపోతుంది.
:::

:::faq స్టేటస్ WAITING FOR FIRST SYNC దగ్గరే ఉంది
మీ వెబ్‌సైట్ ఇంకా క్యాటలాగ్ తీసుకోలేదు. కీ తో మొదటి సింక్ చేయమని మీ డెవలపర్‌ను అడగండి.
:::
