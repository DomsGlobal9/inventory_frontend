ಒಬ್ಬ ವ್ಯಕ್ತಿಯ ಬಗ್ಗೆ ಎಲ್ಲವೂ **Settings → Team & Users** ನಲ್ಲಿ ಅವರ ಕಾರ್ಡ್‌ನಲ್ಲಿ ಇರುತ್ತದೆ.

## 1. ವ್ಯಕ್ತಿಯನ್ನು ಹುಡುಕಿ

**Settings → Team & Users** ತೆರೆಯಿರಿ. ಪ್ರತಿಯೊಬ್ಬರಿಗೂ ಒಂದು ಕಾರ್ಡ್ ಇದೆ, ಅದರಲ್ಲಿ:

1. [[1]] ಅವರ **ರೋಲ್**,
2. [[2]] **ACTIVE** ಅಥವಾ **INACTIVE**,
3. [[3]] **Password**.

![Kiran Rao ಅವರ ಕಾರ್ಡ್ ಇರುವ Team and Users. ರೋಲ್ ಬಾಕ್ಸ್ 1, ACTIVE 2 ಮತ್ತು Password ಬಟನ್ 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](1-a-person.webp "ಸ್ಟೇಟಸ್‌ನ ಕೆಳಗೆ ಅವರು ಕೊನೆಯದಾಗಿ ಆಕ್ಟಿವ್ ಆಗಿದ್ದ ದಿನ, ಅಥವಾ Never ಕಾಣುತ್ತದೆ.")

ನಿಮ್ಮದೇ ಕಾರ್ಡ್ ಬೂದು ಬಣ್ಣದಲ್ಲಿರುತ್ತದೆ. ಇಲ್ಲಿ ಯಾರೂ ತಮ್ಮದೇ ರೋಲ್, ಸ್ಟೇಟಸ್ ಅಥವಾ ಪಾಸ್‌ವರ್ಡ್ ಬದಲಿಸಲು ಆಗುವುದಿಲ್ಲ. ಅಡ್ಮಿನ್ ಮಾಲೀಕರ ಕಾರ್ಡ್ ಅನ್ನೂ ಬದಲಿಸಲು ಆಗುವುದಿಲ್ಲ.

## 2. ರೋಲ್ ಬದಲಿಸಿ

ರೋಲ್ ಬಾಕ್ಸ್ ಒತ್ತಿ, ಹೊಸ ರೋಲ್ ಆರಿಸಿ. ಅದು ತಕ್ಷಣ ಸೇವ್ ಆಗುತ್ತದೆ. Save ಬಟನ್ ಇಲ್ಲ.

![Anjali Devi ಅವರ ಕಾರ್ಡ್‌ನಲ್ಲಿ ರೋಲ್ ಪಟ್ಟಿ ತೆರೆದಿದೆ, ADMIN, INVENTORY MANAGER, SALES, SUPER ADMIN ಮತ್ತು WAREHOUSE ಕಾಣುತ್ತಿವೆ.](2-change-role.webp "ಟಿಕ್ ಗುರುತು ಆ ವ್ಯಕ್ತಿಗೆ ಈಗ ಇರುವ ರೋಲ್ ತೋರಿಸುತ್ತದೆ.")

ಬದಲಾವಣೆ ತಕ್ಷಣ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಅವರು ಮತ್ತೆ ಸೈನ್ ಇನ್ ಮಾಡಬೇಕಿಲ್ಲ, ಆದರೆ ಅವರ ಮೆನು ಮುಂದಿನ ಸಲ ScaleEzy ತೆರೆದಾಗ ಅಥವಾ ರಿಫ್ರೆಶ್ ಮಾಡಿದಾಗ ಮಾತ್ರ ಬದಲಾಗುತ್ತದೆ. ಪ್ರತಿ ರೋಲ್ ಏನು ಮಾಡಬಹುದು ಎಂದು ತಿಳಿಯಲು [ರೋಲ್‌ಗಳು ಮತ್ತು ಅನುಮತಿಗಳು](/help/settings/roles) ಓದಿ.

## 3. ಈಗಿನ ಪಾಸ್‌ವರ್ಡ್ ನೋಡಿ

ತಂಡದವರು ಪಾಸ್‌ವರ್ಡ್ ಮರೆತಿದ್ದಾರೆಯೇ? ನೀವು ಅದನ್ನು ನೋಡಬಹುದು, ಅಥವಾ ಹೊಸದನ್ನು ಇಡಬಹುದು.

1. ಅವರ ಕಾರ್ಡ್‌ನಲ್ಲಿ **Password** ಒತ್ತಿರಿ.
2. [[1]] **View Current** ತೆರೆದಿರುತ್ತದೆ.
3. [[2]] **Reveal Password** ಒತ್ತಿರಿ. ಪಾಸ್‌ವರ್ಡ್ ಕಾಣುತ್ತದೆ, ಮತ್ತೆ ಕಳುಹಿಸಲು **Email**, **WhatsApp** ಮತ್ತು **Copy** ಬಟನ್‌ಗಳ ಜೊತೆ.
4. ಅದರ ಬದಲು ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಕೊಡಲು [[3]] **Set New** ಒತ್ತಿರಿ. ಮುಂದಿನ ಹಂತ ನೋಡಿ.

![Kiran Rao ಅವರ Password ಬಾಕ್ಸ್. View Current 1, Reveal Password 2 ಮತ್ತು Set New 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](3-password.webp "ಪ್ರತಿ ಸಲ ಪಾಸ್‌ವರ್ಡ್ ನೋಡಿದಾಗ ಅದು ದಾಖಲಾಗುತ್ತದೆ.")

ಪಾಸ್‌ವರ್ಡ್ ನೋಡಲು ನಿಮಗೆ **Read a team member's password** ಅನುಮತಿಯೂ ಬೇಕು. ಮಾಲೀಕರು ಮತ್ತು **ADMIN** ಗೆ ಇದು ಇದೆ.

*No viewable password on file for this account* ಎಂದು ಬಂದರೆ, ಅದರ ಬದಲು **Set New** ಬಳಸಿ.

## 4. ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಇಡಿ

ಪಾಸ್‌ವರ್ಡ್ ಬೇರೆ ಯಾರಿಗಾದರೂ ಗೊತ್ತಿರಬಹುದು ಎನಿಸಿದಾಗ ಇದನ್ನು ಬಳಸಿ.

1. **Password** ಬಾಕ್ಸ್‌ನಲ್ಲಿ **Set New** ಒತ್ತಿರಿ.
2. [[1]] ಕನಿಷ್ಠ 6 ಅಕ್ಷರಗಳ ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಟೈಪ್ ಮಾಡಿ, [[2]] **Set This Password** ಒತ್ತಿರಿ.
3. ಅಥವಾ ScaleEzy ಯೇ ಒಂದು ಮಾಡಲು [[3]] **Or Auto-generate Instead** ಒತ್ತಿರಿ.

![Password ಬಾಕ್ಸ್‌ನ Set New ಭಾಗ. ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಬಾಕ್ಸ್ 1, Set This Password 2 ಮತ್ತು Or Auto-generate Instead 3 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](4-set-new.webp "ಯಾವುದೇ ಬಟನ್ ಒತ್ತಿದ ನಂತರ ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಕಾಣುತ್ತದೆ.")

:::warning ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಇಟ್ಟರೆ ಆ ವ್ಯಕ್ತಿ ಎಲ್ಲೆಡೆ ಸೈನ್ ಔಟ್ ಆಗುತ್ತಾರೆ
ನೀವು ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಇಟ್ಟ ತಕ್ಷಣ, ಆ ವ್ಯಕ್ತಿ ಎಲ್ಲಾ ಫೋನ್ ಮತ್ತು ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ ಸೈನ್ ಔಟ್ ಆಗುತ್ತಾರೆ. ಅವರು ಹೊಸ ಪಾಸ್‌ವರ್ಡ್‌ನಿಂದ ಮತ್ತೆ ಸೈನ್ ಇನ್ ಮಾಡಬೇಕು. ನಿಮ್ಮ ಅಂಗಡಿಗೆ ಇಮೇಲ್ ಕೆಲಸ ಮಾಡುತ್ತಿದ್ದರೆ, ScaleEzy ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು ಅವರಿಗೆ ಇಮೇಲ್ ಕೂಡ ಮಾಡುತ್ತದೆ.
:::

## 5. ಯಾರನ್ನಾದರೂ ನಿಲ್ಲಿಸಿ

ಯಾರಾದರೂ ನಿಮ್ಮ ಅಂಗಡಿ ಬಿಟ್ಟಾಗ, ಅವರ ಲಾಗಿನ್ ಅನ್ನು ಬೇರೆಯವರಿಗೆ ಕೊಡಬೇಡಿ. ಅವರನ್ನು ನಿಲ್ಲಿಸಿ.

ಅವರ ಕಾರ್ಡ್‌ನಲ್ಲಿ [[1]] **ACTIVE** ಒತ್ತಿರಿ. ಅದು ತಕ್ಷಣ **INACTIVE** ಆಗುತ್ತದೆ.

![Ravi Kumar ಅವರ ಕಾರ್ಡ್, INACTIVE ಸ್ಟೇಟಸ್ 1 ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ.](5-switched-off.webp "ಆ ವ್ಯಕ್ತಿಯನ್ನು ಮತ್ತೆ ಆನ್ ಮಾಡಲು INACTIVE ಒತ್ತಿರಿ.")

- ಆ ವ್ಯಕ್ತಿ **ತಕ್ಷಣ ಎಲ್ಲೆಡೆ ಸೈನ್ ಔಟ್ ಆಗುತ್ತಾರೆ**, ಮತ್ತು ಸೈನ್ ಇನ್ ಮಾಡಲು ಆಗುವುದಿಲ್ಲ.
- ಅವರ ಹಿಂದಿನ ಸೇಲ್‌ಗಳು, ಸ್ಟಾಕ್ ಬದಲಾವಣೆಗಳು ಮತ್ತು ಇತಿಹಾಸ ಹಾಗೇ ಇರುತ್ತವೆ.
- ಅವರನ್ನು ಮತ್ತೆ ಆನ್ ಮಾಡಿದರೆ, ಅವರು ಮತ್ತೆ ಸೈನ್ ಇನ್ ಮಾಡಬೇಕು. ಹಳೆಯ ಸೈನ್ ಇನ್‌ಗಳು ವಾಪಸ್ ಬರುವುದಿಲ್ಲ.

:::note ಕೊನೆಯ ಮಾಲೀಕರನ್ನು ನಿಲ್ಲಿಸಲು ಆಗುವುದಿಲ್ಲ
ಒಬ್ಬರೇ **SUPER ADMIN** ಇದ್ದರೆ, ಅವರನ್ನು ನಿಲ್ಲಿಸಲು ಅಥವಾ ಅವರ ರೋಲ್ ಬದಲಿಸಲು ScaleEzy ಒಪ್ಪುವುದಿಲ್ಲ. ಮೊದಲು ಬೇರೆ ಯಾರನ್ನಾದರೂ SUPER ADMIN ಮಾಡಿ.
:::

## 6. ಇತ್ತೀಚಿನ ಚಟುವಟಿಕೆ ನೋಡಿ

**Team & Users** ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ **Recent Activity** ಒತ್ತಿರಿ. ಜನರು ಮಾಡಿದ ಕೊನೆಯ 30 ಕೆಲಸಗಳನ್ನು, ಹೊಸದು ಮೊದಲು, ದಿನಾಂಕ ಮತ್ತು ಸಮಯದ ಜೊತೆ ತೋರಿಸುತ್ತದೆ. ಕೌಂಟರ್‌ನಲ್ಲಿ ಬೆಲೆ ನೋಡುವುದು ಮತ್ತು ಪ್ರಿವ್ಯೂಗಳು ಇದರಲ್ಲಿ ಬರುವುದಿಲ್ಲ, ಏಕೆಂದರೆ ಅವು ಏನನ್ನೂ ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

![Recent Activity ಬಾಕ್ಸ್, Priya Reddy changed a team member's status ಮತ್ತು Priya Reddy created location ನಂತಹ ಕೆಲಸಗಳನ್ನು ದಿನಾಂಕ ಮತ್ತು ಸಮಯದ ಜೊತೆ ತೋರಿಸುತ್ತಿದೆ.](6-recent-activity.webp "ಮುಚ್ಚಲು ಬಾಕ್ಸ್‌ನ ಹೊರಗೆ ಅಥವಾ X ಒತ್ತಿರಿ.")

## ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

:::faq ರೋಲ್ ಬಾಕ್ಸ್ ಮತ್ತು Password ಬೂದು ಬಣ್ಣದಲ್ಲಿವೆ
ಅದು ನಿಮ್ಮದೇ ಕಾರ್ಡ್, ಅಥವಾ ಅದು ಮಾಲೀಕರ ಕಾರ್ಡ್ ಮತ್ತು ನೀವು ಅಡ್ಮಿನ್. ಮಾಲೀಕರನ್ನು ಕೇಳಿ.
:::

:::faq "You cannot manage this account: it can do things you cannot" ಎಂದು ಬರುತ್ತಿದೆ
ಆ ವ್ಯಕ್ತಿಯ ರೋಲ್ ನಿಮ್ಮದಕ್ಕಿಂತ ಹೆಚ್ಚು ಮಾಡಬಲ್ಲದು. ಕನಿಷ್ಠ ಅಷ್ಟೇ ಅನುಮತಿಗಳು ಇರುವವರು, ಅಥವಾ ಮಾಲೀಕರು ಮಾತ್ರ ಅವರನ್ನು ಬದಲಿಸಬಹುದು.
:::

:::faq Reveal Password ಒತ್ತಿದರೆ ಎರರ್ ಬರುತ್ತಿದೆ
ನಿಮ್ಮ ರೋಲ್‌ಗೆ **Read a team member's password** ಬೇಕು. ಮಾಲೀಕರನ್ನು ಕೇಳಿ, ಅಥವಾ ಅದರ ಬದಲು **Set New** ಬಳಸಿ.
:::

:::faq ತಮ್ಮ ಲಾಗಿನ್ ಕೆಲಸ ಮಾಡುತ್ತಿಲ್ಲ ಎಂದು ಆ ವ್ಯಕ್ತಿ ಹೇಳುತ್ತಿದ್ದಾರೆ
ಅವರ ಕಾರ್ಡ್ ನೋಡಿ. **INACTIVE** ಎಂದು ಇದ್ದರೆ, ಅವರನ್ನು ಆನ್ ಮಾಡಲು ಅದನ್ನು ಒತ್ತಿರಿ. ಯಾರಾದರೂ ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಇಟ್ಟಿದ್ದರೆ, ಹೊಸದನ್ನು ಅವರಿಗೆ ಕಳುಹಿಸಿ.
:::
