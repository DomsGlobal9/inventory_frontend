ஒரு நபரைப் பற்றிய எல்லாமே **Settings → Team & Users**-இல் உள்ள அவரது கார்டில் இருக்கும்.

## 1. அந்த நபரைக் கண்டுபிடியுங்கள்

**Settings → Team & Users** திறங்கள். ஒவ்வொருவருக்கும் ஒரு கார்டு இருக்கும், அதில்:

1. [[1]] அவரது **ரோல்**,
2. [[2]] **ACTIVE** அல்லது **INACTIVE**,
3. [[3]] **Password**.

![Kiran Rao-வின் கார்டுடன் Team and Users. ரோல் பெட்டி 1, ACTIVE 2, Password பட்டன் 3 எனக் குறிக்கப்பட்டுள்ளன.](1-a-person.webp "ஸ்டேட்டஸுக்குக் கீழே, அவர் கடைசியாக ஆக்டிவ் ஆக இருந்த நாள் அல்லது Never தெரியும்.")

உங்கள் சொந்த கார்டு மங்கலாக (grey) இருக்கும். இங்கே யாரும் தங்கள் சொந்த ரோல், ஸ்டேட்டஸ் அல்லது பாஸ்வேர்டை மாற்ற முடியாது. ஒரு அட்மின் உரிமையாளரின் கார்டையும் மாற்ற முடியாது.

## 2. ரோலை மாற்றுங்கள்

ரோல் பெட்டியை அழுத்தி, புதிய ரோலைத் தேர்ந்தெடுங்கள். உடனே சேமிக்கப்படும். Save பட்டன் இல்லை.

![Anjali Devi-யின் கார்டில் ரோல் லிஸ்ட் திறந்துள்ளது. ADMIN, INVENTORY MANAGER, SALES, SUPER ADMIN, WAREHOUSE தெரிகின்றன.](2-change-role.webp "அந்த நபருக்கு இப்போது உள்ள ரோலை டிக் குறி காட்டும்.")

மாற்றம் உடனே வேலை செய்யும். அவர் மீண்டும் உள்நுழையத் தேவையில்லை. ஆனால் அடுத்த முறை ScaleEzy-ஐத் திறக்கும்போது அல்லது ரிஃப்ரெஷ் செய்யும்போதுதான் அவரது மெனு மாறும். ஒவ்வொரு ரோலும் என்ன செய்யலாம் என்று பார்க்க, [ரோல்கள் மற்றும் அனுமதிகள்](/help/settings/roles) படியுங்கள்.

## 3. தற்போதைய பாஸ்வேர்டைப் பாருங்கள்

டீம் உறுப்பினர் பாஸ்வேர்டை மறந்துவிட்டாரா? நீங்கள் அதைப் பார்க்கலாம், அல்லது புதிய பாஸ்வேர்ட் அமைக்கலாம்.

1. அவரது கார்டில் **Password** அழுத்துங்கள்.
2. [[1]] **View Current** திறந்திருக்கும்.
3. [[2]] **Reveal Password** அழுத்துங்கள். பாஸ்வேர்ட் தெரியும். அதை மீண்டும் பகிர **Email**, **WhatsApp**, **Copy** பட்டன்களும் இருக்கும்.
4. அதற்குப் பதிலாகப் புதிய பாஸ்வேர்ட் கொடுக்க, [[3]] **Set New** அழுத்துங்கள். அடுத்த படியைப் பாருங்கள்.

![Kiran Rao-வின் Password பெட்டி. View Current 1, Reveal Password 2, Set New 3 எனக் குறிக்கப்பட்டுள்ளன.](3-password.webp "ஒவ்வொரு முறை பாஸ்வேர்ட் காட்டப்படும்போதும் அது பதிவு செய்யப்படும்.")

பாஸ்வேர்டைப் பார்க்க உங்களுக்கு **Read a team member's password** அனுமதியும் வேண்டும். உரிமையாளருக்கும் **ADMIN**-க்கும் இது உண்டு.

*No viewable password on file for this account* என்று வந்தால், அதற்குப் பதிலாக **Set New** பயன்படுத்துங்கள்.

## 4. புதிய பாஸ்வேர்ட் அமைக்கவும்

பாஸ்வேர்ட் வேறு யாருக்காவது தெரிந்திருக்கலாம் என்றால் இதைப் பயன்படுத்துங்கள்.

1. **Password** பெட்டியில் **Set New** அழுத்துங்கள்.
2. [[1]] குறைந்தது 6 எழுத்துகள் உள்ள புதிய பாஸ்வேர்டை டைப் செய்து, [[2]] **Set This Password** அழுத்துங்கள்.
3. அல்லது ScaleEzy-யே ஒன்றை உருவாக்க [[3]] **Or Auto-generate Instead** அழுத்துங்கள்.

![Password பெட்டியின் Set New பகுதி. புதிய பாஸ்வேர்ட் பெட்டி 1, Set This Password 2, Or Auto-generate Instead 3 எனக் குறிக்கப்பட்டுள்ளன.](4-set-new.webp "எந்தப் பட்டனை அழுத்தினாலும், புதிய பாஸ்வேர்ட் பெட்டியில் தெரியும்.")

:::warning புதிய பாஸ்வேர்ட் அமைத்தால் அந்த நபர் எல்லா இடத்திலும் வெளியேற்றப்படுவார்
புதிய பாஸ்வேர்ட் அமைத்தவுடன், அந்த நபர் எல்லா போன்களிலும் கம்ப்யூட்டர்களிலும் வெளியேற்றப்படுவார். புதிய பாஸ்வேர்டுடன் அவர் மீண்டும் உள்நுழைய வேண்டும். உங்கள் கடைக்கு மின்னஞ்சல் வேலை செய்தால், ScaleEzy புதிய பாஸ்வேர்டை அவருக்கு மின்னஞ்சலிலும் அனுப்பும்.
:::

## 5. ஒருவரை நிறுத்துங்கள்

ஒருவர் உங்கள் கடையை விட்டுப் போனால், அவரது லாகினை வேறு யாருக்கும் கொடுக்காதீர்கள். அவரை நிறுத்துங்கள் (switch off).

அவரது கார்டில் [[1]] **ACTIVE** அழுத்துங்கள். உடனே **INACTIVE** ஆக மாறும்.

![Ravi Kumar-இன் கார்டு. INACTIVE ஸ்டேட்டஸ் 1 எனக் குறிக்கப்பட்டுள்ளது.](5-switched-off.webp "அந்த நபரை மீண்டும் இயக்க INACTIVE அழுத்துங்கள்.")

- அந்த நபர் **உடனே எல்லா இடத்திலும் வெளியேற்றப்படுவார்**, மீண்டும் உள்நுழைய முடியாது.
- அவர் முன்பு செய்த விற்பனைகள், ஸ்டாக் நகர்வுகள், ஹிஸ்டரி எல்லாம் அப்படியே இருக்கும்.
- அவரை மீண்டும் இயக்கினால், அவர் மீண்டும் உள்நுழைய வேண்டும். பழைய லாகின்கள் திரும்ப வராது.

:::note கடைசி உரிமையாளரை நிறுத்த முடியாது
ஒருவர் மட்டுமே **SUPER ADMIN** ஆக இருந்தால், அவரை நிறுத்தவோ அவரது ரோலை மாற்றவோ ScaleEzy அனுமதிக்காது. முதலில் வேறு ஒருவரை SUPER ADMIN ஆக்குங்கள்.
:::

## 6. சமீபத்திய செயல்பாடுகளைப் பாருங்கள்

**Team & Users**-இன் மேலே உள்ள **Recent Activity** அழுத்துங்கள். மக்கள் செய்த கடைசி 30 செயல்கள், புதியது முதலில், தேதி மற்றும் நேரத்துடன் தெரியும். கவுண்டரில் விலை பார்ப்பதும் முன்னோட்டங்களும் இதில் வராது, ஏனெனில் அவை எதையும் மாற்றுவதில்லை.

![Recent Activity பெட்டி. Priya Reddy changed a team member's status, Priya Reddy created location போன்ற செயல்கள், ஒவ்வொன்றும் தேதி மற்றும் நேரத்துடன் தெரிகின்றன.](6-recent-activity.webp "மூட, பெட்டிக்கு வெளியே அல்லது X அழுத்துங்கள்.")

## பொதுவான பிரச்சினைகள்

:::faq ரோல் பெட்டியும் Password-உம் மங்கலாக (grey) உள்ளன
இது உங்கள் சொந்த கார்டு, அல்லது நீங்கள் அட்மின், இது உரிமையாளரின் கார்டு. உரிமையாளரிடம் கேளுங்கள்.
:::

:::faq "You cannot manage this account: it can do things you cannot" என்று வருகிறது
அந்த நபரின் ரோல் உங்களுடையதை விட அதிகம் செய்யக்கூடியது. குறைந்தது அதே அனுமதிகள் உள்ளவர் அல்லது உரிமையாளர் மட்டுமே அவரை மாற்ற முடியும்.
:::

:::faq Reveal Password அழுத்தினால் எரர் வருகிறது
உங்கள் ரோலுக்கு **Read a team member's password** அனுமதி வேண்டும். உரிமையாளரிடம் கேளுங்கள், அல்லது அதற்குப் பதிலாக **Set New** பயன்படுத்துங்கள்.
:::

:::faq தன் லாகின் வேலை செய்யவில்லை என்று அந்த நபர் சொல்கிறார்
அவரது கார்டைப் பாருங்கள். **INACTIVE** என்று இருந்தால், அதை அழுத்தி அவரை மீண்டும் இயக்குங்கள். யாராவது புதிய பாஸ்வேர்ட் அமைத்திருந்தால், புதியதை அவருக்குக் கொடுங்கள்.
:::
