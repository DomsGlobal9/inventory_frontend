ఒక వ్యక్తికి సంబంధించినవన్నీ **Settings → Team & Users** లో వారి కార్డ్ మీద ఉంటాయి.

## 1. ఆ వ్యక్తిని వెతకండి

**Settings → Team & Users** తెరవండి. ప్రతి ఒక్కరికీ ఒక కార్డ్ ఉంటుంది, అందులో:

1. [[1]] వారి **రోల్**,
2. [[2]] **ACTIVE** లేదా **INACTIVE**,
3. [[3]] **Password**.

![Kiran Rao కార్డ్‌తో Team and Users. రోల్ బాక్స్ 1, ACTIVE 2, Password బటన్ 3 గా గుర్తించబడ్డాయి.](1-a-person.webp "స్టేటస్ కింద వారు చివరిసారి యాక్టివ్‌గా ఉన్న రోజు, లేదా Never కనిపిస్తుంది.")

మీ సొంత కార్డ్ బూడిద రంగులో ఉంటుంది. ఇక్కడ ఎవరూ తమ సొంత రోల్, స్టేటస్ లేదా పాస్‌వర్డ్ మార్చలేరు. అడ్మిన్ యజమాని కార్డ్‌ను కూడా మార్చలేరు.

## 2. రోల్ మార్చండి

రోల్ బాక్స్ నొక్కి కొత్త రోల్ ఎంచుకోండి. వెంటనే సేవ్ అవుతుంది. Save బటన్ ఉండదు.

![Anjali Devi కార్డ్ మీద రోల్ లిస్ట్ తెరిచి ఉంది, ADMIN, INVENTORY MANAGER, SALES, SUPER ADMIN, WAREHOUSE చూపిస్తోంది.](2-change-role.webp "ఆ వ్యక్తికి ఇప్పుడు ఉన్న రోల్‌ను టిక్ గుర్తు చూపిస్తుంది.")

మార్పు వెంటనే పనిచేస్తుంది. వారు మళ్లీ సైన్ ఇన్ చేయాల్సిన పని లేదు, కానీ వారు తర్వాతి సారి ScaleEzy తెరిచినప్పుడు లేదా రిఫ్రెష్ చేసినప్పుడు మాత్రమే వారి మెనూ మారుతుంది. ప్రతి రోల్ ఏమి చేయగలదో తెలుసుకోవడానికి [రోల్స్, పర్మిషన్‌లు](/help/settings/roles) చదవండి.

## 3. ప్రస్తుత పాస్‌వర్డ్ చూడండి

టీమ్ మెంబర్ పాస్‌వర్డ్ మర్చిపోయారా? మీరు దాన్ని చూడవచ్చు, లేదా కొత్తది పెట్టవచ్చు.

1. వారి కార్డ్ మీద **Password** నొక్కండి.
2. [[1]] **View Current** తెరిచి ఉంటుంది.
3. [[2]] **Reveal Password** నొక్కండి. పాస్‌వర్డ్ కనిపిస్తుంది, దాన్ని మళ్లీ పంపడానికి **Email**, **WhatsApp**, **Copy** బటన్‌లు కూడా ఉంటాయి.
4. బదులుగా కొత్త పాస్‌వర్డ్ ఇవ్వాలంటే, [[3]] **Set New** నొక్కండి. తర్వాతి స్టెప్ చూడండి.

![Kiran Rao Password బాక్స్. View Current 1, Reveal Password 2, Set New 3 గా గుర్తించబడ్డాయి.](3-password.webp "పాస్‌వర్డ్ చూపించిన ప్రతిసారీ అది నమోదు అవుతుంది.")

పాస్‌వర్డ్ చూపించడానికి మీకు **Read a team member's password** పర్మిషన్ కూడా కావాలి. యజమానికి, **ADMIN** కు ఇది ఉంటుంది.

*No viewable password on file for this account* అని వస్తే, బదులుగా **Set New** వాడండి.

## 4. కొత్త పాస్‌వర్డ్ పెట్టండి

పాస్‌వర్డ్ వేరే ఎవరికైనా తెలిసి ఉండవచ్చు అనిపించినప్పుడు దీన్ని వాడండి.

1. **Password** బాక్స్‌లో **Set New** నొక్కండి.
2. [[1]] కనీసం 6 అక్షరాలతో కొత్త పాస్‌వర్డ్ టైప్ చేసి, [[2]] **Set This Password** నొక్కండి.
3. లేదా ScaleEzy నే ఒకటి తయారు చేయడానికి [[3]] **Or Auto-generate Instead** నొక్కండి.

![Password బాక్స్‌లో Set New భాగం. కొత్త పాస్‌వర్డ్ బాక్స్ 1, Set This Password 2, Or Auto-generate Instead 3 గా గుర్తించబడ్డాయి.](4-set-new.webp "ఏ బటన్ నొక్కినా, కొత్త పాస్‌వర్డ్ బాక్స్‌లో కనిపిస్తుంది.")

:::warning కొత్త పాస్‌వర్డ్ పెడితే ఆ వ్యక్తి అన్ని చోట్లా సైన్ అవుట్ అవుతారు
మీరు కొత్త పాస్‌వర్డ్ పెట్టిన వెంటనే, ఆ వ్యక్తి ప్రతి ఫోన్, కంప్యూటర్‌లో సైన్ అవుట్ అవుతారు. వారు కొత్త పాస్‌వర్డ్‌తో మళ్లీ సైన్ ఇన్ చేయాలి. మీ షాప్‌కు ఈమెయిల్ పనిచేస్తుంటే, ScaleEzy కొత్త పాస్‌వర్డ్‌ను వారికి ఈమెయిల్ కూడా చేస్తుంది.
:::

## 5. ఎవరినైనా ఆపివేయండి

ఎవరైనా మీ షాప్‌లో పని మానేసినప్పుడు, వారి లాగిన్‌ను వేరే వారికి ఇవ్వకండి. వారిని ఆపివేయండి.

వారి కార్డ్ మీద [[1]] **ACTIVE** నొక్కండి. అది వెంటనే **INACTIVE** గా మారుతుంది.

![Ravi Kumar కార్డ్, INACTIVE స్టేటస్ 1 గా గుర్తించబడింది.](5-switched-off.webp "ఆ వ్యక్తిని మళ్లీ ఆన్ చేయడానికి INACTIVE నొక్కండి.")

- ఆ వ్యక్తి **వెంటనే అన్ని చోట్లా సైన్ అవుట్ అవుతారు**, మళ్లీ సైన్ ఇన్ చేయలేరు.
- వారి పాత సేల్స్, స్టాక్ మార్పులు, హిస్టరీ అలాగే ఉంటాయి.
- మీరు వారిని మళ్లీ ఆన్ చేస్తే, వారు మళ్లీ సైన్ ఇన్ చేయాలి. వారి పాత సైన్ ఇన్‌లు తిరిగి రావు.

:::note చివరి యజమానిని ఆపివేయలేరు
ఒక్కరు మాత్రమే **SUPER ADMIN** అయితే, ScaleEzy వారిని ఆపివేయడానికి లేదా వారి రోల్ మార్చడానికి ఒప్పుకోదు. ముందు వేరే ఎవరినైనా SUPER ADMIN చేయండి.
:::

## 6. ఇటీవలి యాక్టివిటీ చూడండి

**Team & Users** పైన **Recent Activity** నొక్కండి. ప్రజలు చేసిన చివరి 30 పనులు, కొత్తవి ముందు, తేదీ, సమయంతో కనిపిస్తాయి. కౌంటర్‌లో ధర చూడటం, ప్రివ్యూలు ఇందులో రావు, ఎందుకంటే అవి ఏమీ మార్చవు.

![Recent Activity బాక్స్, Priya Reddy changed a team member's status, Priya Reddy created location లాంటి పనులను తేదీ, సమయంతో చూపిస్తోంది.](6-recent-activity.webp "మూసివేయడానికి బాక్స్ బయట లేదా X నొక్కండి.")
