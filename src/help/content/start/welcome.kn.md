ScaleEzy ನಿಮ್ಮ ಅಂಗಡಿಯ ಪ್ರತಿ ಪೀಸ್‌ನ ಲೆಕ್ಕ ಇಡುತ್ತದೆ: ನಿಮ್ಮ ಬಳಿ ಏನಿದೆ, ಅದು ಎಲ್ಲಿದೆ, ಅದಕ್ಕೆ ಎಷ್ಟು ಖರ್ಚಾಯಿತು, ಮತ್ತು ನೀವು ಏನು ಮಾರಿದ್ದೀರಿ. ನಿಮ್ಮ ತಂಡದ ಪ್ರತಿಯೊಬ್ಬರೂ ತಮ್ಮದೇ ಲಾಗಿನ್‌ನಿಂದ ಸೈನ್ ಇನ್ ಮಾಡುತ್ತಾರೆ, ಮತ್ತು ತಮ್ಮ ಕೆಲಸಕ್ಕೆ ಬೇಕಾದದ್ದನ್ನು ಮಾತ್ರ ನೋಡುತ್ತಾರೆ.

![ScaleEzy ಯಲ್ಲಿ ನಿಮ್ಮ Dashboard. ಸ್ಟಾಕ್ ಮೌಲ್ಯ, ಕಡಿಮೆ ಸ್ಟಾಕ್ ಮತ್ತು ಇತ್ತೀಚಿನ ಕೆಲಸಗಳನ್ನು ತೋರಿಸುತ್ತಿದೆ.](1-dashboard.webp "ಸೈನ್ ಇನ್ ಮಾಡಿದ ನಂತರ ಮೊದಲು ಬರುವ ಸ್ಕ್ರೀನ್ Dashboard.")

## ನಿಮ್ಮ ಅಂಗಡಿಯಲ್ಲಿ ಸ್ಟಾಕ್ ಹೇಗೆ ಓಡಾಡುತ್ತದೆ

![ಚಿತ್ರ: ಸಪ್ಲೈಯರ್ ಸಾಮಾನು ಕಳುಹಿಸುತ್ತಾರೆ, ನೀವು ಅದನ್ನು ಖರೀದಿ ಆರ್ಡರ್‌ನಲ್ಲಿ ಸ್ವೀಕರಿಸುತ್ತೀರಿ, ಶೆಲ್ಫ್‌ಗಳಲ್ಲಿ ಇಡುತ್ತೀರಿ, ಕೌಂಟರ್‌ನಲ್ಲಿ ಅಥವಾ ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ ಮಾರುತ್ತೀರಿ, ಮತ್ತು ರಿಟರ್ನ್‌ಗಳು ಮತ್ತೆ ಶೆಲ್ಫ್‌ಗೆ ಬರುತ್ತವೆ.](diagram-stock-flow.svg)

1. **ಖರೀದಿ.** ನಿಮ್ಮ ಸಪ್ಲೈಯರ್‌ಗೆ ಖರೀದಿ ಆರ್ಡರ್ (purchase order) ಮಾಡುತ್ತೀರಿ. ಸಾಮಾನು ಬಂದಾಗ ಅದನ್ನು *ಸ್ವೀಕರಿಸುತ್ತೀರಿ*, ಆಗ ನಿಮ್ಮ ಸ್ಟಾಕ್ ಹೆಚ್ಚುತ್ತದೆ.
2. **ಇಡುವುದು.** ನೀವು ರ್ಯಾಕ್ ಮತ್ತು ಶೆಲ್ಫ್‌ಗಳನ್ನು ಬಳಸಿದರೆ, ಪ್ರತಿ ಪೀಸ್ ಅನ್ನು ಒಂದು ಶೆಲ್ಫ್‌ನಲ್ಲಿ ಇಡುತ್ತೀರಿ. ಆಗ ಯಾರು ಬೇಕಾದರೂ ಕೆಲವೇ ಸೆಕೆಂಡುಗಳಲ್ಲಿ ಅದನ್ನು ಹುಡುಕಬಹುದು.
3. **ಮಾರಾಟ.** ಕೌಂಟರ್‌ನಲ್ಲಿ **New sale** ಮೂಲಕ, ಅಥವಾ ಆನ್‌ಲೈನ್ ಮತ್ತು Shopify ನಲ್ಲಿ. ನಿಮ್ಮ ಸ್ಟಾಕ್ ತಾನಾಗಿಯೇ ಕಡಿಮೆಯಾಗುತ್ತದೆ.
4. **ರಿಟರ್ನ್‌ಗಳು.** ಗ್ರಾಹಕರು ಏನನ್ನಾದರೂ ಹಿಂದಿರುಗಿಸಿದಾಗ, ನೀವು ಅದನ್ನು ಪರಿಶೀಲಿಸುತ್ತೀರಿ ಮತ್ತು ಅದು ಮತ್ತೆ ಸ್ಟಾಕ್‌ಗೆ ಸೇರುತ್ತದೆ.

### ಪ್ರತಿ ಹಂತದಲ್ಲಿ ಸ್ಟಾಕ್‌ಗೆ ಏನಾಗುತ್ತದೆ

*ಹೋಲ್ಡ್* (held) ಎಂದರೆ ಪೀಸ್‌ಗಳು ಇನ್ನೂ ಸ್ಟೋರ್‌ನಲ್ಲೇ ಇವೆ, ಆದರೆ ಒಂದು ಆರ್ಡರ್‌ಗಾಗಿ ತೆಗೆದಿಡಲಾಗಿದೆ, ಹಾಗಾಗಿ ಬೇರೆ ಯಾರೂ ಅವುಗಳನ್ನು ಮಾರಲು ಆಗುವುದಿಲ್ಲ. ಆರ್ಡರ್‌ನಲ್ಲಿ ಇದು **RESERVED** ಎಂದು ಕಾಣುತ್ತದೆ.

| ಹಂತ | ನಿಮ್ಮ ಸ್ಟಾಕ್‌ಗೆ ಏನಾಗುತ್ತದೆ |
|---|---|
| **Counter sale** (New sale) | ನೀವು ಮಾರಿದ ಸ್ಟೋರ್‌ನಲ್ಲಿ ತಕ್ಷಣ ಕಡಿಮೆಯಾಗುತ್ತದೆ. |
| **Draft order** | ಏನೂ ಬದಲಾಗುವುದಿಲ್ಲ. |
| **Confirmed order** | ಇನ್ನೂ ಏನೂ ಸ್ಟೋರ್‌ನಿಂದ ಹೊರಗೆ ಹೋಗುವುದಿಲ್ಲ, ಆದರೆ ಪೀಸ್‌ಗಳನ್ನು ಈ ಆರ್ಡರ್‌ಗಾಗಿ **ಹೋಲ್ಡ್** ಮಾಡಲಾಗುತ್ತದೆ. |
| **Dispatched** (ಕಳುಹಿಸಿದ್ದು ಅಥವಾ ಕೈಗೆ ಕೊಟ್ಟಿದ್ದು) | ಕಡಿಮೆಯಾಗುತ್ತದೆ, ಮತ್ತು ಹೋಲ್ಡ್ ಬಿಡುಗಡೆಯಾಗುತ್ತದೆ. ಕೆಲವು ಪೀಸ್‌ಗಳನ್ನು ಮಾತ್ರ ಕಳುಹಿಸಿದರೆ, ಉಳಿದವು ಹೋಲ್ಡ್‌ನಲ್ಲೇ ಇರುತ್ತವೆ. |
| **Cancel Order** | ಹೋಲ್ಡ್ ಆಗಿದ್ದ ಪೀಸ್‌ಗಳನ್ನು ಮತ್ತೆ ಮಾರಬಹುದು. ಏನೂ ಹೊರಗೆ ತೆಗೆದಿರಲಿಲ್ಲ, ಹಾಗಾಗಿ ಸ್ಟಾಕ್ ಬದಲಾಗುವುದಿಲ್ಲ. |
| **Close rest of order** (ಸ್ವಲ್ಪ ಕಳುಹಿಸಿದ್ದು) | ಕಳುಹಿಸಿದ್ದು ಮಾರಾಟವಾಗಿಯೇ ಇರುತ್ತದೆ. ಕಳುಹಿಸದ ಪೀಸ್‌ಗಳನ್ನು ಮತ್ತೆ ಮಾರಬಹುದು. |
| **Return completed** | **Restock** ಎಂದು ಗುರುತಿಸಿದ ಪೀಸ್‌ಗಳು, ಆರ್ಡರ್ ಬಂದ ಸ್ಟೋರ್‌ನಲ್ಲಿ ಮತ್ತೆ ಹೆಚ್ಚುತ್ತವೆ. **Damaged** ಅಥವಾ **Scrap** ಪೀಸ್‌ಗಳು ಸೇರುವುದಿಲ್ಲ. |
| **Purchase order received** | ನೀವು ಸ್ವೀಕರಿಸುವ ಸ್ಟೋರ್‌ನಲ್ಲಿ ಹೆಚ್ಚಾಗುತ್ತದೆ. ಆರ್ಡರ್‌ನ ಸ್ವಲ್ಪ ಭಾಗವನ್ನು ಈಗ, ಉಳಿದದ್ದನ್ನು ನಂತರ ಸ್ವೀಕರಿಸಬಹುದು. ಖರೀದಿ ಆರ್ಡರ್ ಕಳುಹಿಸುವುದರಿಂದ ಏನೂ ಬದಲಾಗುವುದಿಲ್ಲ. |
| **Transfer** | ಒಂದು ಸ್ಟೋರ್‌ನಲ್ಲಿ ಕಡಿಮೆಯಾಗಿ ಇನ್ನೊಂದರಲ್ಲಿ ತಕ್ಷಣ ಹೆಚ್ಚಾಗುತ್ತದೆ. ಹೋಲ್ಡ್ ಆಗಿರುವುದನ್ನಲ್ಲ, ಫ್ರೀ ಇರುವ ಪೀಸ್‌ಗಳನ್ನು ಮಾತ್ರ ಸಾಗಿಸಬಹುದು. |

:::note ಯಾವುದೂ ಅಳಿಸಿ ಹೋಗುವುದಿಲ್ಲ
ನಿಮ್ಮ ಸ್ಟಾಕ್‌ನ ಪ್ರತಿ ಬದಲಾವಣೆಯೂ ಬೇರೆ ಸಾಲಾಗಿ ಸೇವ್ ಆಗುತ್ತದೆ, ಯಾರು ಮಾಡಿದರು ಮತ್ತು ಯಾವಾಗ ಎಂಬುದರ ಜೊತೆಗೆ. ಒಂದು ಸಂಖ್ಯೆ ಯಾಕೆ ಹಾಗಿದೆ ಎಂದು ನೀವು ಯಾವಾಗ ಬೇಕಾದರೂ ನೋಡಬಹುದು.
:::

## ScaleEzy ಯಲ್ಲಿ ನೀವು ಏನೇನು ಮಾಡಬಹುದು

| ಭಾಗ | ಇದು ಯಾವುದಕ್ಕೆ |
|---|---|
| **Products** | ನೀವು ಮಾರುವ ಎಲ್ಲವೂ, ಸೈಜ್, ಬಣ್ಣ, ಬೆಲೆ, ಬಾರ್‌ಕೋಡ್ ಮತ್ತು ಫೋಟೋಗಳ ಜೊತೆಗೆ |
| **Orders** | ಕೌಂಟರ್ ಮಾರಾಟ, ಆನ್‌ಲೈನ್ ಆರ್ಡರ್‌ಗಳು, Shopify ಆರ್ಡರ್‌ಗಳು, ಮತ್ತು ಎಷ್ಟು ಹಣ ಬಂತು |
| **Returns** | ಗ್ರಾಹಕರು ಹಿಂದಿರುಗಿಸುವ ಸಾಮಾನುಗಳು |
| **Inventory** | ಪ್ರತಿ ಸ್ಟೋರ್‌ನಲ್ಲಿ ಎಷ್ಟು ಸ್ಟಾಕ್ ಇದೆ, ಕಡಿಮೆ ಸ್ಟಾಕ್ ಅಲರ್ಟ್‌ಗಳು, ಮತ್ತು ಸ್ಟಾಕ್ ಎಣಿಕೆ |
| **Shelves** | ಪ್ರತಿ ಪೀಸ್ ಯಾವ ರ್ಯಾಕ್ ಮತ್ತು ಶೆಲ್ಫ್‌ನಲ್ಲಿದೆ |
| **Transfers** | ನಿಮ್ಮ ಸ್ಟೋರ್‌ಗಳ ನಡುವೆ ಸ್ಟಾಕ್ ಸಾಗಿಸುವುದು |
| **Purchase Orders** | ಸಪ್ಲೈಯರ್‌ಗಳಿಂದ ಖರೀದಿಸುವುದು ಮತ್ತು ಡೆಲಿವರಿ ಸ್ವೀಕರಿಸುವುದು |
| **Offers** | ಸೇಲ್‌ಗಳು, ಡಿಸ್ಕೌಂಟ್ ಕೋಡ್‌ಗಳು ಮತ್ತು ಕೌಂಟರ್‌ನಲ್ಲಿ ಡಿಸ್ಕೌಂಟ್‌ಗಳು |
| **Customers** | ನಿಮ್ಮ ಗ್ರಾಹಕರು ಮತ್ತು ಅವರು ಏನು ಖರೀದಿಸಿದರು |
| **Settings** | ನಿಮ್ಮ ಅಂಗಡಿಯ ವಿವರಗಳು, ಸ್ಟೋರ್‌ಗಳು, ತಂಡ ಮತ್ತು ರೋಲ್‌ಗಳು |

:::tip ನಿಮ್ಮ ಕೆಲಸಕ್ಕೆ ಬೇಕಾದದ್ದು ಮಾತ್ರ ಕಾಣುತ್ತದೆ
ಸೇಲ್ಸ್‌ಮನ್‌ಗೆ **Purchase Orders** ಕಾಣದಿದ್ದರೆ, ಅದು ಬೇಕೆಂದೇ ಹಾಗೆ ಮಾಡಿರುವುದು. ಯಾರು ಏನು ನೋಡಬೇಕು ಎಂದು ಅಂಗಡಿಯ ಮಾಲೀಕರು **Settings → Roles & Permissions** ನಲ್ಲಿ ನಿರ್ಧರಿಸುತ್ತಾರೆ.
:::
