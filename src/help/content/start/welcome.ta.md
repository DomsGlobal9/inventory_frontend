உங்கள் கடையில் உள்ள ஒவ்வொரு பீஸையும் ScaleEzy கணக்கில் வைத்திருக்கிறது: உங்களிடம் என்ன இருக்கிறது, அது எங்கே இருக்கிறது, அதன் விலை என்ன, நீங்கள் என்ன விற்றீர்கள். உங்கள் டீமில் ஒவ்வொருவரும் தங்கள் சொந்த லாகினில் உள்நுழைவார்கள். அவரவர் வேலைக்குத் தேவையானதை மட்டுமே பார்ப்பார்கள்.

![ScaleEzy-இல் உங்கள் டாஷ்போர்டு. ஸ்டாக் மதிப்பு, குறைவான ஸ்டாக், சமீபத்திய செயல்பாடுகள் தெரிகின்றன.](1-dashboard.webp "உள்நுழைந்த பிறகு முதலில் வரும் திரை Dashboard தான்.")

## உங்கள் கடையில் ஸ்டாக் எப்படி நகர்கிறது

![படம்: சப்ளையர் சரக்கு அனுப்புகிறார், நீங்கள் பர்ச்சேஸ் ஆர்டரில் அதைப் பெற்றுக்கொள்கிறீர்கள், ஷெல்ஃப்களில் வைக்கிறீர்கள், கவுண்டரில் அல்லது ஆன்லைனில் விற்கிறீர்கள், ரிட்டர்ன்கள் மீண்டும் ஷெல்ஃப்களுக்கு வருகின்றன.](diagram-stock-flow.svg)

1. **வாங்குதல்.** உங்கள் சப்ளையரிடம் பர்ச்சேஸ் ஆர்டர் போடுகிறீர்கள். சரக்கு வந்ததும் அதைப் *பெற்றுக்கொள்கிறீர்கள்*. உங்கள் ஸ்டாக் கூடுகிறது.
2. **வைத்தல்.** நீங்கள் ரேக், ஷெல்ஃப் பயன்படுத்தினால், ஒவ்வொரு பீஸையும் ஒரு ஷெல்ஃபில் வைக்கிறீர்கள். அப்போது யார் வேண்டுமானாலும் சில விநாடிகளில் அதைக் கண்டுபிடிக்கலாம்.
3. **விற்றல்.** கவுண்டரில் **New sale** மூலம், அல்லது ஆன்லைனிலும் Shopify-இலும். உங்கள் ஸ்டாக் தானாகவே குறையும்.
4. **ரிட்டர்ன்.** வாடிக்கையாளர் எதையாவது திருப்பிக் கொண்டுவந்தால், நீங்கள் அதைச் சரிபார்க்கிறீர்கள். அது மீண்டும் ஸ்டாக்கில் சேரும்.

### ஒவ்வொரு படியிலும் ஸ்டாக்கிற்கு என்ன ஆகிறது

*ஒதுக்கி வைக்கப்பட்டது* என்றால், பீஸ்கள் இன்னும் ஸ்டோரில்தான் இருக்கின்றன, ஆனால் ஒரு ஆர்டருக்காகத் தனியாக வைக்கப்பட்டுள்ளன. அதனால் வேறு யாரும் அவற்றை விற்க முடியாது. ஆர்டரில் இது **RESERVED** என்று தெரியும்.

| படி | உங்கள் ஸ்டாக்கிற்கு என்ன ஆகிறது |
|---|---|
| **Counter sale** (New sale) | நீங்கள் விற்ற ஸ்டோரில் உடனே குறையும். |
| **Draft order** | எதுவும் மாறாது. |
| **Confirmed order** | இன்னும் எதுவும் ஸ்டோரை விட்டுப் போகாது, ஆனால் பீஸ்கள் இந்த ஆர்டருக்காக **ஒதுக்கி வைக்கப்படும்**. |
| **Dispatched** (அனுப்பப்பட்டது அல்லது கையில் கொடுக்கப்பட்டது) | குறையும், ஒதுக்கி வைத்தது விடுவிக்கப்படும். சில பீஸ்கள் மட்டும் அனுப்பப்பட்டால், மீதி ஒதுக்கியே இருக்கும். |
| **Cancel Order** | ஒதுக்கி வைத்த பீஸ்களை மீண்டும் விற்கலாம். எதுவும் வெளியே எடுக்கப்படவில்லை, அதனால் ஸ்டாக் மாறாது. |
| **Close rest of order** (பாதி அனுப்பப்பட்டது) | அனுப்பியவை விற்றதாகவே இருக்கும். அனுப்பாத பீஸ்களை மீண்டும் விற்கலாம். |
| **Return completed** | **Restock** எனக் குறித்த பீஸ்கள், ஆர்டர் வந்த ஸ்டோரில் மீண்டும் கூடும். **Damaged** அல்லது **Scrap** பீஸ்கள் கூடாது. |
| **Purchase order received** | நீங்கள் சரக்கைப் பெற்றுக்கொள்ளும் ஸ்டோரில் கூடும். ஆர்டரில் ஒரு பகுதியை இப்போதும் மீதியைப் பிறகும் பெற்றுக்கொள்ளலாம். பர்ச்சேஸ் ஆர்டரை அனுப்புவதால் எதுவும் மாறாது. |
| **Transfer** | ஒரு ஸ்டோரில் குறைந்து, மற்றொன்றில் உடனே கூடும். ஒதுக்கி வைத்தவை அல்ல, ஃப்ரீயாக உள்ள பீஸ்களை மட்டுமே மாற்ற முடியும். |

:::note எதுவும் அழிக்கப்படுவதில்லை
உங்கள் ஸ்டாக்கில் நடக்கும் ஒவ்வொரு மாற்றமும், யார் செய்தார், எப்போது செய்தார் என்ற விவரத்துடன் தனி வரியாகச் சேமிக்கப்படுகிறது. ஒரு எண் ஏன் அப்படி இருக்கிறது என்று எப்போது வேண்டுமானாலும் பார்க்கலாம்.
:::

## ScaleEzy-இல் நீங்கள் என்ன செய்யலாம்

| பகுதி | இது எதற்கு |
|---|---|
| **Products** | நீங்கள் விற்கும் எல்லாப் பொருட்களும், சைஸ், கலர், விலை, பார்கோடு, போட்டோவுடன் |
| **Orders** | கவுண்டர் விற்பனை, ஆன்லைன் ஆர்டர்கள், Shopify ஆர்டர்கள், எவ்வளவு பணம் கட்டப்பட்டது |
| **Returns** | வாடிக்கையாளர்கள் திருப்பிக் கொண்டுவரும் பொருட்கள் |
| **Inventory** | ஒவ்வொரு ஸ்டோரிலும் உங்களிடம் எவ்வளவு இருக்கிறது, குறைவான ஸ்டாக் அலர்ட்கள், ஸ்டாக் எண்ணிக்கை |
| **Shelves** | ஒவ்வொரு பீஸும் எந்த ரேக், எந்த ஷெல்ஃபில் இருக்கிறது |
| **Transfers** | உங்கள் ஸ்டோர்களுக்கு இடையே ஸ்டாக்கை மாற்றுதல் |
| **Purchase Orders** | சப்ளையர்களிடம் வாங்குதல், டெலிவரிகளைப் பெற்றுக்கொள்ளுதல் |
| **Offers** | சேல், டிஸ்கவுண்ட் கோடுகள், கவுண்டரில் டிஸ்கவுண்ட் |
| **Customers** | உங்கள் வாடிக்கையாளர்கள், அவர்கள் என்ன வாங்கினார்கள் |
| **Settings** | உங்கள் கடை விவரங்கள், ஸ்டோர்கள், டீம், ரோல்கள் |

:::tip உங்கள் வேலைக்குத் தேவையானது மட்டுமே தெரியும்
சேல்ஸ்மேனுக்கு **Purchase Orders** தெரியவில்லை என்றால், அது வேண்டுமென்றே செய்யப்பட்டது. யார் எதைப் பார்க்கலாம் என்று கடை உரிமையாளர் **Settings → Roles & Permissions**-இல் முடிவு செய்வார்.
:::
